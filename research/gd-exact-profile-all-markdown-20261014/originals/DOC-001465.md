# Explicit alternative-state tests for the three terminal screens

Status: JOINT UNVERIFIED. These tests refute weaker universal claims only.
They do not assert that any tested state is reached from e_1.
The frozen static function, backward definitions, physical word and true
radius are exactly those of joint_analysis.md, shared finding8dfaa8cef518215c.
No new function, step, computation or formal submission is introduced.

Use its C=beta+sqrt(1+2beta), kappa=1+beta^2, sigma_i, ell_i, A_i,D_i.
A component vanishes exactly when x_j<=A_j and
x_(j+1)>=beta*(x_j-ell_j).

## A. Cross-time pairing need not be nonnegative

Choose 2<=i<=k-2 and a physical suffix step h=b_(m-2) satisfying

    h>2kappa+2ell_(i+2)/(beta*sigma_i)
                                 +2C*sigma_(i+1)/sigma_i.
    alpha=h/2.

Set x_i=A_i, x_(i+1)=ell_(i+1)-kappa*sigma_i,
x_(i+2)=ell_(i+2), and x_j=0 for i+3<=j<=k.
Set x_(k+1)=ell_(k+1)+D_(k+1).

Here is an explicit choice of every earlier coordinate, removing any
implicit "sufficiently negative" selection. The known proposed update
of coordinate i is x_i^+=A_i-alpha*beta*sigma_i. Set

    x_(i-1)=min(A_(i-1),
              ell_(i-1)+min(x_i,x_i^+)/beta)-sigma_(i-1),

and successively for j=i-2,...,1 set

    x_j=min(A_j,ell_j+x_(j+1)/beta)-sigma_j.

Finally replace x_1 by min(x_1,A_1-beta*D_2).
Lowering x_1 cannot spoil its zero-cone inequality. At both the initial
and proposed next samples every component j<i has nonpositive input and
edge residuals. Hence its projection is zero, and (6) leaves all these earlier
coordinates unchanged, verifying the proposed update consistently.

Initially r_i=0,z_i=kappa*sigma_i, so

    (P_i,Q_i)=(beta*sigma_i,sigma_i).

The next component has input <ell_(i+1) and output ell_(i+2), so it is
zero. At j=i+2 the input is ell_(i+2) with nonnegative output, hence zero;
all later retired components are also zero. Therefore the retired
combined-gradient vector before the step is exactly
(beta*sigma_i,-sigma_i) on coordinates i,i+1.

After the step,

    r_i^+=-alpha*beta*sigma_i,
    z_i^+=kappa*sigma_i*(1-alpha)<0,
    r_(i+1)^+=(alpha-kappa)*sigma_i-ell_(i+2)/beta
                                               >C*sigma_(i+1).

Thus component i vanishes, while i+1 is in its horizontal cap since
its output remains ell_(i+2). All earlier components are zero by the
explicit selection; later retired components stay zero. The terminal
scalar remains isolated: its excess after the step is
D_(k+1)*(1-h/[2(1+S_(m-1))])>0, because
S_(m-1)>=b_(m-2)=h. Thus no omitted last gradient enters the retired vector.

The retired combined-gradient vector after the step is exactly
(0,C*sigma_(i+1)) on these coordinates. Consequently

    <d_after,d_before>=-C*sigma_i*sigma_(i+1)<0.

This uses the full static function and its physical available h.
It refutes universal nonnegativity of cross-time retired gradient
pairings. It does not refute an integrated inequality on the actual
initialized trajectory.

## B. Own-checkpoint margins are not sufficient for retirement invariance

Choose 2<=i<=k-1 and h=b_(J+i-2), alpha=h/2. This step occurs in the
complete H_(J+i-1) after checkpoint i. Assume the explicit finite conditions

    beta*D_(i+1)-beta^2*D_i-ell_(i+1)/beta
                                             >=kappa*sigma_(i-1),
    beta*T_i/M_i<1, h*C<2M_(i+1),
    u_(i+1)>=C+sqrt(1+2beta)*y_(i+1)/beta.                 (B1)

Set

    x_(i-1)=A_(i-1)-beta*D_i,
    x_i=A_i-beta*D_(i+1),
    x_(i+1)=ell_(i+1)+D_(i+1),
    x_j=0 for j>=i+2.

If i>=3, choose the earlier coordinates by the same zero-cone recipe
as in A, using boundary coordinate x_(i-1) and its proposed next value

    x_(i-1)^+=x_(i-1)-alpha*beta*sigma_(i-1).

That makes every component j<i-1 zero before and after. Enforce also
x_1<=A_1-beta*D_2 as in A. For i=2 no additional earlier coordinate
is needed: x_1=A_1-beta*D_2 already has the permanent first margin.

Now r_(i-1)=-beta*D_i<0 and

    z_(i-1)=beta*D_(i+1)-beta^2*D_i-ell_(i+1)/beta.

Condition(B1) and the exact edge formula give

    P_(i-1)=beta*sigma_(i-1),
    Q_(i-1)=sigma_(i-1)>0.

The own component i has its exact negative checkpoint margins

    r_i=-beta*D_(i+1), z_i=-kappa*D_(i+1),

so P_i=Q_i=0. The next component is precisely at its local block's
starting pair (ell_(i+1)+D_(i+1),0). The last condition in (B1)
therefore gives P_(i+1)=C*sigma_(i+1), Q_(i+1)=0.
Every old and future derivative is evaluated from the same function;
none is removed in this update.

Using D_i=sigma_(i-1)*(h/2-1),

    r_i^+=-beta*D_(i+1)+alpha*sigma_(i-1)
          =-beta*D_(i+1)+D_i+sigma_(i-1)>0,
    x_(i+1)^+=ell_(i+1)
                         +D_(i+1)*(1-h*C/[2M_(i+1)])
                                                >ell_(i+1).

Its new actual envelope value is consequently the positive horizontal
Huber Hub_(C*sigma_i)(r_i^+). The earlier zero-cone recipe verifies
the proposed previous-coordinate update; for i=2 it follows from Q_0=0.

The conditions in (B1) hold eventually in the joint scale derivation:
the amplitude ratios are uniformly positive, beta=1/k, the sigma and
translation terms are exponentially smaller than beta*D_i, and
h*C/(2M_(i+1)) tends to (lambda-2)/lambda<1.
No numerical threshold or finite-depth m>=1536 claim is inferred.

This refutes invariance based only on own-checkpoint margins and earlier
negative margins. It retains a saturated incoming Q_(i-1) and a legal
later step. The simultaneous tested point is an alternative state; the
true later state must instead be derived from the complete ordered history
in equations(32),(33),(33a). Initialized retirement is neither disproved
nor established.
