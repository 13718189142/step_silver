There is a short exact explanation for the first major face transition
in both selected zeta4 trajectories, valid beyond the recorded depths.
It does not control their whole suffix or assert an asymptotic payoff.

Fix m>=2 and the SAME centered tree, weights, original word and unit
start as in DERIVATION.md, with zeta=4. Let
k=2^(m-1)-1, b=1+a*c^(m-1), S_left=sum H_(m-1),
D=1+2S=1+4S_left+2b and delta=4/D.
Every h_i is positive. Since beta>=1/2 and c>1,
b=1+beta*c^(m-2)>=3/2. For each i<=k the prefix sum s_i<=S_left,
and hence

  1-delta*s_i >= (1+2b)/D >= delta.

For any t>=delta, projection of t*v_left onto delta*K_m is
delta*v_left: its full-leaf normal is
delta*(t-delta)*(<v_left,v_s>-1)<=0, since both leaves have norm one.
Induction therefore proves at every query through the largest bridge

  x_i=(1-delta*s_i)*v_left, g_i=delta*v_left, 0<=i<=k,
  x_(k+1)=-(2b-1)*v_left/D.

These are actual physical queries and the actual largest bridge h_k=b.
Put T=(2b-1)/4, so x_(k+1)/delta=-T*v_left.
The first reduced vertex is b_0=-sqrt(w_0)*e_root. Its candidate
normalized residual is Y=-T*v_left+sqrt(w_0)*e_root. For 1<=ell<m,

  <Y,b_ell-b_0>
    =2w_0-T*(2w_0+sum_(1<=j<ell)w_j-w_ell).

The parenthesized quantity is smallest at ell=1, because successive
increments equal 2w_ell-w_(ell+1)=w_ell*(2-r)>0. The final all-left
vertex has a further positive increment 2w_(m-1). Thus every inactive
normal is strictly negative whenever

  T > 2/(2-r)=c/(c-1).

For m>=4, beta>=3/4, c>lambda and lambda^2>5, giving
b>1+(3/4)*5=19/4 and T>17/8>2; meanwhile c/(c-1)<2 because c>2.
Thus, for EVERY m>=4, the exact first post-bridge gradient is

  g_(2^(m-1))=delta*b_0.

It is a right-root SUBTREE AVERAGE, not an individual full leaf; its
unique full-leaf barycentric representation is uniform on that subtree.
The state has nonzero coordinates at every depth, whereas this gradient
has only its root coordinate. The deep state is retained. In the frozen
m8/m10 records this transition occurs respectively at queries128/512,
as the symbolic calculation predicts. This derivation does not fix the
next support: the recorded trajectories subsequently use several faces.

For the observed m8,zeta4 suffix all supports are contained in {0,1,2};
the m10,zeta4 suffix has the same containment, including {2} and {0,2}.
Since b_0,b_1,b_2 have no coordinates at depth>=3, every such recorded
GD update leaves those deep coordinates unchanged. Their terminal values
in the raw rows therefore equal the first post-bridge values. In these
cases the objective is largely the positive excess <x-g,g>, not the
tiny squared-gradient contribution. This explains why the new scale
avoids the old pilot's observed terminal core collapse. The containment
is a statement about the recorded runs, not an all-m induction.

Conversely the zeta8 and zeta16 m8 records end with long checked core
suffixes. There g=x at each queried state, so x_next=(1-h)x. To describe
the mechanism symbolically, define s2(i) as the binary digit sum and
Pi_i=product_(t<i)(1-h_t). Because
1-h_t=-beta*c^(v2(t+1)-1) and
sum_(j=1)^i v2(j)=i-s2(i), one has

  Pi_i=(-1)^i*beta^i*c^(-s2(i)).

Whenever a suffix from q through n is actually inside the body, induction
in the physical updates gives

  V=||x_q||^2*beta^(2(n-q))*c^(2*s2(q)-2m).

This is a CONDITIONAL identity; it does not assert that such a suffix
exists. The frozen records checked all suffix queries, starting at90
for zeta8 and at85 for zeta16. No product or new payoff was evaluated
from this formula after closure. The identity explains the loss of
terminal value in those records without extending it to untested m.
