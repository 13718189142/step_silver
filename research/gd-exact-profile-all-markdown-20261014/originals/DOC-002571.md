# A uniform terminal-charge reduction for the chronological birth kernel

Status: **unverified proof draft**, fifth launch, second and final allocated
round. This file gives exact horizon truncation identities, an exact formula
for the constant column, and a proved conditional terminal-charge estimate.
It does **not** prove the remaining coefficient hypotheses. No fact submission
is authorized, so none of the new assertions is a fact-graph building block.

The underlying problem is still the original exact-profile minimax problem.
Even positivity of this entire kernel would only exclude its specified
reciprocal-level temporal family, not resolve the original problem.

## 1. Definitions, with the same original chronological word

Fix m>=128, epsilon=1/m, lambda=1+sqrt(2),
c=lambda(1+epsilon), a=(1-epsilon)/c, and d_k=1+a*c^k.
For this file extend the formula for d_k to every integer k>=0, keeping the
SAME epsilon. The extension is a device for writing coefficients; no new
steps are added to the original trajectory or interpolation constraints.

Let H_0 be empty and H_(j+1)=(H_j,d_j,H_j). The queried word is H_m with
its final d_0 removed, with q=2^m-2 steps h_i, elapsed times
s_i=sum_(r<i)h_r, and S=s_q. For vectors v,w_0,...,w_(m-1), define

 p_ij=product_(r<i)(1-h_r/d_j),
 g_i=v+sum_j p_ij*w_j,  x_i=x_0-sum_(r<i)h_r*g_r.

All vectors use one arbitrary common real Gram matrix. The first physical
d_j kills its modal column, so g_q=v and
x_q=x_0-S*v-sum_j d_j*w_j.

For one common value array put
Q_ij=f_i-f_j+<g_i,x_j-x_i>+||g_i-g_j||^2/2, including the zero optimum jet.
Necessity of Q_ij<=0, with this orientation, follows from the accepted
fact1252b8823bb5a290. Define

 J=sum_(i<q){2s_(i+1)h_i<g_(i+1),g_i>
       +s_(i+1)||g_(i+1)-g_i||^2+h_i(1-h_i)||g_i||^2}.

The exact identity is

 ||x_0||^2-2S f_q+2sum_i h_i Q_(i,star)
          +2sum_i s_(i+1)Q_(i+1,i)=||x_q||^2+J.             (1)

To check it, the optimum terms sum to
2sum h_i f_i-||x_0||^2+||x_q||^2+sum h_i(1-h_i)||g_i||^2;
summation by parts in the chain terms gives
2S f_q-2sum h_i f_i plus the other two terms in J. This also shows that
all selected Q multipliers are actual nonnegative original constraints.

Define phi_k(z)=product_(r<k)(1-d_r*z),
V_k=v+sum_j phi_k(1/d_j)w_j, U_k=V_k-v, and y_k=d_k U_k.
For k=m put U_m=0. Set z=(S+1)v.
The triangular evaluation matrix has nonzero positive diagonal, so this
change of coordinates is invertible on the residual vectors.

There is a birth array B_ik, initially B_00=1, all other B_0k=0, with

 B_(i+1),k=(1-h_i/d_k)B_ik+(h_i/d_(k-1))B_i,(k-1),          (2)

where the second summand is zero at k=0. It gives g_i=sum_k B_ik V_k.
This follows from
(1-hz)phi_k=(1-h/d_k)phi_k+(h/d_k)phi_(k+1).
On the infinite ruler word, an occupied state k always has d_k>=h_i:
at the first d_j all states below j have already vanished, and the
transition at d_j kills state j. Consequently all occupied transition
probabilities are nonnegative, sum_k B_ik=1, and

 B_ik=0 if k>i or i>=2^k.                                  (3)

The first assertion follows from advancing at most one state per step.
For the second, the first d_k is step2^k-1, with all smaller states already
zero, and its transition moves every remaining mass out of state k.

## 2. A row-finite infinite matrix and the exact constant-column identity

Run (2) formally on the infinite ruler word with the same d_k. In each
individual summand defining J put g_i=sum_k (B_ik/d_k)y_k, with no v.
Define E_kl to be its accumulated symmetric quadratic coefficient.
This is well-defined without summing an infinite numerical series: if a
term contains y_k, (3) forces its step index i<=2^k-1.
Also no state larger than i+1 can occur in that term. Therefore

 E_kl=0 when k<l and l>2^k.                                (4)

Every row has finite support. For 0<=k,l<m, E_kl is EXACTLY the residual
matrix entry for the original queried word, since all steps that can
contribute have already occurred before the last deleted d_0.

Write the actual form as

 J=sum_(k,l<m)E_kl<y_k,y_l>
       +2sum_(k<m)ell_k<y_k,z>+D||z||^2,
 D=S/(S+1).

Then its unnormalized constant load is

 ellhat_k:=(S+1)ell_k=sum_(l>=0)E_kl*d_l.                   (5)

In particular ellhat_k, like each E_kl, is independent of the enclosing
depth once the physical parameters epsilon,c,a have been fixed.

Proof of (5). In the extended birth system set every y_l=d_l*v. The
resulting g_i equals v because sum_l B_il=1. Polarizing against the single
coordinate y_k therefore gives the actual cross coefficient with the
constant gradient. Only finitely many steps and finitely many l can
contribute to that coefficient, by (3)-(4), so this substitution requires
no interchange of infinite sums. After restoring z=(S+1)v the identity
is precisely (5). Transient coefficients B_ik for k<m are unaffected by
the extension, and setting V_l=v at every l>=m recovers the original
absorbing state. Thus no artificial gradient or interpolation condition
has entered the actual data.

As direct checks, put t=d_0,u=d_1. The first two steps give

 E_00=(2-t)/t, E_01=(t-1)/u,
 E_11=[2t+u(2-u)]/u^2,
 E_12=(t+u)(u-1)/(u*d_2),
 ellhat_0=1, ellhat_1=t^2/u+t+1.                            (6)

For example, E_00*d_0+E_01*d_1=(2-t)+(t-1)=1, agreeing
with the first constant load. The second row likewise gives (6).

## 3. The exact effect of a right boundary

All definitions in this section use the infinite coefficient array (4).
Set an entry with a negative index to zero, and define

 A_i=E_(i,i+1), e_i=E_(i,i+2),
 b_i=A_i-2(e_(i-1)+e_i),
 tau_i^- =sum_(0<=l<=i-3)|E_il|,
 tau_i^+ =sum_(l>=i+3)|E_il|,
 t_i=E_ii-A_(i-1)-A_i+e_(i-2)-tau_i^-.                     (7)

The letter t_i in (7) is a diagonal margin, distinct from the isolated
scalar t=d_0 in (6). Both tail sums are finite by (4).

For the finite m-by-m residual matrix, extract second-neighbor triple
squares and adjacent pair squares using

 e_i^[m]=E_(i,i+2) (0<=i<=m-3),
 b_i^[m]=E_(i,i+1)-2(e_(i-1)^[m]+e_i^[m]),
 r_i^[m]=E_ii-E_(i-1,i)-E_(i,i+1)+e_(i-2)^[m]+e_i^[m]
                   -sum_(0<=l<m,|l-i|>=3)|E_il|.            (8)

Out-of-range entries in the FINITE definitions (8) are zero. Substitution
into (7) gives the exact formulas

 b_i^[m]=b_i                         (0<=i<=m-3),
 b_(m-2)^[m]=b_(m-2)+2e_(m-2),

 r_i^[m]=t_i+e_i-sum_(i+3<=l<m)|E_il| (0<=i<=m-3),
 r_(m-2)^[m]=t_(m-2),
 r_(m-1)^[m]=t_(m-1)+A_(m-1).                              (9)

Thus a proof of the infinite bulk remainder alone can miss the entire
e_(m-2) term at the penultimate row. Formula (9) retains that charge.

In particular, the following bounds imply all needed finite residual
square signs and uniform lower bounds for the denominators used below:

 e_i>=0, tau_i^+<=e_i, t_i>=0,
 b_i>=2/15, and A_i>=2/5 for i>=2.                          (10)

Under (10), e_i^[m]>=0, b_i^[m]>=2/15, r_i^[m]>=0, and
r_(m-1)^[m]>=2/5. These are direct consequences of (9).
No claim that (10) has been proved for the actual whole family is made.

## 4. A complete conditional bound on the terminal charge

pseudoinverse or eigenvalue hypothesis. In addition to (10), suppose

           2d_i<=ellhat_i<=(11/4)d_i for every i>=2.         (11)

Only the indices needed in (9) and below are necessary; uniform bounds on
the infinite arrays are a convenient stronger formulation.
Then the COMPLETE local-square constant remainder satisfies

                         Delta>1/100                       (12)

for every actual m>=128. This is a proved implication, not a proof of
its hypotheses (10)-(11).

First define alpha_(-1)=0, alpha_i=ell_i-alpha_(i-1), and

 C_charge=sum_(i<m-1)alpha_i^2/b_i^[m]
                    +alpha_(m-1)^2/r_(m-1)^[m],
 Delta=D-C_charge.                                         (13)

The exact full square identity is

 J=sum_(i<m-1)r_i^[m]||y_i||^2
   +r_(m-1)^[m]||y_(m-1)+(alpha_(m-1)/r_(m-1)^[m])z||^2
   +sum_(i<m-1)b_i^[m]||y_i+y_(i+1)+(alpha_i/b_i^[m])z||^2
   +sum_(i<m-2)e_i||y_i+2y_(i+1)+y_(i+2)||^2
   +sum_(k<l<m,l-k>=3)|E_kl| ||y_k+sgn(E_kl)y_l||^2
   +Delta||z||^2.                                         (14)

Indeed the triple squares supply the distance-two entries and twice their
weights to each adjacent entry. The pair squares then supply exactly
b_i^[m], and the long-range squares supply precisely their signed entries.
Their diagonal cost is the one subtracted in (8). Finally
ell_i=alpha_i+alpha_(i-1) proves the constant cross terms, and the completed
squares spend exactly C_charge. Define a zero-weight signed square as zero.

## 5. An exact inverse formula for attacking the remaining scalar bounds

Set xi_j=d_j*w_j. The triangular birth transformation is y=R*xi with
R_kj=(d_k/d_j)phi_k(1/d_j) for j>=k, and zero otherwise.
For 0<=j<=k its inverse has the closed formula

 (R^(-1))_jk = product_(0<=r<=k,r!=j)(1-d_r/d_j)^(-1).       (20)

One proof uses Newton interpolation at theta_j=1/d_j. The coefficients
c_j=[product_(r!=j)(theta_j-theta_r)]^(-1) annihilate every polynomial
of degree less than k and give its leading coefficient at degree k:
this follows by comparing the degree-k coefficient in the Lagrange
interpolation formula. Apply it to phi_l, 0<=l<=k, whose leading
coefficient at l=k is (-1)^k product_(r<k)d_r. This gives the inverse
of the evaluation matrix, and multiplying row j by d_j and column k
by1/d_k yields (20). The formula is also valid at k=0 by empty products.

For the ACTUAL affine-geometric levels, let q_c=1/c and
P_r=product_(s=1)^r(1-q_c^s), with P_0=1. Then (20) becomes

 (R^(-1))_jk
  =(-1)^(k-j) q_c^((k-j)(k-j+1)/2)
       *(d_j/(d_j-1))^k/(P_j P_(k-j)).                     (21)

This is exact, not a replacement of d_j by a*c^j. To see it, factor
1-d_r/d_j=[(d_j-1)/d_j](1-c^(r-j)) in each of the k factors
in (20), then split r<j and r>j. In particular, the alternating sign
and the fast decay with distance k-j have explicit formulas.

For later error estimates, P_r>1/4 uniformly. Indeed q_c<5/12, and
product_(s=2)^r(1-q_c^s)>=1-sum_(s=2)^r q_c^s
>=1-q_c^2/(1-q_c)>59/84. Multiplying by 1-q_c>7/12 gives
P_r>413/1008>1/4 for r>=1 (P_0=1). Therefore

 |(R^(-1))_jk| <16 q_c^((k-j)(k-j+1)/2)
                     *exp(k/(a*c^j)).                    (22)

The last step uses (1+1/(a*c^j))^k<=exp(k/(a*c^j)). The exponential
factor cannot be dropped uniformly at small j; it is the exact effect
of the additive1 in the physical levels. Formula (22) is a coefficient
estimate, not yet a bound on all entries of the transformed kernel.

## 8. Unconditional uniform tail bounds from the birth paths

The infinitely extended rows in (24) can be reduced to a fixed width with
explicit error, without a numerical kernel evaluation or an extra sign
assumption. The following bounds hold for the ACTUAL parameters above.

For an integer r>=0 define

 p_r=min{1, (7/2)^r/[r! 2^(r(r-1)/2)]}.

For r>=1 put

 H_r=(77/4)p_r+(343/24)2^(-r)[(5/2)p_(r-1)+p_r].           (33)

Then for every k>=2 and r>=1,

 |E_(k,k+r)| <=(d_k/d_(k+r))H_r <=2^(-r)H_r.              (34)

Here is a direct path proof. All steps that contribute to row k occur
by the first physical d_k. Their total elapsed time is
T=S_(H_k)+d_k. The explicit word sum and a/(c-2)<1 give

 S_(H_k)=a*c^k/(c-2)+(1-a/(c-2))*2^k-1<=c^k-1,
 T<(1+1/a)d_k<(7/2)d_k.                                  (35)

Every one of these steps is at most d_k. Once a birth path first reaches
state k, to reach state k+r by this time it must make r further births
on distinct increasing steps. Condition on its first arrival at k.
For any specified r birth steps the probability is at most their step
product divided by d_k*d_(k+1)*...*d_(k+r-1); the intervening stay
probabilities and any continuation probability are at most one.
The sum of these products is at most T^r/r!, because the expansion of
T^r contains every product of r distinct steps r! times and all other
terms are nonnegative. By (15), the denominator is at least
d_k^r*2^(r(r-1)/2). The resulting bound holds for every possible
arrival time, hence also without conditioning. It proves

       B_(i,k+r)<=p_r for every i<=2^k.                    (36)

This estimate applies to both ends of every step contributing to row k.

To bound the actual quadratic coefficient, write v_ij=B_ij/d_j for the
coefficient of y_j in g_i; this symbol v_ij is unrelated to the constant
gradient vector v. Equation (2) implies

 |v_(i+1),k-v_ik| <=h_i(c+1)/d_k^2,
