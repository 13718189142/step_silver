# Phase-sensitive seed amplification: source and scope check

Contextual source screen,2026-09-27; not an accepted Danus theorem.

[Liu,Chen,Jiang,Wang,arXiv2609.11788v1](https://arxiv.org/html/2609.11788v1)
uses leaf count N. Proposition2.5 identifies U_N with the symmetric
recursive primitive scalar. Section6 reciprocates OBS-F rates into W_N
with W_1=1 and join A(u,w)=(4u+w+sqrt(w*w+8u*w))/2. Theorem6.3 gives a
positive Lipschitz periodic asymptotic profile for N^p times the OBS-F rate,
uniform over dyadic blocks. Theorem6.5 states nonconstancy and strict
separation from its homogeneous support barrier. Remark1.2 explicitly
limits optimality to recursively generated classes. Application here
requires matching U_N=P_(N-1),source W_N=B_(N-1),p=our rho, normalization,
and every index shift. Neither that paper's theorem names nor its reported
formalization are treated as verifier acceptance by this project.

C72 d4ccd3fd9ce605f1 proves a DRAFT sufficient amplification threshold
A_seed>(r_seed+1)^rho by replacing primitive leaves and comparing through
one GLOBAL limsup. That criterion deliberately avoids a phase theorem.
It does not establish necessity of that threshold, or rule out useful
non-dyadic seeds below the power envelope. Main's new proposed question is
whether an exact phase-resolved comparison gives a strictly weaker usable
threshold. This is an inference and research request, not a derived claim.
It must retain the physical output length m_seed*n and the actual terminal
leaf loss from C72.

A useful answer needs a proved phase/DP matching, a legitimate input
subsequence, a quantitative strict margin and an actual full certificate.
An unevaluated infimum involving an unknown phase is not a found seed.
Nor is a small finite gain above P_r automatically enough.

[Chikhi,arXiv2609.13765v1](https://arxiv.org/html/2609.13765v1)
was also screened. Its Theorem1's exact objective is F(z_N), where
z_N=prox_(lambda F)(x_N), in relaxed proximal point. The sharp eta/4 factor
there is not the original smooth f(x_N) objective coefficient. The paper's
smooth constant-step optimality statement concerns final gradient norm.
Neither result directly provides an improving schedule for this goal.
This is an applicability boundary, not a criticism of those results.

No new optimizer, phase scan, installation, verifier, or external publication
was made. The full-primitive44-evaluation batch is closed; its28 unused
