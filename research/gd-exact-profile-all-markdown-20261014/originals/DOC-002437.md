## 2. One static smooth convex function

\[

## 5. Exact evaluation of Profile A on the full path

The unsigned physical mass identity fixed by the source gives

\[

\qquad
\frac{U_A}{S}\longrightarrow\frac{3+v}{4}.

Define the actual signed physical gradient sum \(G_A=\sum_{i<n}u_i^A g_i\). For any block of physical steps of mass \(L\), squared-step sum \(V_{\rm block}\), and starting cumulative time \(t\),

\[
\sum_{\rm block}h_iT_i=tL+\frac{L^2-V_{\rm block}}2.
\tag{5.2}
\]

For the actual block \(j\ge2\), \(t=S-S_j\), \(L=L_j=S_j-S_{j-1}\), and \(V_{\rm block}=V_j-V_{j-1}\). Hence its unsigned Profile A weight is exactly

\[
W_j=\frac{L_j}{2}
+\frac{S_j^2-S_{j-1}^2+V_j-V_{j-1}}{4S}.
\tag{5.3}
\]

The same expression with \(S_0=V_0=0\) defines the last single-step weight \(W_1\). All block gradients are their signs except for the final physical gradient, whose magnitude is \(\beta\). Thus

\[
G_A=\sum_{j=1}^m(-1)^{m-j}W_j
+(-1)^{m-1}(\beta-1)W_1.
\tag{5.4}
\]

The correction in (5.4), divided by \(S\), tends to zero. For each fixed \(k\ge0\), (3.2) and (4.3) give

\[
\frac{S_{m-k}}S\to r^k,\qquad
\frac{V_{m-k}}{S^2}\to vr^{2k}.
\]

Accordingly,

\[
\frac{W_{m-k}}S\to
\frac{1-r}{2}r^k+\frac{(1+v)(1-r^2)}4r^{2k}.
\tag{5.5}
\]

Here the passage from fixed \(k\) to the entire alternating sum is uniform. Indeed, for all sufficiently large enclosing \(m\) and \(0\le j\le m\), (3.2) and (4.3) give \(S_j\le Cc^j\), \(V_j\le Cc^{2j}\), and \(S_m\ge c^m/C\), for one absolute constant \(C\). Formula (5.3) then bounds \(|W_{m-k}|/S\) by \(C'(r^k+r^{2k})\), because \(c\ge c_0\). The tails beyond \(k=K\) tend to zero uniformly as \(K\to\infty\). Taking a finite-prefix limit and then this geometric tail bound justifies summing (5.5).

The resulting limit is

\[
\frac{G_A}{S}\longrightarrow
\gamma_A:=\frac{1-r}{2(1+r)}
+\frac{(1+v)(1-r^2)}{4(1+r^2)}
=\frac r2+\frac{1+v}{4\sqrt2}.
\tag{5.6}
\]

Use odd \(m\), so that the actual terminal gradient is \(-q\). Define the positive-direction residual increment

\[
M_A=u_n^Aq-G_A.
\]

By (4.2), (5.1), and (5.6),

\[
\frac{M_A}{S}\longrightarrow
\eta_A:=r\left(\frac{32}{17}-\frac{3+v}{4}\right)-\gamma_A
=r\left(\frac{43}{68}-\frac v4\right)
-\frac{1+v}{4\sqrt2}.
\tag{5.7}
\]

This constant is strictly positive with a rational margin. Since \(r>2/5\), \(v<1/20\), and \(1/\sqrt2<5/7\),

\[
\eta_A>
\frac25\left(\frac{43}{68}-\frac1{80}\right)
-\frac{21}{20}\frac5{28}
=\frac{411}{6800}>\frac3{50}.
\tag{5.8}
\]

Therefore \(M_A>0\) for every sufficiently large odd enclosing \(m\).

## 6. Profile B: an exact comparison on physical indices
