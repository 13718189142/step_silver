# Bounded formula discovery, owned by main

The persistent Goal authorizes this fresh small discovery batch. It is
separate from every closed historical grant and from the native analytical
allocation, whose mathematical-program allowance remains zero. All model
calls remain Astra/ultra; no model call is made by this numerical batch.

Purpose: screen one explicit midpoint initialization for the correlated
strictly damped Gray dictionary. The program evaluates the frozen formulas,
all prescribed projection-normal rows and the distance to the explicitly
known minimizer. It does NOT solve a projection/PEP/optimization problem,
formally verify a claim, or certify an asymptotic result.

Limits:12 charged child jobs,5 external wall-clock seconds per job,60
reserved/accounted seconds total. The intended batch is2 calibrations and8
discovery cases. The last2 slots are reserved only for one documented code
or backend repair with calibration, or one explicit reconstruction; they
are not additional exploratory grid points. Every failure and timeout is
charged BEFORE execution. No solver, benchmark DP, package installation,
network math service, verifier call or fact submission is authorized.

All case parameters and source are frozen before the first mathematical
import. The public existing numerical Python runtime is reused as software;
no worker-private memory is read. Each external child is terminated after
5 seconds. All jobs are sequential. Numeric output is explicitly evidence
for discovery only; raw signed residuals and arrays are retained without
PSD repair, clipping or omitted rows. Unused reserve is retired at closure.

The finite probes m6 and m8 are OUTSIDE the claimed m>=1536 target domain.
They may reveal algebraic failure patterns; they prove neither feasibility
nor impossibility in the original asymptotic problem. A positive result
still requires a complete exact, uniform proof and independent attack.
Original target OPEN. The worker and native TASK limits are unchanged.
