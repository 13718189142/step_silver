Exact optima and uniform deficits for two static spiral witness families with independently chosen stage parameters.

All spaces, norms and inner products are finite-dimensional real Euclidean ones. The notation defined below is local to this statement and its proof. In particular, local arc constants C_i are distinct from the benchmark sequence C_n; local coordinate states are distinct from hierarchy masses. The two constructions below are separate families.

Fix an integer m>=1536 and a real parameter 0<tau<=1/4. Set lambda=1+sqrt(2), beta=1-tau/m, c=lambda(1+tau/m), a=beta/c, H_0=(), and H_(j+1)=(H_j,1+a*c^j,H_j) for 0<=j<m. Every child uses this same enclosing pair (m,tau). Put h=H_(m,tau)=H_m, S_j=sum H_j, n_m=2^m-1, and H_base(h)=1/(1+2S_m). Every original physical entry of h is retained in its original order.

For advertised smoothness L>0 and an objective g with an attained minimum, use the actual updates x_(t+1)=x_t-(h_t/L)*grad g(x_t), 0<=t<n_m, and define

    E_L(g,h)=2(g(x_(n_m))-min g)/(L*dist(x_0,argmin g)^2).

All instances below start at x_0=e_0, the first standard coordinate vector, and have strictly positive closest distance. Write E=E_1. The functions F and f below are constructed at smoothness one; their general-L instances are L*F and L*f.

Choose any ordered subset of original positions of h, of any size 1<=k<=n_m, and write

    h=(block_0,b_0,block_1,...,b_(k-1),block_k), s_i=sum block_i.

Each block is the complete original chronological list between selections. Empty blocks are allowed. For each 0<=i<k choose independently kappa_i>0 and 0<epsilon_i<=1/2. These choices may depend on the entire word, m, tau and every selected position, and are fixed before defining one static objective. Put

    theta_sp,i=arctan(1/epsilon_i),
    C_i=sqrt(1+epsilon_i^2)*exp(kappa_i*theta_sp,i),
    T_i=(exp((1-kappa_i^2)*theta_sp,i/kappa_i)-1)/(1-kappa_i^2) if kappa_i<1,
    T_i=theta_sp,i/kappa_i if kappa_i>=1,
    H_sp,i=C_i*[1+(1+kappa_i)*T_i]-1,
    A_i=epsilon_i+(1+H_sp,i)/epsilon_i.

For source eligibility require b_i>=2(1+epsilon_i^(-2)). For main eligibility define

    qmax_i=1 if kappa_i<=epsilon_i,
    qmax_i=sqrt((1+epsilon_i^2)/(1+kappa_i^2))
           *exp(kappa_i*[theta_sp,i-arctan(1/kappa_i)]) otherwise,
    N_i=max(0,kappa_i*qmax_i-epsilon_i),
    B_i=1+max(epsilon_i^(-2),N_i/epsilon_i),

and require b_i>=B_i. All eligibility equalities, epsilon_i=1/2, kappa_i=1, kappa_i>1, and all mixtures of different neighboring parameters are included.

The exact local construction used in each family is as follows. For one stage suppress i, and define, on 0<=theta<=theta_sp,

    R(theta)=C*exp(-kappa*theta),
    e(theta)=(cos(theta),-sin(theta)),
    t(theta)=(-sin(theta),-cos(theta)),
    v(theta)=R(theta)*e(theta)=(p(theta),-q(theta)),
    K=conv({0} union {v(theta):0<=theta<=theta_sp}).

For a chronological local list alpha_1,...,alpha_r>=0, set theta_r=theta_sp and r_r=v_r=(epsilon,-1). Define the states backward. If r_j=(u_j,-y_j) and alpha=alpha_j, use v_(j-1)=(C,0), theta_(j-1)=0, r_(j-1)=r_j+alpha*(C,0) when y_j<=kappa*[u_j+(alpha-1)*C]. Otherwise theta_(j-1) is the unique root theta in (0,theta_j] of

    <r_j,e(theta)-kappa^(-1)*t(theta)>/R(theta)=1-alpha,

and set v_(j-1)=v(theta_(j-1)) and r_(j-1)=r_j+alpha*v_(j-1). These are exact finite mathematical definitions, including zero local steps. Define the ordered outputs

    P=sum_(j=1)^r alpha_j*p(theta_(j-1)),
    Q=sum_(j=1)^r alpha_j*q(theta_(j-1)).

The empty list has P=Q=0. Given its local checkpoint b_loc and positive scale sigma as specified separately below, set

    z_circ=(1-sigma*(epsilon+P),sigma*(1+Q))=(c_1,c_2),
    U=1-sigma*(P+epsilon*b_loc), Y=sigma*Q,
    V={0,v(0),v_0,...,v_r},
    phi(z)=sigma*max_(v in V)<v,z-z_circ>,
    f_loc(x)=env_1(phi)(x)=min_z[phi(z)+||x-z||^2/2].

Here env_1 denotes this quadratic envelope. The local query states are x_j^loc=z_circ+sigma*r_j. Define Hub_d(z), for d>0, as 0 for z<=0, z^2/2 for 0<=z<=d, and d*z-d^2/2 for z>=d.

SOURCE family. For each eligible stage use its own parameters, local list block_i/2, local checkpoint b_i/2, and

    sigma'_i=1/[C_i*s_i/2+epsilon_i*b_i/2+A_i].

Primes on P'_i,Q'_i,r'_(i,j),v'_(i,j),phi'_i,f'_i,c'_(i,1),c'_(i,2),U'_i,Y'_i denote exactly these half-step local objects; f'_i is the local envelope. Put

    G'_i=sigma'_i*b_i/2,
    D'_0=1, ell'_0=0,
    D'_(i+1)=D'_i*G'_i, ell'_(i+1)=D'_i*sigma'_i*Q'_i,
    delta'=D'_k/(1+s_k),
    F(x)=(1/2)*sum_(i<k)(D'_i)^2
         *f'_i((x_i-ell'_i)/D'_i,x_(i+1)/D'_i)
         +(1/2)*Hub_(delta')(x_k-ell'_k), x in R^(k+1).

MAIN family. For each eligible stage use its own parameters, the full physical local list block_i, and local checkpoint b_i. Let P_i,Q_i,r_(i,j),v_(i,j) be these full-step objects. Put

    M_i^tr=P_i+max(epsilon_i*b_i,epsilon_i+(1+Q_i)/epsilon_i),
    sigma_i=1/M_i^tr,
    D_0=1, ell_0=0,
    D_(i+1)=D_i*sigma_i*(b_i-1),
    ell_(i+1)=D_i*sigma_i*(1+Q_i).

Use these scales in the local definition of phi_i,c_(i,1),c_(i,2),U_i,Y_i. Define

    Phi_i(z)=D_i^2*phi_i((z_i-ell_i)/D_i,z_(i+1)/D_i), i<k,
    delta=D_k/(1+2s_k), Phi_k(z)=delta*max(z_k-ell_k,0),
    J(z)=max_(0<=i<=k)Phi_i(z), f=env_1(J), z in R^(k+1).

Each F and f is a single everywhere finite convex differentiable function with 1-Lipschitz gradient and attained minimum zero. All parameters, planes, scales and translations in these definitions are fixed before the run. In SOURCE, at the start of stage i, coordinates j<i are frozen at ell'_j+D'_j*U'_j, the current coordinate is ell'_i+D'_i and later coordinates are zero. At the ordinary and checkpoint queries the active local state is x_j^loc and the exact gradient and value are

    grad F(x)=D'_i*sigma'_i*v'_(i,j)/2 on coordinates (i,i+1),
    F(x)=(D'_i*sigma'_i)^2
         *[<v'_(i,j),r'_(i,j)>-||v'_(i,j)||^2/2]/2.

All other gradient coordinates vanish. Thus a physical step h_t implements precisely the local half step h_t/2. The checkpoint leaves coordinate i at ell'_i+D'_i*U'_i and the next coordinate at ell'_(i+1)+D'_(i+1). In its tail, at already executed physical mass u in [0,s_k],

    x_k-ell'_k=D'_k-delta'*u/2,
    grad F(x)=delta'*e_k/2,
    F(x)=[delta'*(D'_k-delta'*u/2)-(delta')^2/2]/2,
    2F(x_(n_m))=(D'_k)^2/[2(1+s_k)].

In MAIN, at the start of stage i, coordinates j<i are frozen at ell_j+D_j*U_j, the current coordinate is ell_i+D_i and later coordinates are zero. At all ordinary and checkpoint queries the exact data are

    grad f(x)=D_i*sigma_i*v_(i,j) on coordinates (i,i+1),
    f(x)=(D_i*sigma_i)^2
         *[<v_(i,j),r_(i,j)>-||v_(i,j)||^2/2].

All other gradient coordinates vanish. Every full physical step implements exactly the full local step; the checkpoint freezes coordinate i at ell_i+D_i*U_i and puts the next coordinate at ell_(i+1)+D_(i+1). In its tail, at already executed physical mass u in [0,s_k],

    x_k=ell_k+D_k-delta*u,
    grad f(x)=delta*e_k,
    f(x)=delta*(D_k-delta*u)-delta^2/2,
    2f(x_(n_m))=D_k^2/(1+2s_k).

The complete SOURCE minimum set is

    C_source={x: x_i<=zeta'_i,
       epsilon_i*x_i-x_(i+1)<=epsilon_i*zeta'_i-D'_i*c'_(i,2), i<k;
       x_k<=ell'_k}, zeta'_i=ell'_i+D'_i*c'_(i,1).

It contains zero. For an exact formula retaining every row, let A_rad consist of rows e_i^T and (epsilon_i*e_i-e_(i+1))^T for i<k, followed by e_k^T, and let t_rad be their right sides in this polyhedron. For every linearly independent row subset I put A_I=(A_rad)_I, r_I=A_I*e_0-(t_rad)_I, K_I=A_I*A_I^T, lambda_I=K_I^(-1)*r_I. The empty subset contributes zero. The true squared closest distance is

    rho_S^2=dist(e_0,C_source)^2
       =max_(I independent,lambda_I>=0) r_I^T*K_I^(-1)*r_I,
    0<rho_S^2<=1.

Thus its actual payoff is (D'_k)^2/[2(1+s_k)*rho_S^2]. In particular the first-center expression is only a lower distance bound:

    rho_S^2>=(sigma'_0)^2*[(epsilon_0+P'_0)^2+(1+Q'_0)^2].

The complete MAIN minimum set is

    C_main={x: x_i<=zeta_i,
       epsilon_i*x_i-x_(i+1)<=epsilon_i*zeta_i-D_i*c_(i,2), i<k;
       x_k<=ell_k}, zeta_i=ell_i+D_i*c_(i,1).

It contains zero. Its true closest point to e_0 is z_bar=(c_(0,1),c_(0,2),0,...,0), and

    rho_M^2=dist(e_0,C_main)^2
       =sigma_0^2*[(epsilon_0+P_0)^2+(1+Q_0)^2]>0,
    E(f,h)=(b_0-1)^2/
       {[(epsilon_0+P_0)^2+(1+Q_0)^2]*(1+2s_k)}
       *product_(i=1)^(k-1)[(b_i-1)/M_i^tr]^2.

All original physical query rows, the unqueried terminal row and every minimizer row satisfy every ordered smooth-convex interpolation inequality. Explicitly, for g=L*F or L*f and any two such samples x_u,x_v,

    g(x_u)-g(x_v)+<grad g(x_u),x_v-x_u>
       +||grad g(x_u)-grad g(x_v)||^2/(2L)<=0.

Their full Gram matrices are positive semidefinite. No step, gradient coordinate, query, terminal point or minimizer inequality is omitted.

Include also the empty-selection members: SOURCE has F=Hub_(1/(1+S_m))/2 from 1, with closest distance 1 and E(F,h)=1/[2(1+S_m)]; MAIN has f=Hub_(1/(1+2S_m)) from 1, with closest distance 1 and E(f,h)=H_base(h). For either family and every L>0, scaling the constructed objective by L and using the physical steps h_t/L preserves every iterate and gives E_L(L*F,h)=E(F,h), respectively E_L(L*f,h)=E(f,h).

For the original benchmark define Omega(x,y)=(x+y+sqrt((x+y)^2+4xy))/2 and G(x,y)=2x+y/2+sqrt(y^2+8xy)/2 for x,y>=0. Set C_0=B_0=1 and, for every integer n>=1,

    C_n=max_(0<=j<n)Omega(C_j,C_(n-j-1)),
    B_n=max_(0<=j<n)G(C_j,B_(n-j-1)), U_n^ZJ=1/B_n,

with every original integer split retained. Let Z_1=lim_(m->infinity)lambda^(-m)*B_(2^m-1), whose existence, positivity and finiteness are unconditional conclusions of predecessor 04219554e41d9750. Only that predecessor's unconditional benchmark/ray and certified saved-enclosure conclusions are used; no seed hypothesis is assumed.

The following bounds hold uniformly for every m>=1536 and 0<tau<=1/4, all eligible nonempty selections of arbitrary size, and all independent local parameter choices above:

    E_L(L*f,H_(m,tau))<(441/500)/(1+2S_m)       [MAIN],
    E_L(L*F,H_(m,tau))<(9801/10000)/(1+2S_m)  [SOURCE].

Define L_source,stage and L_main,stage as the suprema of these actual closest-distance normalized payoffs over their respective selections and independent parameter arrays, including their respective empty-selection members. Define L_both,stage as the supremum over the union of the two separate families and L_source,stage^H=max{L_source,stage,H_base}. Then the exact family optima are

    L_source,stage(H_(m,tau))=1/[2(1+S_m)],
    L_main,stage(H_(m,tau))=L_both,stage(H_(m,tau))
       =L_source,stage^H(H_(m,tau))=1/(1+2S_m).

For every m>=1536 they satisfy the strict original-benchmark deficits

    B_(n_m)*L_both,stage(H_(m,1/4))<237/250,
    B_(n_m)*L_both,stage(H_(m,tau))<79/80 for every 1/5<=tau<=1/4.

The same two bounds hold for each of the other three named optima. For each fixed 0<tau<=1/4, the B_(n_m)-scaled limit of each of the four named optima, as m tends to infinity, is exactly Z_1/(2*exp(tau)).

These are optima only over the two explicitly specified static witness families on this hierarchy. The statement gives no upper bound for unrestricted W_n, no tau=1 theorem, no optimality over other functions or schedules, and no resolution of the original exact minimax problem.
