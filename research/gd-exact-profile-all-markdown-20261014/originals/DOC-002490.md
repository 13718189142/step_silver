# Frozen output schema

Allocation 287b7a3644e5bda3; resume 5b362b0a381a2444.
All numerical contents below are produced inside the external 20-second child.

Each attempted case receives stdout.txt, stderr.txt, PRECHARGE.json and a broker
receipt.json with process identity, deadline, exit status, elapsed wall time,
calibration verdict, file-presence flags and byte hashes. A killed or failed
child may have partial exports; that is not a complete or passing case.

Complete child exports are:

- input_arrays.npz: V,h,P,G,A,C,K,cn,D, and for Gray all original characters,
  weights, W, Gray labels, original frame Gram, independent kernel and signed
  difference, chronological levels and radii, closed radii and signed
  differences, root/radial data. Fixture cases include every exact-builder
  comparison. No inverse Gram, dropped character, radius clipping or geometry
  optimization is used.
- program_data.npz: the canonical sparse conic constraint matrix components,
  shape, right side, objective vector and quadratic components if present.
- solver_data.json: versions, requested options, status, CVXPY solver statistics,
  all original constraint duals and primal variables b,zstar,tau,F. The one
  CLARABEL solve's available canonical x,s,z and primal/dual objective/residual
  data are exported through its existing solution accessor; accessor failure
  is explicitly flagged, never repaired by a second solve.
- arrays.npz: input arrays plus returned b,zstar,tau,F, signed scaled ordered,
  zero and polar residuals, squared-cone and SOC defects, tau defect, all
  available original and canonical dual/primal outputs. With robust positive
  tau only: x0, selected polar point, prescribed X and gradients, initializer
  potentials, all signed unscaled ordered/zero/polar defects, direct normal
  evaluations and discrepancies, GD recurrence defects, prescribed function
  values, terminal numerator, selected radius and selected-polar score.
- result.json: solver status, objective, construction statistics, each signed
  residual family's min/max/absolute maximum and positive count, tau/guard
  flags, extraction status, program objective and D_j times objective, separate
  selected-polar score and D_j times that score, and true-distance status.
  Calibrations add in-child expected objective, objective error, each gate and
  exact failure reasons. complete_exports is a file-presence check; broker
  additionally requires exit 0, no timeout and a parsable result.
- transcript.json: the existing F,b,zstar,tau values as direct JSON lists or
  scalar, and if extraction passes the existing x0, selected polar point,
  initializer potentials, numerator, selected squared radius and score.
  This repeats already calculated quantities; it performs no additional solve.
- SUMMARY.md: a text snapshot of the numerical result before the final export
  completeness gate. The final result.json and broker receipt govern that gate.
- ERROR.json is saved on an uncaught child exception when the deadline permits.

No numeric residual is clipped. The extraction guard is finite tau>1e-7 and
tau>100*abs(squared-cone defect). A selected polar point is never labeled the
closest one from numerical output. The true closest distance remains numerically
uncomputed, including when the symbolic calibration has a known exact formula.

The stdlib broker writes budget.json, registration.jsonl, PREFLIGHT_HASH_RECEIPT,
per-job receipts and CLOSED.json. Each of four slots is charged 20 seconds
before launch. Both calibration gates are mandatory; a failure retires every
unused slot. Source edits stop at FREEZE.json. Later closeout may read saved text
and hash bytes, but may not load numerical arrays or launch another calculation.
