## 2. The aggregate identity

Let B_C be the B contribution of C alone. Exact zero divergence gives

    z^T B_C z = -sum_(j outside Lblock,i in Lblock) C_ji (H-t_i).

One way to derive it is to set every formal gradient on Lblock equal to a common vector and every other gradient to zero. Lg has coefficient t_i inside Lblock and H outside it. The internal directed terms cancel by the zero-divergence identity, leaving precisely the displayed boundary sum.

At the root bridge,

    (B_C)_kk=sum_(i<k)C_ki-(R-1)sum_(j>k)C_kj.

The actual final step within H_(m-1) is b, so H-t_i>=a for every i<k. Therefore

    z^T B_C z+a(B_C)_kk <=0.

The base terminal fan has z^T B0 z=sum_(i<k)mu_i t_i and (B0)_kk=u. Consequently every matrix in the class satisfies

    z^T K z+a K_kk
    <=sum_(i<k)mu_i t_i+a u-(A^2+a u^2)/(4q).

There is no terminal-gradient penalty in these two tests because neither z nor e_k includes the final query l.

    z^T B z+a B_kk

    sum_(i<k)(H-t_i)(mu_i-lambda_(l,i))_+ >H/150,
