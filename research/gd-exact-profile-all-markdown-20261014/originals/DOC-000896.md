# Frozen output schema

All mathematical content is produced inside a charged child. Coordinates of
the full gradient matrix are (g0,...,gn,p); the independent original matrix
uses (x0,g0,...,gn,p); the quotient uses (g0,...,g_(n-1),p). Edge lists order
all physical edges first and all i->p edges last. Original lambda and mu use
that same order. Every absent edge has weight zero by topology, not rounding.

input_arrays.npz: actual h,t,M, physical/auxiliary edges, full base and edge
coefficient tensors, literal original-row base and lambda-scaled tensors,
all divergence/contact coefficient matrices and right sides, quotient index
map, E and quotient-to-full difference map. Fixture differences are included.

program_data.npz: canonical conic A in CSC, b,c, any P in CSC, with cone
dimensions in solver_data.json. There is exactly one problem.solve call.

arrays.npz: all input arrays plus raw mu, original lambda, w, w/2, full mu
and lambda tables, gamma, full P, independent original matrix, Rred, original
gradient-block Rred, margin slack, full quotient identity defect and common
gradient null defect; every signed divergence/contact equality residual;
every nonnegativity residual -mu; signed PSD spectral residuals -eigenvalues,
raw eigenvalues for full P, Rred and margin slack; source-to-literal differences;
all CVXPY primal and dual values; canonical solver x,s,z; stationarity and
complementarity records and dual PSD eigenvalues when a solution is returned.

solver_data.json: software versions, fixed options, status, solve count,
primal variables, dual values for every original constraint, native solution
x,s,z,status,obj_val,obj_val_dual,solve_time,iterations,r_prim,r_dual and solver
statistics. An accessor failure is explicit and makes exports incomplete.

transcript.json: actual inputs and edges as lists, mu/lambda (edge lists and
full tables), absorption w and w/2, gamma, signed residual lists, raw spectra,
all original and quotient solved coefficient matrices and concise diagnostic
values. This enables text-only readback without post-close array loading.

result.json: solver status and gamma, strict calibration checks and reasons,
solver and export completeness, all diagnostic scalars. Production calibration
fields are null. Every numerical finding is UNVERIFIED DISCOVERY.

All signs are retained. Equality residuals are left minus right. The PSD
residual list is minus the eigenvalue list; a positive entry is a violation.
For nonnegative mu the signed residual is -mu. Only maxima used in numerical
gate summaries may use max(0, max(-mu)); raw residuals are never clipped.
The gamma is a matrix margin and has no W normalization or witness meaning.

Broker-owned PRECHARGE/receipt JSON, stdout/stderr and byte hashes document
the full external process group and deadline. The broker imports only stdlib
and performs no mathematical operations. It requires complete successful
children and both unchanged calibration gates before production. Native
registration occurs once before FREEZE; numerical registration and CLOSED
receipts retire every unused slot without renewal.
