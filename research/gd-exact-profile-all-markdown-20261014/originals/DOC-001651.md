# Tree embedding as a possible reserve-payment tool

Primary-source method lookup, October8. Contextual lead only; no imported Danus fact, matched GD theorem, mathematical program or verification request.

Arcozzi, Holmes, Mozolyako and Volberg, [Bellman Function Sitting on a Tree](https://academic.oup.com/imrn/article/2021/16/12037/5610523), Section1.1, Theorem1.3, gives a Carleson embedding on a dyadic tree with an explicit factor4. In finite-tree notation, let mu_v>=0 and let T_v be the descendants of v including v. A rescaling of the stated condition is

    sum_(v in T_u) t_v [mu(T_v)]^2 <= C mu(T_u),  for every u,

with t_v>=0. The conclusion is

    sum_v t_v [sum_(w in T_v) mu_w y_w]^2 <= 4 C sum_w mu_w y_w^2.

The paper proves its tree inequality using the Bellman majorant4(F-f^2/(v+A)); it also distinguishes the tree setting from the usual martingale setting. The relevant displayed hypotheses and Section1 proof setup were read. This source is an existing theorem, not a newly established research result.
