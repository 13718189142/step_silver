# Variable-step dense history certificate: a root-derived sufficient interface

JOINT UNVERIFIED. Manual analytical derivation on2026-10-08 after explicit human continuation. No mathematical program, numerical data or formal verification. This is a sufficient family to investigate, not a completed all-depth upper bound.

Motivation, not a premise: Section4 of [Chikhi, Last-Iterate Performance of Gradient Descent and Relaxed Proximal Point via s-Composability](https://arxiv.org/html/2609.13765) uses two monotone sequences to generate a dense interpolation certificate for a particular constant schedule. The construction below varies every physical step and permits diagonal slack. Its applicability to our hierarchy remains entirely to be proved.

## 1. A quantitatively sufficient terminal penalty

Normalize L=1. Fix h_i>1, i=0,...,n-1, S=sum h_i, and an actual smooth convex GD history x_(i+1)=x_i-h_i g_i. Let x_star be any minimizer, R=||x0-x_star||. For a scalar Gamma define

    H_Gamma =
      2 sum_(i<n) h_i(f_i-f_n)
      +sum_(i<n)h_i(1-h_i)||g_i||^2
      -Gamma||g_n||^2.

If H_Gamma>=0 for every actual history, telescoping squared distances and using
<g_i,x_i-x_star>>=f_i-f_star+||g_i||^2/2 gives

    R^2 >= ||x_n-x_star||^2+2S(f_n-f_star)+Gamma||g_n||^2.

Write delta=f_n-f_star. If g_n=0 then delta=0. Otherwise the terminal interpolation inequality gives

    ||x_n-x_star||^2 >= (delta+||g_n||^2/2)^2/||g_n||^2.

For Gamma+1/4>=0, arithmetic-geometric mean therefore gives

    R^2 >= [2S+1+2 sqrt(Gamma+1/4)] delta,
    W_n(h) <= 1/[S+1/2+sqrt(Gamma+1/4)].

Thus a sufficient terminal penalty for the desired17/16 bound is

    Gamma >= (225/289)(S+1/2)^2-1/4.                (T)

This implication is full-function-class and uses the original selected-minimum radius. It does not assert the history inequality is true.

## 2. Dense nonnegative multipliers

Use the POSITIVE interpolation orientation

    Q_ij=2(f_i-f_j)-2<g_j,x_i-x_j>-||g_i-g_j||^2 >=0.

These are all distinct physical/terminal pairs0,...,n. Set r_i=h_i-1 fori<n; r_n=0 is bookkeeping only, not a final step. Choose

    A_-1=0 < A_0 <= ... <= A_(n-1),
    D_1 >= ... >= D_n >= D_(n+1)=0,

and define, for0<=a<b<=n,

    lambda_ab=(A_a-A_(a-1))(D_b+r_b D_(b+1)),
    lambda_ba=(A_(a-1)+r_a A_a)(D_b-D_(b+1)).

All multipliers are nonnegative. A_a is only needed for a<n. Multiplying every A by a positive constant and dividing every D by the same constant changes no lambda.

For a<b the coefficient of<g_a,g_b>, divided by2, is

    lambda_ab+lambda_ba
       -h_a sum_(i<=a)lambda_ib
       +h_b sum_(i>b)lambda_ia.

The last sum is empty for b=n, so no h_n is used. The two partial sums are

    A_a(D_b+r_b D_(b+1)),
    (A_(a-1)+r_a A_a)D_(b+1).

Substitution cancels the mixed coefficient identically for arbitrary physical steps, using h_i=1+r_i. No PSD estimate is used for this cancellation.

## 3. Exact remaining scalar requirements

Let T_k=sum_(i<k)h_i, T_n=S, and define the cut flow

    F_k =
      A_k [D_(k+1)+sum_(b=k+2)^n h_(b-1)D_b]
      -D_(k+1)[r_k A_k+sum_(a<k)h_a A_a],
      0<=k<n.

Require F_k=T_(k+1). This says out_i(lambda)-in_i(lambda)=h_i fori<n and -S for terminaln, giving exactly the desired function-value coefficients.

Put q_0=1 and

    q_k=1+2 A_(k-1)D_k, 1<=k<=n.

At an interior physical index k the square coefficient in sum lambda Q is

    -h_k+2[r_k^2 A_kD_(k+1)-A_(k-1)D_k].

The source term with A_-1 is zero at k=0. At terminaln it is S+1-q_n. Hence, under the cut equations, the COMPLETE identity is

    H_Gamma =
      sum_(i!=j)lambda_ij Q_ij
      +sum_(k<n)[q_k-r_k^2 q_(k+1)]||g_k||^2
      +[q_n-1-S-Gamma]||g_n||^2.                 (I)

Sufficient scalar inequalities are

    q_k >= r_k^2 q_(k+1) for every physical k,
    q_n >= 1+S+Gamma,

together with monotone nonnegative A,D and every cut equation. With(T), these would certify the needed full-W bound. They are currently UNSOLVED for the actual hierarchy.

For an independent sign check only: at n=1, A0=1, the cut forces D1=h/(2-h); the physical residual is nonnegative iff1<h<=sqrt2. Terminal Gamma can be at most h^2/(2-h). This restricted family does not capture all one-step objective-optimal certificates. Do not infer necessity for the full PEP cone.
