Affine-height polytope Moreau envelopes represent the full finite-word gradient-descent supremum.

All spaces, norms, and inner products below are finite-dimensional and Euclidean. For every integer n>=0, every finite nonnegative word h=(h_0,...,h_(n-1)), and every L>0, define W_n(h) as the supremum of
    2(f(x_n)-f(x_star))/(L||x_0-x_star||^2)
over every convex differentiable f:R^d->R with gradient Lipschitz constant at most L and an attained minimum, every selected minimizer x_star, and every x_0!=x_star, where
    x_(i+1)=x_i-(h_i/L)grad f(x_i), 0<=i<n.
The word is fixed before the objective is selected. Empty words, zero steps, and arbitrarily large finite steps are allowed. Write R_n(h)=W_n(h)/2.

For the same n,h, define W_aff_n(h) by taking the supremum of
    2 Phi_ah(X_ah(n))/||X_ah(0)||^2
over the following choices in arbitrary positive finite dimension D. Let K_ah be a compact polytope with at most n+2 vertices, containing 0, and let lambda_ah in R^D satisfy
    <lambda_ah,Y> > 0 for every Y in K_ah with Y!=0.
The degenerate polytope K_ah={0} is allowed. Define the single global objective
    Phi_ah(X)=min_(Y in K_ah){<lambda_ah,Y>+||X-Y||^2/2}.
Choose X_ah(0)!=0 with <lambda_ah,X_ah(0)> = 0, and run the actual updates
    X_ah(i+1)=X_ah(i)-h_i grad Phi_ah(X_ah(i)), 0<=i<n.

Then every such Phi_ah is everywhere finite, convex, differentiable with gradient Lipschitz constant at most 1, and has minimum value 0 and complete minimum set {0}. In particular the denominator in its payoff is its true squared initial distance to the entire minimum set. For every finite n and nonnegative h,
    W_aff_n(h)=W_n(h).

More precisely, the following constructive assertion holds. Let f:R^d->R be mu-strongly convex and ell-smooth, with mu>0 and 0<ell<1, minimum f(0)=0, and x_0!=0. Strong convexity means
    f(v)>=f(u)+<grad f(u),v-u>+(mu/2)||v-u||^2
for all u,v; ell-smooth means the gradient is ell-Lipschitz. Run the same word with advertised smoothness 1, so x_(i+1)=x_i-h_i grad f(x_i). For all i=0,...,n, including the terminal sample, put
    g_i=grad f(x_i), v_ah(i)=f(x_i),
    y_ah(i)=x_i-g_i, delta_ah(i)=v_ah(i)-||g_i||^2/2.
Use an extra optimum label star with x_star=g_star=y_ah(star)=0 and v_ah(star)=delta_ah(star)=0. Define
    gamma_ah=(1/ell-1)/2,
    z_ah(0)=0,
    z_ah(i+1)=(1-h_i)z_ah(i)+h_i delta_ah(i), 0<=i<n,
    e_ah(i)=z_ah(i)-delta_ah(i), 0<=i<=n.
For a real number t let [t]_+=max(t,0). Define the finite scalar
    M_ah=max { [e_ah(i)(delta_ah(j)-delta_ah(i))]_+
                    /(gamma_ah||g_i-g_j||^2):
               0<=i<=n, j in {star,0,...,n}, g_i!=g_j },
where the maximum of an empty set is defined to be zero. For every finite B_ah>0 with B_ah^2>=max(1,2M_ah), put, in R^(d+1),
    lambda_ah=(0,B_ah),
    Y_ah(i)=(y_ah(i),delta_ah(i)/B_ah),
    X_ah(i)=(x_i,z_ah(i)/B_ah),
    G_ah(i)=(g_i,e_ah(i)/B_ah), 0<=i<=n,
    Y_ah(star)=0,
    K_ah=conv{0,Y_ah(0),...,Y_ah(n)}.
Here conv denotes convex hull and the zero in lambda_ah is the horizontal zero vector in R^d. This K_ah, lambda_ah, and X_ah(0) belong to the stated restricted class. Writing P_ah for Euclidean projection onto K_ah, all the following hold simultaneously:
    P_ah(X_ah(i)-lambda_ah)=Y_ah(i),
    grad Phi_ah(X_ah(i))=G_ah(i),
    Phi_ah(X_ah(i))=v_ah(i)+e_ah(i)^2/(2B_ah^2), 0<=i<=n,
    X_ah(i+1)=X_ah(i)-h_i G_ah(i), 0<=i<n,
    <lambda_ah,X_ah(0)> = 0,
    dist(X_ah(0),argmin Phi_ah)^2=||x_0||^2,
    2Phi_ah(X_ah(n))/||X_ah(0)||^2
       =2f(x_n)/||x_0||^2+e_ah(n)^2/(B_ah^2||x_0||^2).
Thus the horizontal trajectory is exact in one extra coordinate and the terminal objective correction is nonnegative and is of order B_ah^(-2) for this fixed source and word.

For an arbitrary original source, the equality of suprema uses translation of its selected minimizer to zero, division of the objective by L, and then the regularizations
    f_eps(x)=(1-2epsilon)f(x)+(epsilon/2)||x||^2, 0<epsilon<1/2.
For each fixed source and finite word these are epsilon-strongly convex and (1-epsilon)-smooth with unique minimum at zero; their actual terminal values converge to that of the translated, normalized original source. The lift is chosen separately for each epsilon. This covers arbitrary selected original minima, including nonunique original minimum sets.

The assertion includes repeated samples, equal source gradients, zero source gradients, and all normals involving the original terminal. It asserts neither a quantitative convergence rate or benchmark comparison, nor a uniform approximation across words or horizons, attainment of either supremum, simplex geometry, a uniform bound on B_ah, or an adversary selectable from the schedule alone without a source trajectory.
