# Finite-seed metric boundary in the literature

Primary-source scope screen,2026-09-27. Context only, no imported Danus fact.

[Grimmer,Shu,Wang,arXiv2410.16249v2](https://arxiv.org/html/2410.16249v2)
defines f-composability using final objective under an initial-distance
bound, together with a sum/product equality. Its discussion of schedules
numerically optimized through length25 concerns that objective. Conjecture1
is a minimax conjecture, not a general proof. Its g-composable minimax
discussion uses a gradient criterion with a different initial measure;
the definitions must be checked before any transfer. These passages do
not supply a matched theorem deciding the present four-step intrinsic
primitive-capacity interface.

[Das Gupta,Van Parys,Ryu,BnB-PEP](https://ir.cwi.nl/pub/34900/34900.pdf)
Section6.1 concerns momentum-free smooth-convex function-value reduction.
Other gradient-norm applications use different assumptions/algorithm
classes. The methodology suggests full nonconvex method/certificate search,
but the checked paper does not itself provide an exact certificate for
our specific primitive threshold. No secondary summary is treated as a
proof of this finite problem or the original asymptotic goal.

This was a bounded scope check, not a claim that no relevant theorem exists
anywhere. No posted solution to the exact user benchmark was sought.

source screen.
