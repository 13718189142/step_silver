# Complex polynomial transcripts and interpolation cycles

Status: exploratory derivation, not a verifier-accepted fact. This does not resolve the exact Zhang--Jiang profile comparison. Normalize L=1, x_*=0, f_*=0 and ||x_0||=1.

## 1. Counterexample to local curvature lifting

Take h_0=1 and x_0=(1,0), g_0=(1/2,1/2), x_1=(1/2,-1/2), g_1=(1/2,0), x_*=g_*=0.
The GD equation holds. Every pair satisfies <g_i-g_j,x_i-x_j>=||g_i-g_j||^2.
Also g_0=P_0 x_0 and g_1=P_1 x_1, where P_0 projects onto span((1,1)) and P_1 projects onto the first axis. Both are symmetric PSD contractions.
Nevertheless, smooth-convex interpolation against the optimum forces f_0=1/4 and f_1=1/8. The inequality from point 1 to point 0 requires f_0-f_1>=3/8, a contradiction. The three-cycle * -> 1 -> 0 -> * has positive total lower-increment weight 1/4.

## 2. The schedule-specific algebraic object

Fix n>=1 and any real nonnegative schedule h_0,...,h_{n-1}. Define

    P_0(z)=1, P_t(z)=product_{s=0}^{t-1}(1-h_s z), 1<=t<=n.

For z=a+ib identify C with R^2 and set x_t=P_t(z), g_t=z P_t(z), x_*=g_*=0.
Multiplication by z is the real matrix A_z=[[a,-b],[b,a]]. It need not be a gradient map globally. Only the finite sampled transcript is proposed for interpolation. GD holds exactly, with the original ordered real schedule. Put c=a-a^2-b^2.

For every ordered pair in I={*,0,...,n}, define the edge weight from j to i by

    q_ij = <g_j,x_i-x_j> + (1/2)||g_i-g_j||^2
         = (a/2)(|x_i|^2-|x_j|^2)
           + b Im(conj(x_j) x_i) - (c/2)|x_i-x_j|^2.

For a directed simple cycle C=(i_0,...,i_{r-1},i_r=i_0), put

    A_C = sum_{k=0}^{r-1} Im(conj(x_{i_k}) x_{i_{k+1}}),
    E_C = sum_{k=0}^{r-1} |x_{i_{k+1}}-x_{i_k}|^2.

The sum of q weights on C is b A_C-c E_C/2. Both orientations occur.
The finite data admit smooth-convex interpolating values if and only if

    c E_C >= 2 |b A_C| for every simple cycle C.                     (C)

Write D_h for this set of complex parameters. It is a closed semialgebraic set whose defining polynomials are obtained from all prefix polynomials. The two-cycle between * and 0 forces c>=0, so D_h is in the compact disk (a-1/2)^2+b^2<=1/4. No restriction to rational or algebraic schedules occurs.

Here is the value-selection argument. Give the complete directed graph on I weights q_ij on j->i. Under (C), every cycle has nonpositive weight. Let ell_i be the maximum weight of a path i->*, permitting the empty path at *. Removing repeated nonpositive cycles cannot decrease weight, so the maximum is over finitely many simple paths; ell_*=0. Set F_i=-ell_i. Appending a maximum path i->* to edge j->i, then removing cycles, gives ell_j>=q_ij+ell_i. Hence F_i-F_j>=q_ij.
Conversely, summing feasible differences along each path i->* yields F_i<=-ell_i. Thus these values simultaneously maximize every F_i for the fixed transcript.

A constructive interpolant is f=H^*, where

    H(g)=max_i { <g_i,x_i>-F_i + <x_i,g-g_i>
                 +(1/2)||g-g_i||^2 }.

The pair inequalities imply that the i-th quadratic is active at g_i, that H(g_i)=<g_i,x_i>-F_i, and that x_i belongs to the subdifferential of H at g_i. The finite function H is 1-strongly convex. Its conjugate is finite, convex, differentiable and 1-smooth. Conjugacy gives f(x_i)=F_i and grad f(x_i)=g_i. The sample at * gives f(0)=0 and grad f(0)=0, so 0 is a global minimizer. This is the constructive argument of Taylor--Hendrickx--Glineur, arXiv:1502.05666, Theorem 4, Corollary 1 and Remark 2; the exact downloaded statement and proof were read.

Thus each z in D_h yields a legal witness

    B_h(z)=2 F_n=-2 ell_n <= W_n(h).                                   (B)

The optimum-pair inequalities give

    |z|^2 |P_n(z)|^2 <= B_h(z)
                    <= (2a-|z|^2)|P_n(z)|^2.                        (V)

All prefix information enters D_h and ell_n; the terminal polynomial alone cannot determine these cycle constraints.

## 3. A universal legal lens

Put N=n+2, theta=pi/N. The schedule-independent set

    K_n={a+ib : a-a^2-b^2 >= |b| cot(theta)}

lies in D_h for every schedule. For any complex r-gon v_j,

    |sum_j Im(conj(v_j) v_{j+1})|
      <= (1/2) cot(pi/r) sum_j |v_{j+1}-v_j|^2.                     (A)

Proof without simplicity or convexity of the polygon: write
v_j=sum_{k=0}^{r-1} d_k exp(2 pi i k j/r). Orthogonality makes the area expression r sum_k |d_k|^2 sin(2 pi k/r), and the energy 4r sum_k |d_k|^2 sin^2(pi k/r). The zero mode contributes nothing. For each other mode the absolute ratio is (1/2)|cot(pi k/r)|, at most (1/2)cot(pi/r). Since r<=N, (C) follows.

The finite cyclic monotonicity viewpoint is also discussed by Bartz, Bauschke, Borwein, Reich and Wang, Fitzpatrick functions, cyclic monotonicity and Rockafellar's antiderivative (2007), Example 4.6. That exact paper and its Fourier/circulant proof were downloaded and read. Inequality (A) is derived here instead of invoked as a black box.

## 4. Quantitative obstruction: the universal lens is too weak

K_n supplies legal nonquadratic witnesses but cannot prove the silver exponent on its own. An explicit Chebyshev schedule defeats this mechanism.

Let m=2n+1. The polynomial

    p(z)=(-1)^n T_m(sqrt(z))/(m sqrt(z))

has degree n, p(0)=1 and roots

    lambda_k=cos^2((2k-1) pi/(2m)), k=1,...,n.

It equals product_k(1-h_k z) for positive h_k=1/lambda_k, in any order. Here T_m(cos u)=cos(mu). Oddness makes the quotient a polynomial with a well-defined value at zero.

For n>=2 set t=tan(pi/(n+2)) and u=asinh(t/2). For z=a+ib in K_n, 0<=a<=1 and |b|<=t a(1-a). With s=a(1-a),

    (2a-1)^2/cosh^2(u) + (2b)^2/sinh^2(u)
      <= 1-4s+16s^2 <= 1.

Thus K_n is in the filled ellipse with foci 0,1 parametrized by z=(1+cos(w))/2 with |Im w|<=u. A square root is cos(w/2), so

    |z| |p(z)|^2 = |T_m(sqrt(z))|^2/m^2
                 <= cosh^2(m u/2)/m^2.

Since u<=t/2 and tan(theta)<=4 theta/pi on [0,pi/4],
m u/2<=m/(n+2)<2. From (V), every legal interpolating function for every z in K_n has terminal gap

    2 F_n <= 2 cosh^2(2)/(2n+1)^2.                                  (O)

This is an upper bound only for the restricted witness family. It is not a full-class upper bound on the Chebyshev schedule.

Adding the canonical flat-region Huber witness does not repair this rate loss.
Differentiating the Chebyshev differential equation
(1-x^2)T_m''-x T_m'+m^2 T_m=0 at zero gives
T_m'''(0)=-(m^2-1)T_m'(0), with T_m'(0)=(-1)^n m. Consequently

    sum_k h_k=-p'(0)=(m^2-1)/6=2n(n+1)/3.

For S=sum h, the canonical Huber function is f_delta(x)=x^2/2 if |x|<=delta and delta|x|-delta^2/2 otherwise, with delta=1/(2S+1).
Starting at x_0=1, GD stays in its positive affine-gradient region: all prefixes have x_t>=x_n=(S+1)/(2S+1)>=delta. Its normalized terminal gap is exactly 1/(2S+1), also O(n^-2).

The target benchmark has order n^-rho with rho=log_2(1+sqrt(2))<2.
Thus the guaranteed-lens-plus-canonical-Huber mechanism loses a factor tending to zero relative to the target on these schedules. This kills the universal-lens simplification, not D_h and not the original minimax conjecture.

## 5. Remaining branch decision

The full D_h construction gives a concrete legal candidate mechanism. No uniform estimate of sup_{z in D_h} B_h(z) matching S_bullet(n) is proved. Merely postulating that estimate is a theorem-strength blocked comparison.
A reopening needs a distinct structural estimate on prefix-polynomial point clouds or a stronger moment class; replacing D_h by K_n is quantitatively ruled out by (O).
