## Model, normalization and analytical interface

The conic program is identical to the preceding closed packet. The only
scientific/code change is the arithmetic used in fixed calibration identity
checks, described below; CHILD_SOURCE_CHANGE.diff records that change.

For a finite word h=(h0,...,h_(n-1)), define S=sum h, M=1+2S,
t_i=1+sum_(k<i)h_k and t_p=M. Physical gradients are g0,...,gn and the
auxiliary coordinate p remains free. The original normals have orientation
Q_ij=<X_j-G_j,G_i-G_j><=0. With a_j=1 for physical j and a_p=1/M,
mu_ij=a_j lambda_ij, so physical lambda=mu and absorption lambda=M mu.
Allowed edges have nonnegative independent mu. Every physical node has an
absorption edge i->p, with no prescribed absorption pattern. There are no
p-out, star or diagonal edges.

All original divergence and contact equations are imposed:

    out_i-in_i=2(1_(i=n)-1_(i=p)),
    sum_j mu_ij(t_j-t_i)=2h_i for i<n, and 0 for i=n,p.

The complete non-diagonal residual is

    R=2<g_n,sum_(k<n)h_k g_k>+||g_n||^2-M||p||^2
      +sum_ij mu_ij <B_jG,G_j-G_i>,
    B_iG=g_i+sum_(k<i)h_k g_k, B_pG=Mp.

DERIVATION.md derives the x0 cancellation, the exact common-gradient null
direction under the contact equations, and the equivalence of full PSD to
PSD after fixing g_n=0. The quotient retains coordinates
(g0,...,g_(n-1),p); it does not replace p by an optimized gradient mixture.
The objective maximizes gamma with Rred-gamma E PSD and
E=diag(1,...,1,0). Gamma is a matrix margin, not the normalized objective
error W. The original problem continues to use W=2R for objective errors;
that R is unrelated to the certificate polynomial named R here.

The tree contains both directions of every edge from i<n to
i+2^nu2(i+1). The complete topology contains all physical ordered pairs
i!=j. The latter can redistribute physical flow beyond the tree while
preserving exactly the same absorption freedoms and full matrix test.
