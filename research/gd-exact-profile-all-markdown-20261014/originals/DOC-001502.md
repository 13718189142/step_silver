# Frozen output schema

All numerical arrays, imports, constructions, checks and exports are generated only inside the precharged 20-second child process group. No postclosure array reload or reanalysis is permitted.

Per case:

- `source_frame.json`, `input_arrays.npz`: full word (production), literal prefix, enclosing parameters, `a_last,D`, index labels including star, the full formal basis, every point/gradient/value coefficient, every distinct ordered original row, its Gram and value coefficients, and objective coefficients. No source-weight/support/rank restriction.
- `exact_fixtures.json`: rational coefficient/value-flow and attainment differences for both independent exact calibration identities; raw floating differences kept separately. Production records nonapplicability.
- `program_data.npz`, `canonical_data.json`: full canonical CLARABEL CSC matrices, vectors, cone dimensions and shapes generated before the one solve.
- `arrays.npz`, `transcript.json`: raw full Gram, all f including the zero star value, every signed original row and independent direct row evaluation, radius residual, raw Gram eigenvalues, the unscaled primal objective, every original dual multiplier, dual radius multiplier, dual PSD multiplier, original dual polynomial, value and full matrix stationarity residuals, dual eigenvalues, nonnegativity residuals, complementarity, and signed primal-dual gaps. Numerical values are not clipped or repaired. Optional coordinate extraction is deliberately skipped, with an explicit reason; negative raw eigenvalues are preserved.
- `solver_data.json`: CVXPY/CLARABEL and package versions, fixed options, reported status and value, warning messages, solver statistics, all native x/s/z vectors and native residual/objective information, all canonical constraint duals. Native data comes from the single completed solve.
- `result.json`: compact saved-text summary, raw numerical metrics, calibration checks and failure reasons, production `D*V` and `D*q_dual` versus `17/16`, export completeness and interpretation boundaries.
- `stdout.txt`, `stderr.txt`: process and solver output; `failure.json` on an exception if writeable before the external deadline.
- `PRECHARGE.json`, `PREFLIGHT_HASH_RECEIPT.json`, `receipt.json`: frozen-byte verification, full 20-second precharge before launch, actual external time, process-group deadline/termination, exit/export/calibration status and byte hashes.

Top-level preparation produces separate immutable host/container snapshots, native registration exactly once, allocated/registered budget snapshots, provenance, freeze and execution-container verification. The broker is administrative standard-library code. It updates budget/registration, refuses retries, gates production on both calibrations, retires unused credit, and writes `CLOSED.json`. After closure, only saved-text transcription, reports, hashes and accounting are allowed. All claims remain UNVERIFIED DISCOVERY, original target OPEN.
