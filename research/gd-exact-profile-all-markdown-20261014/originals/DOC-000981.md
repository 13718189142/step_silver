## 6. A complete restricted-row transcript at every physical index

This construction tests ALL coefficient choices on E80, not merely the
two explicit laws. It also shows why full boundary metrics cannot fix
missing rows by themselves. Define

    Rreset=a*c^2/Mleaf=beta*c/Mleaf,
    sbit(k)=number of ones in the binary expansion of integer k>=0,
    v80_k=(-1)^k*Rreset^k*c^(-sbit(k))/Mleaf,
                                      0<=k<Nleaf.                   (6.1)

Here sbit(0)=0. This is a closed formula, never an executed recurrence.
If r=v2(k+1), binary carry gives sbit(k+1)-sbit(k)=1-r. Therefore

    v80_(k+1)/v80_k=-Rreset*c^(r-1)
               =-a*c^(r+1)/Mleaf=-d_(1+r)/Mleaf.        (6.2)

For each leaf index2k prescribe the REAL scalar jets

    x_(2k)=Mleaf*v80_k,  g_(2k)=v80_k,
    f_(2k)=(b+1/2)*v80_k^2.

For each queried checkpoint2k+1<n prescribe

    x_(2k+1)=v80_k, g_(2k+1)=v80_k, f_(2k+1)=v80_k^2/2.     (6.3)

The leaf update gives Mleaf*v80_k-b*v80_k=v80_k. The following bridge update
gives v80_k-(1+d_(1+v2(k+1)))*v80_k=Mleaf*v80_(k+1), by (6.2).
Thus these are the EXACT original physical GD relations. In particular
x_0=Mleaf*v80_0=1; there is no freedom to change the radius in the proof.

After the final physical leaf the actual terminal position is

    t80=x_n=v80_(Nleaf-1)
       =-Rreset^(Nleaf-1)/(Mleaf*c^(m-1)).               (6.4)

The sign is negative because Nleaf-1 is odd. Its binary expansion has
m-1 ones. This gives (6.4) directly from (6.1), including the last leaf.
Complete that terminal with

    u80term=g_n=2t80/(b+2),
    f_n=t80^2/(b+2),
    x_star=g_star=f_star=0.                            (6.5)

There is no assertion of a single function interpolating these jets.
Their scalar Gram matrix is PSD because all vectors are literal scalars.

We now check EVERY row type in E80, including orientations and the
terminal; no numerical check or finite-horizon inference is used.

    Q_(leaf,star)=0, Q_(star,leaf)=-b*v^2.

    Q_(leaf(v),check(w))=0,

These are ALL adjacent prefix incidences, so all of them satisfy Q<=0.

    Q_(n,leaf(v))=-b*(v-u/2)^2<=0.                    (6.8)

Indeed its expression is f_n-u*t80+u^2/2+b*u*v-b*v^2.
The remaining incoming optimum-terminal row is
Q_(star,n)=-f_n+u^2/2=-b*u^2/4<=0.
This checks all row types(a)--(e), every optimum row, every leaf,
every checkpoint, and the actual unqueried terminal.
