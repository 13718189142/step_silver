# Random-threshold Huber obstruction — unverified candidate

UNVERIFIED COMPLETE FAMILY CALCULATION. Normalize L=1 and initial distance1. For tau>0 define H_tau(x)=x^2/2 for |x|<=tau and tau|x|-tau^2/2 otherwise, minimized at0. Its derivative clips x to [-tau,tau], hence is nondecreasing and1-Lipschitz, so the function is a legal smooth convex instance. It is even, so x_0=1 suffices for both normalized initial signs.

For a>=0 define M_a(z)=z-a clip(z,-1,1). Let D_n be the composition of these maps in chronological order 2^{n-1},2^{n-2},...,1, and put S_n=2^n-1. Claim D_n(z)=sign(z)(|z|-S_n)_+ for every real z. For n=1, M_1(z) has exactly this form. Suppose the identity holds at n-1 and set A=2^{n-1}, so S_{n-1}=A-1. The maps are odd, so take z>=0. If 0<=z<=1, M_A(z)=(1-A)z lies in[-(A-1),0]. If 1<=z<=2A-1, M_A(z)=z-A lies in[-(A-1),A-1]. The induction hypothesis sends both ranges to0. If z>2A-1, then M_A(z)=z-A>A-1, so D_{n-1}(M_A(z))=z-A-(A-1)=z-S_n. Oddness treats z<0. This proves the exact identity.

For the GD schedule d^(n)=(2^{n-1},...,1), rescale z=x/tau. The identity gives x_n=(1-tau S_n)_+. Write S=S_n. If tau>=1/S then x_n=0. For 0<tau<=1/(S+1), the endpoint is in the affine Huber region and
2H_tau(x_n)=2tau-(2S+1)tau^2<=1/(2S+1),
with equality at tau=1/(2S+1). For 1/(S+1)<=tau<=1/S, the endpoint lies in the quadratic region and
2H_tau(x_n)=(1-S tau)^2<=1/(S+1)^2<=1/(2S+1).
Consequently
sup_{tau>0} 2H_tau(x_n)=1/(2^{n+1}-1).
This holds for every n>=1. Thus for every law on tau (even one selected after seeing the entire binary schedule), its expected normalized error is at most1/(2^{n+1}-1). No minimax interchange is used: the deterministic pointwise upper bound is integrated.

Translations and orthogonal embeddings preserve the scalar trajectory and the normalization. Radial Hubers H_tau(||x-x_star||) have collinear GD trajectories, so the same identity holds for any starting displacement; after scaling its length to1 the parameter is tau/||x0-x_star||. A finite direct sum of these full-curvature scalar/radial components has a normalized error equal to the initial-squared-distance weighted average of component normalized errors. Hence it has the same cap; any distribution over these direct sums does too.

This is a limitation of full-curvature symmetric Huber thresholds, embeddings, and separable direct sums. It does not include arbitrary lower core curvatures, asymmetric tails, sums of overlapping ridge Hubers, or general convex functions. The schedule d^(n) is not claimed to have small unrestricted W_n; other legal functions can make it unstable. In particular this is not a negative answer to P.
