# Literature lead: terminal storage for retained certificate history

Source screen by main, 2026-09-26. This is a bounded research lead, not a theorem import or a correctness judgment. The papers were opened as standard methodology sources, not searched as posted solutions to the exact benchmark. The selected current shared files and SOURCE_NOTES.md had no matches for the searched IQC/OZF terms; that is not an exhaustive novelty claim.

## Primary sources and checked boundaries

[Scherer (2022), arXiv:2207.01363](https://arxiv.org/pdf/2207.01363), especially Theorem 11, equations (25), (30)--(35), Appendix A.5 and section 7. The paper constructs discrete-time constraints with a quadratic terminal term for convex subgradients, using causal and anticausal filters. A finite doubly hyperdominant matrix condition certifies the construction. The displayed filter starts at zero. The stability theorem also needs a coupled storage positivity condition. Its proposed losslessness relative to a more general multiplier test is a conjecture, not a theorem. This supplies a candidate certificate parametrization, not the project's objective-gap constant or an unrestricted converse.

[Fazlyab--Ribeiro--Morari--Preciado, arXiv:1705.03615](https://arxiv.org/pdf/1705.03615), Theorem 3.1 and equations (3.2), (3.5)--(3.9). The framework allows iteration-dependent algorithm matrices and a Lyapunov function containing objective gap and a quadratic state term. Its sufficient matrix conditions include common fixed-point relations, valid quadratic bounds, nonnegative nondecreasing objective weights and PSD storage matrices. The upper guarantee depends on finding those certificates. It does not establish their completeness or the exact minimax profile.

[Carrasco et al., arXiv:1812.02397](https://arxiv.org/pdf/1812.02397), introduction and Definition II.4. This multiplier-search paper treats discrete-time SISO LTI systems. Its FIR approximation/completeness statements must not be promoted to a theorem for arbitrary-dimensional, nonstationary gradient descent. It is background only, not a direct bridge.

## Main's proposed compatibility test, not a source conclusion

The current max4 candidate in research/max4_two_sided_residual_join.md has recovered ordinary ConPP after allowing aggregate-coordinate cancellations while retaining nonnegative actual interpolation coefficients. The remaining difficulty concerns independent finite residual penalties and cross-block information. This is the reason to test a joint terminal storage matrix rather than introduce an unrelated numerical search.

Keep that concrete identity as the starting object. Determine whether a short-memory storage description can retain useful cross terms missing from the two separate squared residual penalties. The required deliverable is an explicit finite-horizon identity with its actual smooth-convex interpolation multipliers and boundary state, or a precise demonstration that the parametrization merely rewrites the already studied cone. A change of vocabulary is not a new route.

At a block join the filter generally has nonzero inherited memory. It cannot be reset to zero to reuse a theorem whose hypothesis was zero initialization. Account for both boundary states and any function-value terms. The algorithm itself remains the original prescribed GD recursion; auxiliary filter states are proof quantities only, never momentum, averaging or adaptive steps. Check the original last-iterate objective normalization, not just an output-norm or stability bound.

The source conjecture is unavailable as a premise. No completeness, time-varying extension, or lossless compression is assumed. If the finite full-interpolation reduction does not provide an actual new join or a stronger exact invariant, record that result and return to the existing quantitative interface. No additional numerical evaluations or routine verifier calls are allocated.
