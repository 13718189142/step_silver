# C58 complete-PEP extension: model and scaling audit

This is numerical discovery under the one-time max3 allocation in
`max3_full_objective_extension_budget.json`. Every attempted call is
recorded before model construction; its status and elapsed time are saved
afterward. Imports are conservatively included in the measured time.
Post-solve array serialization and residual diagnostics are not solver time.
No eigenvalues or multipliers are repaired or truncated. No hidden solver
fallback or retry is performed. The public runtime invokes CLARABEL0.11.1
through CVXPY1.9.3 with one computational thread.

## Complete mathematical model

For the actual supplied schedule h of length n, take independent formal
vectors x0,g0,...,gn. Let xi=x0-sum_(t<i)h_t gt and let the optimum sample
have x_star=g_star=f_star=0. Optimize over the full symmetric Gram matrix
and all n+1 function values, with no rank or support restriction:

    maximize 2f_n,
    Gram >=0, Gram_(x0,x0)<=1,
    Q_ij=f_i-f_j+<g_i,x_j-x_i>+||g_i-g_j||^2/2<=0
          for EVERY distinct ordered pair in {star,0,...,n}.

Accepted fact1252b8823bb5a290 supplies the equivalence with the actual
smooth-convex worst case. No terminal inequality is deleted here.

In the original formal basis, let A_ij be the symmetric coefficient
matrix for the quadratic part of Q_ij, and let Fcoef have entries+1 at
i and-1 at j when these are finite. The script constructs the full sparse
arrays directly. Both star directions and every finite direction occur.

## Exact change of coordinates used for conditioning

Let M=1+sum h and D=diag(1,1/M,...,1/M). The variables in the solver are

    Ghat=Gram(x0,Mg0,...,Mgn), fhat=Mf.

The original Gram is D Ghat D. The solver constraint is M Q_ij<=0,
with coefficient matrix M D A_ij D, and it maximizes2fhat_n. This is an
invertible change of variables and a positive constraint/objective scaling.

If the solver returns raw pair multipliers lambda and raw norm multiplier
rho, the ORIGINAL pair multipliers are the same lambda and the original
dual objective is q=rho/M. The complete original coefficient matrix is

    C_orig=q e0 e0^T+sum lambda_ij A_ij.

The scaled stationarity matrix is M D C_orig D. It is compared directly
with the RAW dual multiplier of the PSD constraint. Value flow is checked
as Fcoef^T lambda-2 e_n, using the original objective. The saved data include
both scaled and original Grams, all raw pair labels/multipliers, both
objective matrices, PSD duals, function values, all original Q residuals,
all flow residuals, complementarity, eigenvalues, and scaling metadata.

## Analytic one-step calibration

For h=(1), choose multipliers lambda_(0,star)=lambda_(1,star)=
lambda_(1,0)=1 and all others zero. Their value coefficients cancel2f1.
The full coefficient identity at q=1/3 is

    (1/3)||x0||^2-2f1+Q_(0,star)+Q_(1,star)+Q_(1,0)
      =(1/3)||x0-(3/2)(g0+g1)||^2+(1/4)||g0-g1||^2.

This proves the upper bound1/3 directly. The scalar Huber function with
threshold1/3, initial point1, and step1 has g0=g1=1/3, x1=2/3 and
f1=1/6, attaining the bound. Thus the calibration target is exactly1/3.
