# Fixed extraction schema

One new job, three fixed saved cases `03_P3`, `04_P4`, `05_P5`, no solves. Every numerical operation and export occurs inside the single precharged external-20-second child group.

For each case, save under `raw/extraction/<case>/`:

- `source_frame.json`: byte-preserved old authority for every original row label and coefficient, literal word, prefix and formal basis. `input_source_arrays.npz` carries the same authority arrays copied without changing values.
- `extraction.json`, `extraction.npz`: raw `mu`, `nu`, their totals, the labelled division `mu/sum(mu)`, all original multipliers/row labels, `q,a,D,k`, `K_H=2+2sum k-a^2`, Huber value and signed comparisons; full `N,L,B,Kresidual`; full original polynomial and its comparison with the saved matrix; uncorrected and flow-corrected source-coordinate matrix differences; value-flow, row-sum/column-sum, stationarity, sign and eigenvalue defects; original saved Gram/eigenvalues and signed primal rows retained without repair.
- `dyadic_nodes.json`: every original node and boundary leaf, exact index mapping defined in DERIVATION, left/bridge/right raw source masses and diagnostic fractions. No label is dropped with the last update.
- `SAVED_TEXT.md`: readable parameters, full source and incoming-star profiles, node table and saved diagnostics for manual followthrough; no inference that a numerical pattern is exact.

Top-level child outputs: `SUMMARY.json`, `SAVED_TEXT.md`, `COMPLETE.json` with all export-presence flags. Preserve all tiny signed defects; do not repair, fit, threshold, project, or clip. Source Schur expressions are labelled raw diagnostics and are computed only after confirming the exact original-polynomial convention with the explicit numerical value-flow correction.

Administrative wrapper outputs: native-registration/budget snapshots, FREEZE, container hash receipts, precharge, whole-group external timing/exit/logs, raw file byte hashes and CLOSED numerical allowance. Mathematical credit becomes zero even on timeout or failure. Manual analysis from saved TEXT only is explicitly permitted after closure; no further mathematical program or raw array access. REPORT/HANDOFF close the single native invocation and identify the actual two-law count.
