## 1. The resolved class and conclusions

All spaces are finite-dimensional real Euclidean spaces. For positive
radii r_minus and r_plus, a centered asymmetric Huber function phi has
phi(0)=0 and derivative

    phi'(s)=max(-r_minus,min(s,r_plus)).

Consider one STATIC objective

    F(x)=x^T A x/2 + sum_(j=1)^r alpha_j phi_j(u_j^T x),       (1)

where A is symmetric positive semidefinite, each u_j is a unit vector,
alpha_j>0, and

    A+sum_j alpha_j u_j u_j^T <= I.                           (2)

The number r may be zero. Dimensions, directions, both radii and weights
may depend arbitrarily on the horizon. Let

    N0=ker A intersect intersection_j u_j^perp, E=N0^perp.

The additional hypothesis tested here is a background-curvature floor:

    z^T A z >= mu ||z||^2 for all z in E, 0<=mu<=1.          (3)

There is NO restriction on which ridge regions the actual queried or
terminal points visit. Hessians in different regions need not commute.
Define the actual GD iterates for a nonnegative physical word h by

    x_(i+1)=x_i-h_i grad F(x_i),
    V=2[F(x_n)-min F]/dist(x_0,argmin F)^2.                   (4)

Initial points in argmin F are omitted. All terminal gradients and values
are those of the SAME function (1).

For the ORIGINAL diagnostic words fix m>=128 and set

    sigma=1+sqrt(2), c=sigma(1+1/m), beta=1-1/m,
    a=beta/c, ell=1+a, d_j=1+a c^j,
    H_0=(), H_(j+1)=(H_j,d_j,H_j), 0<=j<m,
    h=H_m, N=2^m, n=N-1,
    S_j=sum H_j, M_j=1+S_j, K=1/(2M_m-1).                  (5)

Every child word in this proof keeps these SAME enclosing-m parameters.
The main conclusions are:

1. If mu>=mu_exact:=2/ell-1, the exact supremum of V over the whole
   class (1)--(3), with all changing regions allowed, is

       beta^(2N-2) c^(-2m).                                (6)

   The unit quadratic attains it. The result is exact over this specified
   class, not over unrestricted convex smooth objectives.

2. Put

       mu_floor=[1-1/(beta c)]/ell.                         (7)

   If mu>=mu_floor, every such run satisfies

       V <= beta^(-2)c^(-2m),
       V/K < 2/[beta^2 c^m],
       B_n V -> 0 uniformly over the class as m -> infinity. (8)

   Here B_n is the ORIGINAL Zhang--Jiang denominator of accepted
   `b98bb807d514e80d`. Both mu_floor and mu_exact tend to sqrt(2)-1,
   with mu_floor<mu_exact for every stated m. The thresholds, dimension,
   number of ridges and all other data may vary with m.

3. There is an explicit stronger necessary condition for attaining even
   the accepted same-word scalar value K. Define

       L_m=log[beta^2 c^(2m)/(2M_m-1)],
       mu_comp=[1-exp(L_m/N)/(beta c)]/ell.                 (9)

   Every run in (1)--(3) with V>=K must have mu<=mu_comp. Moreover

       1/(2m-1)<mu_comp<mu_floor,
       mu_floor-mu_comp=[exp(L_m/N)-1]/(beta c ell)>0.      (10)

4. The resolved class really contains nonlinear, noncommuting,
   repeatedly changing queried gates on ORIGINAL H_m. Section 6 gives
   one static two-dimensional function whose ridge visits are positive
   outer, negative outer, positive outer, then core at every remaining
   actual sample. Its actual gradients change sign at EVERY physical
   step, are not collinear, and have nonconstant correlations. Its true
   initial distance is exactly 1. Its payoff is nevertheless bounded by
   (6), hence is strictly weaker than K on this same word.

This supplies a precise obstruction for the newly specified curved-
background subclass. It does not exclude weak or singular backgrounds,
or arbitrary nonlinear changing-region functions. The upper envelopes
below are not claimed attainable outside the regime of (6).

## 2. Static legality, true minimizer distance and all original pairs

Every summand in (1) is nonnegative. A Huber term vanishes precisely
when its scalar argument is zero. Thus argmin F=N0 and min F=0.
Let z0 be the orthogonal projection of x0 onto N0. Translation of every
iterate by -z0 changes neither the values nor the gradients, because
A z0=0 and u_j^T z0=0 for all j. All gradients lie in E. We may work
on E with x0 in E; its squared norm is the TRUE squared distance in (4).

For any two points x,z define the scalar secant coefficient theta_j by

    phi_j'(u_j^T x)-phi_j'(u_j^T z)
                 =theta_j u_j^T(x-z), 0<=theta_j<=1.       (11)

If the arguments coincide take theta_j=0. The monotonicity and the
1-Lipschitz property of clipping prove both bounds, across any number
of region boundaries. Consequently

    grad F(x)-grad F(z)=C(x,z)(x-z),
    C(x,z)=A+sum_j alpha_j theta_j u_j u_j^T,
    mu I_E <= C(x,z)|E <= I_E.                             (12)

This proves global convexity and 1-smoothness. It also gives the actual
secant matrix used below; no matrix is independently chosen along the
trajectory. For h>=0, diagonalizing this ONE symmetric matrix yields

    ||x-z-h[grad F(x)-grad F(z)]||
       <= q_mu(h)||x-z||,
    q_mu(h)=max{|1-h mu|,|1-h|},                           (13)

for x,z in E. Taking z=0 and multiplying the true one-step bounds gives

    ||x_n|| <= ||x0|| product_(i<n) q_mu(h_i).

Smoothness at the minimizer gives 2F(x_n)<=||x_n||^2, so

    V <= product_(i<n) q_mu(h_i)^2.                        (14)

No commutativity of DIFFERENT secant matrices was used in (13)--(14).

For completeness every original ordered interpolation pair is retained.
Put f_i=F(x_i), g_i=grad F(x_i) and include x_star=g_star=f_star=0.
For a fixed i, J(z)=F(z)-<g_i,z> has its global minimum at x_i.
The 1-smooth descent inequality at x_j gives

    J(x_i)<=J(x_j-grad J(x_j))
            <=J(x_j)-||g_j-g_i||^2/2.

Rearrangement is the original residual

    Q_ij=f_i-f_j+<g_i,x_j-x_i>+||g_i-g_j||^2/2<=0.         (15)

This is the necessity argument of accepted `1252b8823bb5a290`, written
out here to cover both optimum directions, every remote queried pair,
both terminal directions, and all repeated/zero-step samples.

More generally, for ANY fixed nonnegative word all of whose steps obey
h_i>=2/(1+mu), (13) has q_mu(h_i)=h_i-1. Indeed this inequality implies
h_i>=1, 1-h_i mu<=h_i-1, and 1-h_i mu>=-(h_i-1).
The bound (14) is then attained by F(x)=x^2/2, x0=1, r=0.
Thus the exact class supremum on such a word is product_i(h_i-1)^2.
This general finite-word observation includes the empty word. It makes
no matching assertion for schedules that fail the displayed step condition.

## 3. Exact physical word algebra and the same-word scalar comparator

The bounds needed below follow from m>=128 and elementary squaring of
7/5<sqrt(2)<99/70:

    12/5<c<5/2, 2/5<a<29/70<1/2,
    7/5<ell<99/70, 127/128<=beta<1,
    d_1=1+beta=2-1/m>19/10,
    d_j>2 for j>=2.                                      (16)

For the lower bound on a, a=(m-1)/[(m+1)sigma] is at least
8890/21801>2/5. For the upper bound on c,
c<(169/70)(129/128)<5/2. Also a<1/sigma=sigma-2<c-2.

Counting a level j in H_m gives exactly 2^(m-j-1) occurrences.
Summing the physical masses or solving M_(j+1)=2M_j+a c^j gives

    M_j=A_mass c^j+(1-A_mass)2^j,
    A_mass=a/(c-2), 0<A_mass<1.                           (17)

In particular 1<=M_j<=c^j and a c^j<=(c-2)M_j.

We now rederive the best Huber/single-cut comparison directly from
accepted `b98bb807d514e80d`, without using C93 as a lemma. For a cut of
level j, the numerator is (a c^j)^2. If P is its actual preceding mass,
its denominator is

    (1+P)^2[1+2(S_m-d_j-P)].                             (18)

The logarithm of (18) has second derivative
-2/(1+P)^2-4/[1+2(S_m-d_j-P)]^2<0. Hence its minimum over the mass
interval from the first to the last occurrence is at one of those
endpoints. Write M=M_(m-1). At the first occurrence P=S_j and the
following mass is at least S_(m-1). Its cut value is at most
(c-2)^2/(2M-1). At the last occurrence the preceding mass is at least
S_(m-1) and the following mass is S_j. Its value is at most

    (c-2)^2 M_j^2/[M^2(2M_j-1)] <= (c-2)^2/(2M-1),       (19)

because x^2/(2x-1) is nondecreasing for x>=1 and M_j<=M.
Finally M_m<=cM, c<5/2 and c-2<1/2 imply

    (c-2)^2(2M_m-1)<=(5M-1)/4<=2M-1.

The last inequality is equivalent to M>=1. Thus every cut is no larger
than K=1/(2M_m-1). The global Huber term attains K, proving

    K_n(H_m)=K.                                          (20)

An explicit attaining scalar function is the symmetric Huber function
with radius K, started at 1. Its iterates are
x_i=1-K sum_(t<i)h_t; they all remain on
the positive outer ray. Its terminal normalized value is K.

## 4. All gates allowed: exact supremum and the wider curvature screen

The product of the upper-endpoint factors over H_j is

    U_j:=product_(h_i in H_j)(h_i-1)
        =a^(2^j-1)c^(2^j-j-1)
        =beta^(2^j-1)c^(-j).                            (21)

For j=0 the expression gives 1. One can also check (21) by the exact
recursion U_(j+1)=U_j^2 a c^j.

For h>1 and 0<=mu<=1, (13) can be written

    q_mu(h)=max{1-mu h,h-1}.                            (22)

For all bridge levels j>=2 the second term wins, by d_j>2. At level 1
it wins whenever

    mu>=mu_1:=2/d_1-1=1/(2m-1).                         (23)

Define q0=max{1-mu ell,a} and q1=max{1-mu d_1,beta}. The ENTIRE
product bound, with no lost low-level factor, is

    V <= U_m^2 (q0/a)^N (q1/beta)^(N/2).                 (24)

This holds for all 0<=mu<=1. If mu>=mu_1 it reduces exactly to

    V <= beta^(-2)c^(-2m) [beta c q0]^N.                 (25)

If mu>=mu_exact=(1-a)/(1+a)=2/ell-1, q0=a. All steps satisfy the
condition following (15), and (25) equals beta^(2N-2)c^(-2m).
The unit quadratic attains it with true distance 1, proving (6).
It can be embedded with arbitrary flat directions without changing the
true-distance quotient, because Section 2 projects onto E.

For the weaker condition mu>=mu_floor of (7), note first that
beta c>2 and ell<3/2. Therefore mu_floor>1/3>mu_1. Also
1/(beta c)>a, since a beta c=beta^2<1. It follows that
mu_floor<mu_exact and q0<=1/(beta c). Equation (25) proves the first
bound in (8). By (17) and (20),

    V/K <=(2M_m-1) beta^(-2)c^(-2m)
           <2/[beta^2 c^m].                            (26)

This ratio is less than 1 for the stated m. The accepted original-
benchmark estimate in `b98bb807d514e80d` is
B_n<=1+4n^(log_2 3). Since n=2^m-1<2^m,

    B_n V <= beta^(-2)[c^(-2m)+4(3/c^2)^m] -> 0,         (27)

uniformly, because beta>=127/128 and c>12/5 gives 3/c^2<25/48<1.
No fitted profile, internal child capacity or substituted recurrence is
used here. Both thresholds tend to (1-1/sigma)/(1+1/sigma)
=sqrt(2)-1 by their displayed definitions.

## 5. A necessary weak direction for even the scalar payoff

The exponent L_m in (9) is strictly positive. Indeed (17) implies

    exp(L_m)=beta^2 c^(2m)/(2M_m-1)
               >beta^2 c^m/2>1.                       (28)

The last inequality follows already from beta>1/2, c>2 and m>=128.
Thus mu_comp<mu_floor. To check the lower bound in (10), first
2m/2^m<=1/8 for m>=7, as follows from 2^7>=16*7 and induction.
Since exp(L_m)<=c^(2m),

    exp(L_m/N)<=c^(1/8)<(5/2)^(1/8)<9/8.                (29)

The last strict comparison follows by the binomial expansion of
(1+1/8)^8, retaining enough positive terms to exceed 5/2. Hence
exp(L_m/N)/(beta c)<9/16 and mu_comp>7/24>1/(2m-1).

Suppose a legal run has V>=K. If mu<mu_1, then already mu<mu_comp.
Otherwise (25) gives

    q0 >= exp(L_m/N)/(beta c) > 1/(beta c)>a.             (30)

Consequently q0=1-mu ell, and (30) is exactly mu<=mu_comp.
Subtracting (9) from (7) proves the exact gap formula (10).

Thus the background matrix of any competitive member of this static
family must have a sufficiently weak direction in the active space E.
This is only a NECESSARY condition. No construction below that floor
is supplied by the product bound, and mu_comp is not asserted to be a
sharp threshold for the actual fixed-function family.

## 6. Actual multiple outer sign changes, noncommuting gates and all visits

Here is a concrete run in the resolved class, for EVERY original H_m
with m>=128. Let phi_r be the symmetric Huber function with radius
r=1/100 and define, once and for all,

    F_gate(x,y)=3x^2/8+7y^2/16
                    +(1/16)phi_r((x+y)/sqrt(2)),
    X_0=(1,0).                                         (31)

Write u=(1,1)/sqrt(2), A=diag(3/4,7/8) and

    H=A+(1/16)u u^T=(1/32)[25,1;1,29].                 (32)

The Hessian in either outer region is A; in the core it is H. Globally
(3/4)I<=A<=H<=(15/16)I<I. Thus (31) is a fixed convex 1-smooth
function, its unique minimizer is 0, and the true initial squared
distance is exactly 1. Its visited Hessians do not commute:
the (1,2) entry of A H-H A is -1/256, hence nonzero.

We prove ALL its region visits, without a finite replay. Abbreviate

    b=d_1=1+beta,
    k=r/(16sqrt(2))=sqrt(2)/3200,
    s(lambda)=1-ell lambda, t(lambda)=1-b lambda.

At X_0 the ridge is strictly positive outer. Its gradient is

    g_0=(3/4+k,k),
    X_1=(s(3/4)-ell k,-ell k).                         (33)

By ell>7/5, the first coordinate of X_1 is less than -1/20 and the
second is negative. Hence u^T X_1<-1/(20sqrt(2))<-r: the first actual
step lands in the strictly negative outer region. Its gradient is
g_1=A X_1-k(1,1), and the second actual step gives

    X_2=(t(3/4)[s(3/4)-ell k]+b k,
                         t(7/8)(-ell k)+b k).          (34)

Both entries are positive. Since b>19/10, t(3/4)<-17/40, the first
entry is greater than 17/800. Consequently
u^T X_2>17/(800sqrt(2))>r, so this query is strictly positive outer.
The third physical step is again ell. For lambda=3/4 or 7/8 set

    C(lambda)=-ell s(lambda)t(lambda)+b s(lambda)-ell.

Directly applying this third step in its now established positive
outer region yields

    X_3=(s(3/4)^2 t(3/4)+k C(3/4), k C(7/8)).           (35)

All s,t in (35) are negative. Therefore both entries of X_3 are
strictly negative. We next establish a uniform small-norm bound with
explicit rational margins. From (16),

    |s(3/4)|<61/1000, |t(3/4)|<1/2,
    |s(7/8)|<119/500, |t(7/8)|<3/4,
    ell<283/200, b<2, k<443/1000000.

These imply

    |C(3/4)| < (283/200)(61/2000)+122/1000+283/200
                  <1581/1000,
    |C(7/8)| < (283/200)(357/2000)+238/500+283/200
                  <2144/1000.

Using the sum of absolute coordinates to bound the Euclidean norm,

    ||X_3|| < (61/1000)^2/2
                   +(443/1000000)(3725/1000)
             =3510675/1000000000 < 9/2500.              (36)

The slightly larger round margin 9/2500 is retained below; no numerical
evaluation of the trajectory is being used in (33)--(36).

It remains to prove that EVERY subsequent actual query and the actual
terminal sample are in the core. For H_j let R_j be the largest product
of (h_i-1) over ANY prefix, including the empty prefix. Formula (21) gives

    U_j a c^j=a beta^(2^j-1)<=a<1.

The physical recursion of H_(j+1) shows that every prefix is either a
prefix of its first H_j or has product U_j a c^j times a prefix of its
second H_j. Thus R_j=1 for all j. More precisely every NONEMPTY prefix
has product at most a: this holds for H_1, is inherited in the first
child, and holds in the second child by the displayed inequality.

The background floor 3/4 exceeds mu_exact, so each ACTUAL step of
(31) obeys ||X_(i+1)||<=(h_i-1)||X_i||, independently of its current
gate. The product over the first three steps is U_2=a^2 beta. For any
i>=3, the suffix product between sample 3 and sample i is therefore
at most a/U_2=1/(a beta). Since a>2/5 and beta>=127/128,

    ||X_i|| <=||X_3||/(a beta)
               <(9/2500)(320/127)<1/100=r.              (37)

This includes i=3. Hence |u^T X_i|<r at EVERY remaining actual sample.
There is no circular assumption of future core behavior in (37): its
contraction bound was valid for every gate before any visits were known.

Thus the complete gate chronology is

    positive outer, negative outer, positive outer,
                       core, core, ..., core.           (38)

The terminal position is explicitly specified, without a replay, by

    X_n=[product_(i=3)^(n-1)(I-h_i H)]X_3,               (39)

with the usual empty-product convention. Equations (33)--(35) and (39)
give every actual point and gradient of this one static function.

For i>=3 all entries of I-h_i H are strictly negative: h_i>=ell>7/5,
and (7/5)(25/32)>1, (7/5)(29/32)>1. Since both coordinates of X_3
are negative, multiplication shows that both coordinates of EVERY
X_i, i>=3, have sign (-1)^i. H has strictly positive entries, so the
same is true of both gradient coordinates. Equations (33)--(35) also
give g_0 positive, g_1 negative and g_2 positive. Thus there is an actual
gradient-coordinate sign change at EVERY step, not a relabeling of
character signs or an alternation of separately chosen functions.

The gradients are genuinely noncollinear. Let b_vec=k(1,1). In the
first two outer regions,

    g_1=g_0-2b_vec-ell A g_0,
    det(g_0,g_1)=-3k/2-(ell/8)(3/4+k)k<0.               (40)

Moreover <g_0,g_1><0 while <g_0,g_2>>0, so their normalized pair
correlations are not constant. The switch from A to the noncommuting
H occurs between actual queried samples 2 and 3. This run is outside
the fixed-queried-region hypothesis of C93 and outside the single-
initial-sign chronology of C92.

All original pairs hold by Section 2, and the true radius is 1. Its
terminal payoff is exactly X_n^T H X_n, with X_n given by (39), and

    0<V_gate<=beta^(2N-2)c^(-2m)<K.                     (41)

To see strict positivity, H has eigenvalues (27 plus or minus sqrt(5))/32.
Its smaller eigenvalue exceeds 3/4, and h_i>7/5, so no I-h_i H is
singular. Formula (35) is nonzero and H is positive definite. The
upper comparison follows from (6) and (26). Thus (31) is a real
changing-region mechanism, but it supplies NO lower-bound improvement;
the same-word accepted global Huber witness is already stronger.

## 7. Attack on the tempting extension below the curvature floor

The product in (14) is an upper envelope over endpoint contractions.
It is not an instruction to switch curvatures independently. A concrete
failure occurs on the first two actual steps of H_m. Set mu=1/4 and
pretend that a scalar run starts at x0=1, uses g0=mu x0, and after the
first step uses the upper endpoint curvature with g1=x1. Then

    x1=1-ell/4, 0<x1<x0, and g1=x1>1/4=g0,              (42)

because ell<3. These two queries violate monotonicity of the derivative
of any convex scalar function. Equivalently
(g0-g1)(x0-x1)<0. They cannot be part of a legal static adversary, even
though each chosen scalar curvature separately belongs to [mu,1].

This attacks the failed positive interpretation of the envelope below
its proved screen. It does NOT prove that the whole weak-background
class is harmless. It also does not assert a multidimensional static
counterexample from arbitrary Hessian switching.

The genuine scalar Huber witness attaining K supplies the opposite
scope check: it has A=0, lies within (1)--(2), and has value K, which
exceeds beta^(-2)c^(-2m) for the stated m. Thus deleting the curvature
floor from (8) is false even before introducing multiple interacting
ridge directions. This known witness is a scope counterexample, not a
new lower bound.

## 8. What this leaves open, and literature grounding

C94 resolves a changing-queried-region subclass that C93 did not cover:
an arbitrary number of coupled ridge gates cannot offset a background
floor at or above (7). The exact strong-floor extremum is (6), and even
scalar competitiveness requires (9). The explicit run (31) proves that
this class is not empty or secretly a fixed-region class. It includes
many actual sign changes and different noncommuting visited Hessians.

The remaining static-ridge question requires weak background directions
in E, together with actual queried gate changes. No sufficient gluing
rule, improved H_m lower bound, arbitrary-h matching theorem or original
target fact is established here. In particular neither max's actual31
child nor the finite C59 adversary is inserted as a reusable child.

Search was conditioned on the changing-gate mechanism. Matlas returned
the standard strong-convexity sector inequality (for example,

premise. The downloaded Stanford course notes

were read through the browser after local text extraction was unavailable
and one browser request failed. Lemma 2.2 concerns the usual contraction
estimate under twice differentiability. Huber functions are not twice
continuously differentiable at their joins. The explicit clipped secants
(11)--(13) supply the needed proof here without a pointwise vector mean-
value assertion or any smooth-Hessian assumption.
