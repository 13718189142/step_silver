# Parent R12 extension: every single nonnegative destination law fails

**UNVERIFIED manual proof. This excludes a coefficient family, not Profile C or the original minimax problem.** No new model or mathematical program was used. The R12b report checked one explicit rank-one flow; this note proves the stated larger single-law scope without changing that report's bytes.

Let the physical source weights be u_i>0 fori<n and letU=sum_(i<n)u_i. The required column sums areb_i=u_i physically andb_n=-U. Consider ANY matrix

    C=p q^T-diag(p), p_i>=0,q_i>=0,sum q_i=1,

    p_i=P q_i-u_i (i<n), p_n=P q_n+U,

There is no restriction to q_i proportional to the algebraicell_i. Both p andq may depend arbitrarily on the whole word.

This follows from the actual lower-triangular trajectory matrix and already includes the complete covariance or other exact decomposition of the dominance cross terms.
