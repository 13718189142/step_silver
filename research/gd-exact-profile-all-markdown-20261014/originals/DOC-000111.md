## 1. Target and actual baseline witnesses

After setting \(L=1\), let \(h\in[0,\infty)^n\) be the entire prescribed word, \(S=\sum_i h_i\), and

\[
x_{i+1}=x_i-h_i\nabla f(x_i),\qquad
W_n(h)=\sup\frac{2(f(x_n)-f_\star)}{\|x_0-x_\star\|^2}.
\]

The supremum has the original full finite-dimensional smooth-convex scope, with an attained minimum and the original last iterate and radius. Let \(C_0=B_0=1\) and, for every integer split \(k+l=n-1\),

\[
C_n=\max\frac{C_k+C_l+\sqrt{C_k^2+6C_kC_l+C_l^2}}2,
\]

\[
B_n=\max\left(2C_k+\frac{B_l}2+
\frac{\sqrt{B_l^2+8C_kB_l}}2\right).
\]

The missing original conclusion is

\[
\forall\epsilon>0\ \exists N_\epsilon\
\forall n\ge N_\epsilon\ \forall h\in[0,\infty)^n:
\quad W_n(h)\ge(1-\epsilon)/B_n,
\]

with \(N_\epsilon\) independent of \(h\).

The complete global Huber and scalar-quadratic pool is retained:

\[
W_n(h)\ge \frac1{2S+1},\qquad
W_n(h)\ge\sup_{0\le\lambda\le1}
\lambda\prod_i(1-h_i\lambda)^2.
\tag{1}
\]

No completeness of this pool is assumed. Nor is Zhang--Jiang's sufficient concatenation theorem used as a converse.

## 2. Line 1: translating a fixed common-normal history

### 2.1 Function, geometry and exact translation law

Let \(K=\operatorname{conv}(0,g_1,\ldots,g_m)\), where the nonzero retained generators include all queried gradients. Use the single static function

\[
F_K(x)=\max_{g\in K}
\{\langle x,g\rangle-\tfrac12\|g\|^2\}.
\tag{2}
\]

It is convex and 1-smooth, \(\nabla F_K=P_K\), and \(F_K(0)=0=\min F_K\). Its normal test at a retained jet is

\[
\langle x_i-g_i,g-g_i\rangle\le0\quad(g\in K).
\tag{3}
\]

A history with positive terminal objective cannot have encountered gradient 0 earlier, so useful histories may be treated with nonzero queried gradients throughout.

Suppose an actual vector \(e\) satisfies

\[
\langle e,g_j\rangle=1\qquad(1\le j\le m).
\tag{4}
\]

Define actual quantities

\[
H=\min_i\langle x_i-g_i,g_i\rangle,\quad
M=\max_j\langle x_0,g_j\rangle,\quad
R^2=\|x_0\|^2,\quad A=\langle x_0,e\rangle,\quad E=\|e\|^2.
\]

For \(t\ge-H\), translate the entire trajectory to \(x_i+t e\), keeping the same body \(K\) and gradients. All nonzero-generator differences in (3) are unchanged. The rows against 0 become exactly \(H_i+t\ge0\). The GD recursion also remains exact, because the same translation is made at every time.

The values and complete boundary data are therefore

\[
F_K(x_i+t e)=F_K(x_i)+t,\quad
H(t)=H+t,\quad M(t)=M+t,
\]

\[
R(t)^2=R^2+2At+Et^2.
\tag{5}
\]

Thus height replenishment is legal, but its original radius is the quadratic expression in (5), not \(R^2\). To raise \(H/M\) to a specified \(\eta_\star\in(H/M,1)\) requires

\[
t=\frac{\eta_\star M-H}{1-\eta_\star}>0.
\tag{6}
\]

For a proposed target denominator \(B\), the exact selected-origin test is

\[
2B(F_K(x_n)+t)-R(t)^2
=2BF_K(x_n)-R^2+2(B-A)t-Et^2.
\tag{7}
\]

All quantities in (5)--(7) belong to this actual history. No favorable value of \(A\) or \(E\) is an independent resource.

For the R5 orthogonal prefix-to-child operation, a child's common normal is inherited explicitly. If the added prefix gradient is \((a,0)\) and the child generators are \((0,b_j)\), then

\[
e_{\rm new}=(1/a,e_B),\qquad
E_{\rm new}=1/a^2+E_B,\qquad
A_{\rm new}=C+v+A_B.
\tag{8}
\]

These identities show exactly where repeated replenishment would pay its additional radius.

### 2.2 The complete minimum cone and the closest-origin condition

For (2),

\[
\arg\min F_K=K^\circ
=\{z:\langle z,g_j\rangle\le0\ \forall j\}.
\tag{9}
\]

The origin is a closest minimizer to \(x_0\) if and only if \(x_0\in\operatorname{cone}K\). Indeed, 0 is the closest point in the polar cone precisely when \(\langle x_0,z\rangle\le0\) for every \(z\in K^\circ\); otherwise a sufficiently small positive multiple of such a \(z\) reduces the distance. The polar of this closed polyhedral polar cone is \(\operatorname{cone}K\).

This condition holds for the R5 orthogonal retained-height histories and every legal common-normal translation of them. Write their generators as \(a_j e_j\), \(a_j>0\), and their initial coordinate supports as \(P_j=a_j(x_0)_j\). At the first query using generator \(j\), its coordinate has not yet moved, so the height there is \(P_j-a_j^2\). Therefore

\[
H\le P_j-a_j^2,\qquad t\ge-H
\quad\Longrightarrow\quad P_j+t\ge a_j^2>0.
\]

Since the common normal is \((1/a_j)_j\), the translated initial point still lies in the positive coordinate cone. Thus 0 really is the closest minimizer, including after the replenishment. There is no omitted improvement from selecting a different minimum in this family.

For a general common-normal hull, (4) alone does not imply the closest-origin condition. An upper bound using the origin radius must not be promoted to an upper bound using the closest minimum without this separate check.

### 2.3 Removing the common component gives another actual whole-word history

Take the minimum-norm solution of (4), and suppose that its affine perpendicular foot lies in the retained nonzero hull:

\[
p=\frac e{\|e\|^2}\in
\operatorname{conv}(g_1,\ldots,g_m).
\tag{10}
\]

Put

\[
\nu=e/\|e\|,\qquad c=1/\|e\|,\qquad
g_j=w_j+c\nu,\qquad w_j\perp\nu.
\]

By (10), \(0\in K_T:=\operatorname{conv}(w_1,\ldots,w_m)\). For the physical points write
\(x_i=y_i+z_i\nu\). The GD recursion gives, at every actual time,

\[
y_{i+1}=y_i-h_iw_i,\qquad
z_i=z_0-c\sum_{r<i}h_r.
\tag{11}
\]

The projected history is not a formal Gram direction: it is realized by the explicit static function

\[
F_T(y)=\max_{w\in K_T}
\{\langle y,w\rangle-\tfrac12\|w\|^2\}.
\tag{12}
\]

Indeed every old nonzero-generator row becomes

\[
\langle y_i-w_i,w_j-w_i\rangle
=\langle x_i-g_i,g_j-g_i\rangle\le0.
\]

Since 0 is a convex combination of the \(w_j\), its row follows as well. Hence \(\nabla F_T(y_i)=w_i\), all physical steps are retained, and 0 is an attained minimum of (12).

Let

\[
D=\|y_0\|^2,\qquad V=2F_T(y_n),\qquad Q=2S+1.
\]

The complete original value and radius split exactly:

\[
2F_K(x_n)=V+2cz_0-Qc^2,\qquad
\|x_0\|^2=D+z_0^2.
\tag{13}
\]

For every real \(z_0\),

\[
2cz_0-Qc^2
\le \frac{z_0^2}{Q},
\tag{14}
\]

because \((z_0-Qc)^2\ge0\). If \(D>0\), (13)--(14) imply the pointwise domination

\[
\boxed{\quad
\frac{2F_K(x_n)}{\|x_0\|^2}
\le
\max\left\{\frac{2F_T(y_n)}{\|y_0\|^2},
\frac1{2S+1}\right\}.
\quad}
\tag{15}
\]

If \(D=0\), the tangent history starts at its minimum and remains there, so \(V=0\); the Huber term alone bounds (13). This covers that degeneracy.

A common-normal translation changes only \(z_0\) in (13). Thus (15) includes every legal translation, every horizon and every nonnegative word, with no asymptotic loss calculation or per-level approximation. If the closest-origin condition of Section 2.2 holds, it also bounds the error normalized by the closest valid minimizer.

### 2.4 What the domination means for the actual orthogonal recursion

For the R5 orthogonal generators \(g_j=a_je_j\), the foot condition (10) is automatic:

\[
E=\sum_j a_j^{-2},\qquad
p=\sum_j\frac{a_j^{-2}}E\,g_j.
\]

Its tangent generators satisfy

\[
\langle w_i,w_j\rangle=-1/E\quad(i\ne j).
\]

After a common scaling, they are precisely a centered simplex of the form

\[
\sqrt{A_j}e_j-u,\qquad
A_j=Ea_j^2,\quad \sum_j A_j^{-1}=1.
\]

The initial tangent point and its complete GD chronology come from (11), not from freely chosen support data. Together with the closest-minimizer proof, (15) shows that the entire translated orthogonal retained-height construction is dominated, word by word, by an actual centered tangent history or the global Huber witness.

This is not a proof that the centered history has a small error. It can itself be the needed nonlinear adversary. The conclusion is that common-normal replenishment supplies no additional normalized contribution beyond those two actual witnesses. A proof still has to establish the required centered-history payoff on the hard words.

For this orthogonal family, the centered part also loses the proposed replenishment operation. If it is nontrivial, its strictly positive convex combination giving \(\sum_j\lambda_j w_j=0\), \(\sum_j\lambda_j=1\), prevents any vector from having inner product 1 with all its nonzero generators. Thus the claimed recursive repair cannot simply be repeated on that centered child with the same premise.

## 3. Line 2: retaining a common normal through negative correlations

### 3.1 An actual coupled lift of the R5 simplex

Use an actual R5 simplex history. Its nonzero generators \(w_j\) have pairwise inner product \(-1\), satisfy
\(\sum_j A_j^{-1}w_j=0\), and have the explicit initial point

\[
x_0=\sum_j (P_j/A_j)w_j,\qquad
\mu=\sum_j P_j/A_j.
\]

The R5 phase proof gives, at a query using vertex \(j\), a nonnegative phase score \(L_i\) with

\[
H_i:=\langle x_i-w_j,w_j\rangle
=L_i+s_i+1-\mu\ge0,\qquad L_i\ge0,
\tag{16}
\]

where \(s_i\) is the actual cumulative mass before the query. These are realized histories, including all old values and cross rows.

Let \(e_\perp\) be a new unit vector orthogonal to their span. For
\(0<\gamma\le1\) and \(t\ge0\), choose one fixed lifted body

\[
\widehat K=\operatorname{conv}
\bigl(0,\ w_j+\gamma e_\perp:\text{all retained }j\bigr)
\]

and the initial point

\[
\widehat x_0=x_0+
\left(\gamma\mu+\frac t\gamma\right)e_\perp.
\tag{17}
\]

Prescribe the lifted gradient \(w_j+\gamma e_\perp\) whenever the original history uses \(w_j\). The new coordinate evolves by subtracting \(\gamma\) times every physical step.

All nonzero-generator cross rows are unchanged. The row against 0 at query \(i\) is paid by the height

\[
\widehat H_i
=H_i+\gamma^2(\mu-s_i-1)+t
=(1-\gamma^2)H_i+\gamma^2L_i+t\ge0.
\tag{18}
\]

Thus (17)--(18) realize the entire lifted trajectory on one static smooth convex function. The lifted generators have cross inner products \(-1+\gamma^2\le0\) and have common normal \(e_\perp/\gamma\). Its norm is \(1/\gamma\); it cannot be held fixed when the lift is made small.

### 3.2 The minimum cone and full radius remain explicit

Let \(\lambda_j=1/A_j\). The coefficients

\[
\alpha_j=P_j/A_j+(t/\gamma^2)\lambda_j
\]

are nonnegative, and

\[
\sum_j\alpha_j(w_j+\gamma e_\perp)=\widehat x_0.
\]

Therefore \(\widehat x_0\in\operatorname{cone}\widehat K\), and 0 is a closest minimizer of the lifted function. This rules out a hidden polar-cone improvement in this repair.

Writing \(D=\|x_0\|^2\), \(V=2F_K(x_n)\), and
\(Y=\gamma\mu+t/\gamma\), its complete original radius and terminal value are

\[
\|\widehat x_0\|^2=D+Y^2,\qquad
2F_{\widehat K}(\widehat x_n)=V+2\gamma Y-(2S+1)\gamma^2.
\tag{19}
\]

The same exact inequality (14) now gives

\[
\frac{2F_{\widehat K}(\widehat x_n)}
{\operatorname{dist}(\widehat x_0,\arg\min F_{\widehat K})^2}
\le
\max\left\{\frac{2F_K(x_n)}{\|x_0\|^2},
\frac1{2S+1}\right\}.
\tag{20}
\]

This holds for every legal phase partition, every R5 simplex parameter choice, every \(0<\gamma\le1\), every \(t\ge0\), and the actual arbitrary nonnegative word underlying the history. Optimizing these lift and replenishment parameters cannot beat the existing centered child or Huber. This is a pointwise portfolio domination, not a failure observed on a baseline-covered Silver example.

### 3.3 Scope beyond this explicit lift

The foot condition behind this conclusion is not special to orthogonal generators. For linearly independent generators with positive-definite Gram matrix \(G\) and nonpositive off-diagonal entries, the solution of \(G\lambda=\mathbf1\) is strictly positive. One proof minimizes

\[
\tfrac12 a^TGa-\mathbf1^Ta.
\]

Replacing \(a\) by its componentwise absolute values cannot increase the quadratic term and strictly improves the linear term if a negative component is present. The minimizer is nonnegative. A zero component would make the corresponding row of \(G\lambda\) nonpositive, contradicting its value 1. Hence every component is positive.

Consequently the minimum-norm common-normal foot is a positive convex combination of these generators. The tangent construction of Section 2.3 applies whenever a common-normal history of this type is actually realized. This statement establishes the foot condition only; its closest-minimizer condition still requires the separate cone check. That check was proved for (17), not assumed for every possible correlated hull.

This repair therefore did not produce a new recursive source of normalized error. It returns the problem to the actual centered child, where a common normal is absent and the all-word history selection still needs a different proof.
