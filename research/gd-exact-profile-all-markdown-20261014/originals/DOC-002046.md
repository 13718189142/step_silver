## 2. 问题背景

### 2.1 为什么“只改步长”也可能加速

算法保持最普通的梯度下降形式

\[
x_i=x_{i-1}-h_i\nabla f(x_{i-1}),
\]

不使用 momentum、averaging、line search 或观测反馈。唯一自由度是预先设计有限步长表

\[
H=(h_1,\ldots,h_n).
\]

Silver schedule 说明：即使算法形式不变，通过非平稳、层级化的大步长和小步长排列，也能把 smooth convex last-iterate 的已知 \(O(1/n)\) 级行为提升到

\[
O(n^{-\sigma}),
\qquad
\sigma=\log_2(1+\sqrt2)\approx1.2715533.
\]

核心开放问题是：这是否已经是所有预定步长表能达到的最好指数？

### 2.2 non-anytime 与 anytime 必须分开

本报告只研究 **non-anytime**：

- 每个 horizon \(n\) 可以重新设计一张长度为 \(n\) 的步长表；
- 步长表必须在看到函数值、梯度和迭代点之前固定；
- 只评价最后一次迭代 \(x_n\)。

不研究 anytime：后者要求同一条无限步长序列同时服务所有停止时刻，量词更强，已知界也不同。

## 3. 严格问题设定

### 3.1 函数类

对任意有限维 \(d\)，令

\[
\mathcal F_1(\mathbb R^d)
\]

表示所有满足以下条件的函数 \(f:\mathbb R^d\to\mathbb R\)：

- 凸；
- 可微；
- 梯度 1-Lipschitz；
- 极小点集合非空。

### 3.2 算法与 schedule

给定

\[
H=(h_1,\ldots,h_n)\in(0,\infty)^n,
\]

普通梯度下降为

\[
x_i=x_{i-1}-h_i\nabla f(x_{i-1}),
\qquad i=1,\ldots,n,
\]

输出 \(x_n\)。

假设：

- A1：函数属于完整 \(\mathcal F_1\)；
- A2：\(H\) 可依赖 \(n\)，但必须在观测函数信息前固定，且所有 \(h_i>0\)；
- A3：对手在看到 \(H\) 后可选择有限维数、函数、极小点与初始点；只评价 last iterate。当前冻结 D3 的字面条件是 \(x_0\ne x_\star\)。在获得 contract v3 clarification 前，不把它静默替换为更强的 \(x_0\notin\arg\min f\)。

### 3.3 固定 schedule 的最坏值

\[
\boxed{
R_n(H)
=
\sup_d
\sup_{f\in\mathcal F_1(\mathbb R^d)}
\sup_{x_\star\in\arg\min f}
\sup_{x_0\ne x_\star}
\frac{2(f(x_n)-f(x_\star))}
{\|x_0-x_\star\|^2}.
}
\]

因尺度齐次，展示具体 hard instance 时常写

\[
\|x_0-x_\star\|^2=1,\qquad f_\star=0,\qquad g_\star=0.
\]

C36 的 conic primal 为了严格 Slater 使用

\[
G_{00}=\|x_0-x_\star\|^2\le1;
\]

严格可行点可有 \(G_{00}<1\)，而正的齐次最优解可以缩放到饱和。

### 3.4 horizon-\(n\) 的 minimax 值

\[
\boxed{
V_n=\inf_{H\in(0,\infty)^n}R_n(H).
}
\]

这里 infimum 在 schedule 上，supremum 在 schedule 之后选择的 full-class adversary 上；顺序不能互换。

### 3.5 非 anytime 最优指数

\[
\boxed{
p_{\mathrm{NA}}^\star
=
\sup\left\{
p>0:
\exists C<\infty\
\forall n\ge1\
\exists H^{(n)}>0,\
R_n(H^{(n)})\le C(n+1)^{-p}
\right\}.
}
\]

Silver schedule 可写为

并达到 \(\rho^{-m}\) 量级。

## 4. full PEP 与证书方向

### 4.1 光滑凸插值条件

对节点 \((x_i,g_i,f_i)\)，定义 directed interpolation slack

\[
I_{ij}
=
f_i-f_j
-\langle g_j,x_i-x_j\rangle
-\frac12\|g_i-g_j\|^2.
\]

合法 primal PEP 数据必须同时满足：

- \(I_{ij}\ge0\) 对所有 directed pairs；
- GD 动力学；
- Gram 矩阵 \(\Gamma\succeq0\)；
- 初始归一化；
- 目标为末次迭代 \(2(f_n-f_\star)\)。

**方向规则：**

- 一个合法 primal hard instance 给 \(R_n(H)\) 的下界；
- 一个可行 dual certificate 给 \(R_n(H)\) 的上界；
- dual feasible 不能自动解释为存在 matching primal；
- formal polar separator 若对应的 Gram 不 PSD，也不是合法 hard instance。

### 4.2 aggregate cone

把每条 interpolation inequality 写成生成元

\[
g_{ij}=(e_i-e_j,A_{ij}),
\]

并定义

\[
\mathcal C_H
=
\operatorname{cone}\{g_{ij}:i\ne j\}.
\]

若 multiplier flow 为 \(\lambda_{ij}\ge0\)，则

\[
(d,M)\in\mathcal C_H
\iff
\operatorname{div}\lambda=d,
\qquad
\sum_{ij}\lambda_{ij}A_{ij}=M.
\]

在本报告采用的生成元与目标符号约定下，

\[
d_\star=2e_\star-2e_n.
\]

若 \((d_\star,M)\in\mathcal C_H\) 且
\(qE_{00}+M\succeq0\)，则对任意合法 primal Gram \(G\)，

\[
\boxed{
qG_{00}-2(f_n-f_\star)
=
\sum_{i\ne j}\lambda_{ij}I_{ij}
+\langle qE_{00}+M,G\rangle
\ge0.
}
\]

这直接固定了方向：dual feasible 给 \(R_n(H)\) 的上界，而要证明
T1 的下界，必须在目标阈值以下证明 dual infeasible，或直接构造 primal。
具体地，\(G_{00}\le1\) 给

\[
2(f_n-f_\star)\le qG_{00}\le q.
\]

### 4.3 test-primal fiber invariance

对固定 flow divergence 和 aggregate matrix，

\[
\lambda^\top s(G,f)
=
f^\top\operatorname{div}\lambda
-\left\langle
\sum_{ij}\lambda_{ij}A_{ij},G
\right\rangle.
\]

因此，对一个固定合法 test primal 的 pairing，不需要保留 multiplier gauge 的全部细节；但 parent lift 是否存在、support provenance 与下一层可递归性仍可能依赖完整 fiber。

### 4.4 combined cone/PSD threshold

令 \(d_\star\) 为目标 dual divergence，\(E_{00}\) 为归一化坐标矩阵，定义

\[
\mathscr D_H(q)
=
\left\{
M:
(d_\star,M)\in\mathcal C_H,\quad
qE_{00}+M\succeq0
\right\}.
\]

**Frozen Exact — global fixed-schedule theorem：**

\[
\boxed{
\mathscr D_H(q)\ne\varnothing
\iff
q\ge R_n(H)
}
\tag{PEP-threshold}
\]

对每个有限正 schedule 成立。

证明依赖：

1. \(n+2\) 个不同 \(\mu_k\in(0,1)\) 的 diagonal quadratic 给出严格 primal Slater；
2. polynomial/Vandermonde 论证给 native Gram 正定；
3. 所有 directed slacks 严格正；
4. normalized primal feasible set 紧；
5. conic strong duality 与 dual attainment。

所以 T1 已被准确改写成一个纯定量问题：

\[
\boxed{
\forall\varepsilon>0\ \exists m_0\
\forall m\ge m_0\
\forall H\in(0,\infty)^{2^m-1}\
\forall q<\rho^{-m}e^{-\varepsilon m}:
\quad
\mathscr D_H(q)=\varnothing.
}
\]

严格不等号不可改成在阈值处也为空；若 \(q=R_n(H)\)，threshold theorem
恰给出非空。

\[

### 13.14 Autonomous one-row/full-moment Tail-Snell

#### 路线原意

#### 一步精确反例

在 \(n=1\)、\(h>0\)、\(x>1+h\) 时，若强迫 terminal row 承担完整
moments，则

\[
T_{21}=-\frac{2h^2}{x-1-h},
\qquad
T_{22}=\frac{2h}{x-1-h}.
\]

所需 off-diagonal control 为

\[
q_{21}
=T_{21}-(1-h)T_{22}
=-\frac{2h}{x-1-h}<0,
\]

违反 M-matrix/nonnegative-circulation 约束。第一行虽然可通过 diagonal
exception 承担 moment，但恰会失去希望保留的 homogeneous multiplier。

#### 排除范围

#### 未排除变体

以及 common PSD coupling；这正是当前 Route A。
