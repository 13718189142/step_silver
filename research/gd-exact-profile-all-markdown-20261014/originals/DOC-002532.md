The retired function and its exact updates are

    G_ret(x)=1/2 sum_(i<k)Phi_i(x_i,x_(i+1))
                         +1/2 Hub_(C*sigma_k)(x_k-A_k),
    d_i=P_i-Q_(i-1), x^+=x-(h/2)d, Q_0=Q_k=0,
    V_m=2G_ret(x(N))=sum_(i=1)^k Phi_i(x(N)).

Phi_k denotes the original last circular value, exactly equal to this
horizontal Huber at these actual states. Hence

    B_n*2F(x_n)/R_m^2=T_m+B_n*V_m/R_m^2,
    T_m=B_n*D_(k+1)^2/[2(1+S)*R_m^2]
                  ->T_infty=Z_1*exp(-17/4)/(2lambda)<5/64. (15)

The useful finite-error normalizing scale is

    (B_n/R_m^2)*sigma_1^2*(1+K_k+2^m)->0.                  (16)

Indeed B_n*sigma_1^2=O(lambda^(-m+2k)); multiplying by K_k
still decays exponentially in m. The remaining term is
O((2/lambda)^m*lambda^(2k)), also tending to zero. No numerical
evaluation, finite benchmark replay or m>=1536 inference is used.
