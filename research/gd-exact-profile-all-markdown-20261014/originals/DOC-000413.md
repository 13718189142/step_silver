    M=max_j <v0,b_j> >0,
    R_B^2=||v0||^2, a_B=R_B^2/M, z_B=2F_B(v_end)/M.

Choose theta>0,r>=0 with theta+(tau+1)r<=d and set

    p^2=M/[theta(1+r)], T=(C+theta)p.

The same explicit hull construction from R4 satisfies every original projection row, including zero and all cross-history rows. Its initial point is X0=(v0,T), prefix gradients are(0,p), suffix gradients are(b_j,-rp). It is one static finite-dimensional convex1-smooth function selected before the run. It uses every original prefix step even though the horizontal left coordinate is trivial.

The initial support of its full gradient body is exactly

    M_new=T p=J M, J=(C+theta)/[theta(1+r)].

Indeed the competing suffix supports are bounded above by M-rTp, and (1+r)Tp>M. Its original selected-origin radius and terminal value therefore give

    a_new=C+theta+a_B/J,
