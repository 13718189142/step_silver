## 8. Explicit finite certificate and its independent exact check

The denominator is D80=2^80=1208925819614629174706176. Four arrays
pl,pu,bl,bu enclose respectively C_n from below/above and B_n from
below/above. Their index-zero values are all D80. At every n from 1
through 4095 they use EVERY original split k+l=n-1, k,l>=0.

For positive integer numerators a,b, the primitive radical numerator is
R=(a+b)^2+4ab with linear numerator c=a+b. The dominant radical
numerator is R=b^2+8ab with c=4a+b. Thus each exact join is
(c+sqrt(R))/(2D80). A lower numerator is
floor((c+floor(sqrt(R)))/2); an upper numerator is
ceil((c+ceil(sqrt(R)))/2). These expressions bound that join because
both rounding operations have the indicated orientation. Positivity
and coordinatewise monotonicity of both kernels, followed by taking
the maximum over every split, prove enclosure by induction on n.
No argmax is assumed exact and no split is removed.

Here is a complete deterministic defining program for the finite
certificate. Python integers denote arbitrary-precision integers;
isqrt(v) is the unique nonnegative integer r with r^2<=v<(r+1)^2.
The program's finite loop bounds and all asserted integer values are
part of the certificate. No floating-point quantity enters it.

```python
from math import isqrt
D80 = 1 << 80
nmax = 4095
def enclosed_join(a,b,dominant,upper):
    rad = b*b+8*a*b if dominant else (a+b)*(a+b)+4*a*b
    c = 4*a+b if dominant else a+b
    r = isqrt(rad)
    if upper:
        r += (r*r != rad)
        return (c+r+1)//2
    return (c+r)//2
pl=[D80]; pu=[D80]; bl=[D80]; bu=[D80]
for n in range(1,nmax+1):
    pl.append(max(enclosed_join(pl[k],pl[n-1-k],False,False) for k in range(n)))
    pu.append(max(enclosed_join(pu[k],pu[n-1-k],False,True) for k in range(n)))
    bl.append(max(enclosed_join(pl[k],bl[n-1-k],True,False) for k in range(n)))
    bu.append(max(enclosed_join(pu[k],bu[n-1-k],True,True) for k in range(n)))
qlo=[]; qhi=[]
for n in range(nmax+1):
    lo=isqrt(D80*bl[n]); rf=isqrt(D80*bu[n])
    assert lo*lo <= D80*bl[n] < (lo+1)**2
    assert rf*rf <= D80*bu[n] < (rf+1)**2
    qlo.append(lo); qhi.append(rf+(rf*rf != D80*bu[n]))
root2=isqrt(2*D80*D80)
assert root2*root2 <= 2*D80*D80 < (root2+1)**2
lamlo=D80+root2; lamhi=lamlo+1
slo=isqrt(D80*lamlo)
assert slo*slo <= D80*lamlo < (slo+1)**2
lam2hi=(lamhi*lamhi+D80-1)//D80
assert slo == 1878397475050142397719609
assert lam2hi == 7046136038847924384392699
slacks=[]
for t in range(nmax+1):
    n=t//2
    slack=(slo*qlo[n]-D80*qhi[t] if t%2==0 else
           slo*(qlo[n]+qlo[n+1])-2*D80*qhi[t])
    assert slack>0
    slacks.append(slack)
assert min(slacks)==33709536743225496543599832619768805273186776891
assert slacks.index(min(slacks))==4094
L3071=bl[3071]; H3840=bu[3840]
assert L3071==77954524439662110401113475160
assert H3840==103225412920462918384305104511
assert H3840<90000*D80
assert 773*L3071*D80-100*lam2hi*(H3840+19*D80)==98261575859406148591490057041393620527049740462983180
assert 772*L3071*D80-100*lam2hi*(H3840+19*D80)==4020338508518990670593580566018450094572713188395020
assert 19299*L3071*D80-2500*lam2hi*(H3840+19*D80)==6267225362087608843943037675086081931840802435287340
assert L3071-64000*D80==583271984325843219918211160
assert 2048**4>25600**3
```

In this program qlo[n]/D80<=sqrt(B_n)<=qhi[n]/D80,
slo/D80<=sqrt(lambda), and lambda^2<=lam2hi/D80. Consequently
positivity of the even and odd slacks proves, respectively,
sqrt(B_(2n))<=sqrt(lambda)*sqrt(B_n) and
sqrt(B_(2n+1))<=sqrt(lambda)*(sqrt(B_n)+sqrt(B_(n+1)))/2,
for every fine index from 0 through 4095. In the notation of Section 5,
these are exactly all 4096 inequalities e_t=0. This includes t=0 and
the final odd index4095, whose two coarse indices are2047,2048.

For each n>=1 and every split k+l=n-1, let a=pu[k],b=pu[l],H=pu[n].
The checker verifies

    2H-a-b>=0,  (2H-a-b)^2 >= (a+b)^2+4ab.

This is exactly Omega(a/D80,b/D80)<=H/D80, by squaring two
nonnegative sides. For the dominant recurrence it puts
a=pu[k],b=bu[l],H=bu[n] and checks

    2H-4a-b>=0,  (2H-4a-b)^2 >= b^2+8ab.

These are sufficient upper bounds for ALL original splits. For each
lower endpoint it checks a single stored admissible split with the
lower child endpoints. If L is the parent lower endpoint numerator
and c,R are the corresponding linear/radical numerators, it verifies
either 2L-c<=0 or (2L-c)^2<=R. In the first case sqrt(R)>=2L-c
because sqrt(R)>=0; in the second case the same inequality follows
by squaring. Hence the actual maximum is at least L/D80. Starting
from all four exact index-zero values, induction certifies EVERY
stored interval without any reliance on the original generator's
execution. This proves sufficiency of the independent checker.
