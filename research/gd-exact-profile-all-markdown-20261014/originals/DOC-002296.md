## 1. Dimensionless form of the necessary affine test

Put Q=qD, A=pi*sqrt(D), and Bsc=u/sqrt(D). Congruence of the displayed
matrix gives

    [[Q-A^2, A*Bsc-1],[A*Bsc-1,1-Bsc^2]].

Its determinant equals

    Q-1-A^2-Q*Bsc^2+2*A*Bsc
      =(Q-1)*(1-Bsc^2)-(A-Bsc)^2.

For Q>=1 the PSD conditions can therefore be written as

    A^2<=Q, Bsc^2<=1,
    (A-Bsc)^2<=(Q-1)*(1-Bsc^2).

At Q=1 this forces A=Bsc with |A|<=1, that is u=D*pi and pi^2<=1/D.
At saturation pi=sqrt(q), the first diagonal is zero, so u=1/pi is
forced instead. This saturation is a boundary of the affine feasible
region, not a necessity proved for the whole certificate cone.

For Q=17/16 the ellipse width is explicitly

    |A-Bsc| <= (1/4)*sqrt(1-Bsc^2).

In particular pi=0 is allowed by this necessary screen whenever
u^2<=D/17. This is not a sufficient dual construction.

## 2. A literal interpretation of pi=0 with last-query terminal contact

Suppose the final physical step is b=1+a in(0,2), l=n-1. Set
pi=0, alpha_l=1, other alpha_i=0. The only terminal row is
lambda_n,l=2, and the terminal square is ||gn+a*g_l||^2. Direct expansion
using x_n=x_l-b*g_l gives the exact identity

    -2f_n+2Q_(n,l)
      =-2f_l+(1-a^2)||g_l||^2+||gn+a*g_l||^2.

Thus an original-prefix certificate for

    2f_l-(1-a^2)||g_l||^2 <= q||x0-xstar||^2

would extend to the complete word with this terminal contact. The desired
prefix certificate is not obtained in this note. Merely adding a free
x0 square to an old sharp-q certificate does not supply it.

There is a second, projection-specific sufficient route to the same
prefix quantity. For F_D with gradient P_D and g_l=P_D(x_l), put
d=2-a^2>=1. Then

    2F_D(x_l)-(1-a^2)||g_l||^2
      =2<x_l,g_l>-d||g_l||^2 <= U_d(x_l).

If the ORIGINAL prefix of mass S-b had a universal U_d endpoint law,
this would give denominator

    d+2(S-b)=D-b^2.

This is a conditional interface only: that prefix is not automatically
one of the accepted H3 blocks. No unproved all-prefix U propagation is
