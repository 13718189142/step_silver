Projection-simplex universality for finite words and exact full-class value of the actual seven-step H_3 block.

All spaces, norms, and inner products are finite-dimensional real Euclidean ones. For every integer n>=0, every finite predetermined nonnegative word h=(h_0,...,h_(n-1)), and every advertised L>0, define W_n(h) as the supremum of
    2(f(x_n)-f(x_star))/(L||x_0-x_star||^2)
over every convex differentiable function f with gradient Lipschitz constant at most L and an attained minimum, every selected minimizer x_star, and every x_0!=x_star, using the actual updates
    x_(i+1)=x_i-(h_i/L)grad f(x_i), 0<=i<n.
The schedule is fixed before the function and start are chosen. Empty words and zero steps are included. Write R_n(h)=W_n(h)/2, and p=#{i:0<=i<n and h_i>0}.

(A) For each fixed word h, W_n(h) equals the supremum restricted, at normalized smoothness one, to the functions
    F_D(x)=max_(g in D)(<x,g>-||g||^2/2),
    D=conv{0,w_1,...,w_k} in R^k, 1<=k<=p+1,
where w_1,...,w_k are linearly independent. Thus D is a full-dimensional simplex with the origin as a vertex. The restriction retains all starts, all selected minimizers unequal to the start, and the same actual word. Here conv denotes convex hull, P_D is Euclidean projection onto D, grad F_D=P_D, min F_D=0, and the complete minimum set is the polar cone
    C_D={z in R^k:<z,g><=0 for every g in D}.
For positive scores one may equivalently use the closest-minimum denominator dist(x_0,C_D)^2. For general L the restricted objectives are L F_D and the steps are h_i/L, preserving the same score. This is equality of suprema, with no assertion of finite-parameter exact representation or attainment for each source run, or uniform conditioning or approximation over words.

(B) For every integer m>=1536 set
    epsilon=1/(4m), beta=1-epsilon,
    c=(1+sqrt(2))(1+epsilon), a=beta/c,
    H_0=(), H_(j+1)=(H_j,1+a*c^j,H_j), 0<=j<3.
Every child uses this same m and these same parameters. Let S3 be the sum of the seven entries of H_3. For every nonempty compact convex set D0 containing zero in any positive finite dimension, define, for d>0,
    U_d(x)=max_(g in D0)(2<x,g>-d||g||^2).
Let T_H3 be the actual composition of x -> x-h_i P_D0(x) over the seven original steps of H_3 in order. Then for every start x and every real d>=1,
    U_d(T_H3 x)<=U_(d+2S3)(x).
All physical and auxiliary projections use the same set D0. No interior or full-dimensionality assumption on D0 is required.

(C) For every m>=1536 and its actual seven-step H_3 from (B), the full original function class satisfies
    W_7(H_3)=1/(1+2S3).
The lower equality is attained by a one-dimensional Huber function with the original selected-minimum radius. These assertions make no all-depth H_j U claim and do not resolve the original asymptotic minimax problem.
