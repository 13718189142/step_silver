## 2. Symbols and the fixed function

Define the dimensionless profile Hcap and its derivative ccap by

    Hcap(z)=z^2/2                       if |z|<=1,
             |z|-1/2                   if |z|>=1,
    ccap(z)=max(-1,min(1,z)).

The two formulas agree with their first derivatives at +/-1. The function
ccap is continuous and nondecreasing, and for u<=v it satisfies

    0 <= ccap(v)-ccap(u) <= v-u.

This follows directly by dividing [u,v] at -1 and1: the slope is either0
or1 on each resulting interval, and the increments add. Hence Hcap is convex,
differentiable, and1-smooth. It is nonnegative and vanishes only at0.

Let L>0 be the prescribed smoothness. Let eta>0 be a spatial scale, xi a
minimizer anchor, and mu a minimum value. Our ONE STATIC function is

    f(x)=mu+L eta^2 Hcap((x-xi)/eta),                 (2.1)
    f'(x)=L eta ccap((x-xi)/eta).

Its gradient is L-Lipschitz by the displayed clipping inequality. Its unique
minimizer is xi and its minimum is mu. For x=xi+eta z, one GD step of size h/L
is exactly

    z -> Tcap_h(z):=z-h ccap(z).                    (2.2)

Thus the construction follows the ORIGINAL supplied word forward. A backward
calculation merely selects its starting point; it does not reverse or replace
the supplied step order.

## 4. Complete one-step predecessor sets, including zero and unit steps

For any h>=0 and target y, all real solutions of Tcap_h(z)=y are exactly
the union of the following sets; coincident boundary entries are counted once:

    {y+h}             if y+h>=1;                    (4.1+)
    {y-h}             if y-h<=-1;                   (4.1-)
    {y/(1-h)}         if h!=1 and |y|<=|1-h|;        (4.1c)
    [-1,1]            if h=1 and y=0.               (4.1u)

Every unlisted branch is absent. In particular(4.1c) is never used at h=1.
Proof: on z>=1 the map is z-h, on z<=-1 it is z+h, and on [-1,1]
it is(1-h)z. Solving these three affine equations WITH their interval
conditions proves necessity and sufficiency of the list. At h=1 the middle
equation is0=y and gives precisely(4.1u). No generic inverse notation hides
the exceptional branch.

For y>0 the same-sign positive branch always exists whenever y+h>=1. If that
inequality fails then h<1 and y<1-h, so the core branch exists. For y<0 use
oddness. For y=0, z=0 is always a preimage. Consequently every real target
has a predecessor for every h>=0. This includes arbitrarily large h.

Define mcap_h(t), for t>=0, as the smallest absolute value of a predecessor
of a target of absolute value t. Oddness makes this independent of its sign.
The exact closed formula is

    mcap_h(0)=0,
    mcap_0(t)=t,
    mcap_1(t)=t+1                           for t>0,

    mcap_h(t)=t/(1-h)                       if 0<h<1, 0<t<=1-h,
                t+h                        if 0<h<1, t>1-h,

    mcap_h(t)=t/(h-1)                       if h>1, 0<t<=h-1,
                t+h                        if h>1, t>h-1.            (4.2)

To check minimality when h>1 and 0<t<=h-1, the core predecessor has modulus
t/(h-1)<=1. The opposite outer predecessor, when distinct, has modulus
h-t>=1, and the same-sign outer predecessor has modulus h+t>1. Thus the
core is minimal, including equality. For t>h-1 only the same-sign outer
predecessor remains. For 0<h<1 there is only the core for t<1-h, only the
same-sign outer predecessor for t>1-h, and they coincide at the boundary.
At h=1,t>0 there is only the same-sign outer predecessor. This proves(4.2)
from the full list rather than deleting an inconvenient inverse branch.

For fixed h, mcap_h is strictly increasing on(0,infinity) and nondecreasing
on[0,infinity). In the small-step case the two formulas meet at value1.
In the large-step case the value at t=h-1 is1, whereas the right limit is
2h-1>1. Both pieces have positive slope, so this is an upward jump and
does not destroy monotonicity. The unit-step map has value0 at0 and right
limit1. The zero-step case is the identity.

A minimizing signed predecessor is explicit: use y/(1-h) on a legal core
branch of(4.2), use sign(y)(|y|+h) on an outer branch, and use0 for y=0.
At h=0 this is just y. Thus the formula chooses actual points, not merely
their possible lengths.

## 6. Every ordered interpolation row and the true normalization

Here is a direct row proof for any two real points u,v, with no adjacency
assumption. Write c=ccap. If u>=v, put d=c(u)-c(v)>=0. Lipschitzness gives
d<=u-v and, on [v,u],

    c(t)-c(v) >= max{0,d-(u-t)}.

Integrating the right-hand side over its final interval of length d yields

    Hcap(u)-Hcap(v)-c(v)(u-v) >= d^2/2.             (6.1)

If u<=v, put d=c(v)-c(u)>=0. Then d<=v-u and on [u,v]

    c(v)-c(t) >= max{0,d-(t-u)}.

Integrating over the first interval of length d proves the same inequality
(6.1), now with d^2=(c(u)-c(v))^2. Thus for EVERY ordered pair u,v,

    Hcap(u)>=Hcap(v)+c(v)(u-v)+(c(u)-c(v))^2/2.

Scale by L eta^2 and translate to(2.1). For all sample indices i,j, including
the minimizer and every new/old/terminal index, this says

    f_i>=f_j+g_j(x_i-x_j)+(g_i-g_j)^2/(2L).         (6.2)

The proof holds for both orderings of EACH pair. It therefore covers new-old
rows in both directions, the two new queries against one another, every remote
suffix row, and both optimum rows. A zero step repeats a point and gives
equality. There is no omitted constraint or terminal height surrogate.

The actual minimum is mu and its unique location is xi. Combining(3.4) and

    Vcap_ab,k(r)=(2r-2S-1)/Dcap_ab(r)^2.             (6.3)

    Mcap_(u followed by v)=Mcap_u composed with Mcap_v.              (8.2)

## 11. All-depth obstruction: exact soft-threshold schedules
