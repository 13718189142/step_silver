## 1. The whole class, including dense initial anchors

Let F be any everywhere finite convex differentiable function on a
finite-dimensional Euclidean space, with 1-Lipschitz gradient and a
nonempty set of minimizers. Fix an integer n>=1 and a supplied word h=(h_0,...,h_(n-1)),
all h_i>1, and one actual trajectory of this SAME function,

    X_(i+1)=X_i-h_i g_i,   g_i=grad F(X_i),
    f_i=F(X_i)-min F,      q_i=||g_i||^2,
    R_init=dist(X_0,argmin F)>0,   V=2f_n/R_init^2.

The terminal g_n is the actual gradient, though it is not queried by
the algorithm. It has no prescribed dependence on the queried gradients.
If any g_i=0 for i<n, every later iterate stays at a minimizer and V=0.
In the nonzero case define, for all actual transitions 0<=i<n,

    dstep_i=h_i-1,
    t_proj_i=-<g_i,g_(i+1)>/q_i,
    Jval_i=f_i+q_i/2,       kval_i=Jval_i/q_i.

Assume ONLY the following value condition at the short queried steps:

    Jval_i <= h_i q_i       whenever 1<h_i<2.        (A)

There is no support or value-ratio restriction at steps h_i>=2. The
initial point may have arbitrarily many nonzero coordinates, of arbitrary
signs and magnitudes. Gradient directions need not have a Markov law.
Dimensions, affine value reserves, optimum-row slacks, long-step support
ratios, and all terminal data are otherwise unrestricted.

The class is a class of ACTUAL legal functions. All remote directed rows
hold, not merely local rows. The proof below uses necessary local rows
to upper-bound this whole class; it never asserts that these local rows
are sufficient for interpolation.

For comparison with the assigned Markov/support-ratio interface, choose
any included minimizer as the origin and put

    eta_i=<X_i,g_i>/q_i,
    delta_i=f_i-q_i/2,
    z_i=<X_i,g_i>-f_i-q_i/2.

The two optimum rows in accepted `1252b8823bb5a290` give

    delta_i>=0, z_i>=0,
    Jval_i=q_i+delta_i=eta_i q_i-z_i,
    kval_i=1+delta_i/q_i=eta_i-z_i/q_i >=1.          (1)

Thus the old support range 1<=eta_i<h_i implies (A). The new class uses weaker conditions: at short steps it requires only
delta_i<=(h_i-1)q_i, and at long steps it requires neither condition.
Condition (A) is intrinsic to the actual values and gradients; it does
not depend on which minimizer is named as the origin.
Affine reserve delta_i and optimum slack z_i remain distinct throughout.

Define the nonnegative actual long-step projection budget

    E_proj=sum_(i:h_i>=2) log(max{1,t_proj_i}).       (2)

This formula is defined even when t_proj_i is zero or negative. It is
not a count of anchor coefficients and is not a Euclidean radius.

Main conclusion on the ORIGINAL H_m, defined in Section 5:

    V <= ((a_m+2)/(a_m+1)) beta_m^n c_m^(-m)
                                      exp(E_proj). (3)

In particular the ENTIRE stated class with t_proj_i<=1 at every long
step has vanishing original-B payoff and is exponentially weaker than
the accepted scalar witness on the SAME word. This conclusion includes
fully dense, arbitrarily chosen Markov anchors. No sparsity or lower
bound on their nonzero coefficients is imposed.

## 2. The exact local inequality and its two regimes

Accepted `1252b8823bb5a290` supplies the original residual

    Q_ij=f_i-f_j+<g_i,X_j-X_i>+||g_i-g_j||^2/2<=0.

Substitute the actual GD step into the REVERSE adjacent row:

    Q_(i+1,i)
       =Jval_(i+1)-Jval_i+[1-dstep_i t_proj_i]q_i.

Consequently, without discarding a slack or replacing a value,

    Jval_(i+1)<=Jval_i+[dstep_i t_proj_i-1]q_i.          (4)

For a zero terminal gradient Jval_n=0, so the same inequality applies.
Adding both adjacent rows instead gives cocoercivity on the actual step,

    ||g_i-g_(i+1)||^2
        <=h_i<g_i-g_(i+1),g_i>.

After division by q_i this is

    q_(i+1)/q_i <= dstep_i+(dstep_i-1)t_proj_i.

Cauchy--Schwarz also gives t_proj_i^2<=q_(i+1)/q_i. Hence

    (t_proj_i+1)(t_proj_i-dstep_i)<=0,
    -1<=t_proj_i<=dstep_i.                              (5)

No sign of the adjacent correlation was assumed in (5).

SHORT STEP. Suppose 0<dstep_i<1 and (A) holds. By (5),
dstep_i t_proj_i-1<=dstep_i^2-1<0. Also q_i>=Jval_i/(1+dstep_i).
Using the negative coefficient in the correct direction in (4) gives

    Jval_(i+1)
       <=Jval_i+(dstep_i^2-1)q_i
       <=[1+(dstep_i^2-1)/(1+dstep_i)]Jval_i
       =dstep_i Jval_i.                                (6)

LONG STEP. Suppose dstep_i>=1. The lower optimum row gives q_i<=Jval_i.
If dstep_i t_proj_i-1>=0, equation (4) yields
Jval_(i+1)<=dstep_i t_proj_i Jval_i. If that coefficient is negative,
(4) gives Jval_(i+1)<=Jval_i. In either case

    Jval_(i+1)<=dstep_i max{1,t_proj_i} Jval_i.           (7)

This argument imposes no upper bound on kval_i or eta_i at a long step.
At h_i=2, (5) forces t_proj_i<=1, and (7) is valid with factor1.

Multiplying (6)--(7) proves, with D_word=product_(i<n)dstep_i,

    Jval_n<=Jval_0 D_word exp(E_proj).               (8)

The same product through index n-2 bounds Jval_(n-1). Every factor is
positive. If the actual terminal objective is zero the desired bounds
are automatic, without taking a logarithm of zero.

## 3. The true initial distance and the unrestricted terminal

For EVERY minimizer X_star, 1-smoothness from its zero gradient gives

    f_0<=||X_0-X_star||^2/2,
    q_0<=||X_0-X_star||^2.

For the first inequality, integrate
<grad F(X_star+s(X_0-X_star)),X_0-X_star> from s=0 to1
and use the Lipschitz bound s||X_0-X_star||^2. The second is directly
gradient Lipschitzness. Add half the second inequality to the first
and take the infimum over ALL minimizers:

    Jval_0<=R_init^2.                               (9)

Thus no chosen minimizer is presumed to be closest, and no part of a
dense initial anchor is omitted from the normalization. From (8)--(9),
one immediate general bound is V<=2D_word exp(E_proj).

There is a sharper final-step bound when h_(n-1)=1+a_tail with 0<a_tail<1 and
(A) holds there. Integrating the Lipschitz gradient on that actual step
gives the descent inequality

    f_n<=f_(n-1)-h_(n-1)(2-h_(n-1))q_(n-1)/2
       =Jval_(n-1)-(1-a_tail^2/2)q_(n-1).

Since q_(n-1)>=Jval_(n-1)/(1+a_tail),

    f_n<=[a_tail(a_tail+2)/(2(a_tail+1))]Jval_(n-1).              (10)

There is no terminal support, angle, Markov or value prescription in
(10). Multiply the preceding factors (6)--(7), omit only the last
offset a_tail, and use (9). This proves the general final-short-step form

    V<=C_tail(a_tail) D_word exp(E_proj),
    C_tail(a_tail)=(a_tail+2)/(a_tail+1)<2.                         (11)

For general smoothness L>0, apply the result to F=f/L and the normalized
gradients grad f/L. The actual steps are h_i/L and V is exactly
2(f(X_n)-f_star)/(L dist(X_0,argmin f)^2), as required by W=2R.

## 4. The full Markov anchor price, retained rather than substituted

This section explains explicitly how the obstruction includes the
assigned dense-anchor models. It is NOT proposed as a new sufficient
construction or a free Gram optimization.

Suppose the nonzero QUERIED gradient directions u_i=g_i/A_i,
A_i=sqrt(q_i), 0<=i<n, satisfy the product law

    <u_i,u_j>=product_(k=i)^(j-1)rho_k, i<j,
    -1<=rho_k<=1.                                  (12)

For |rho_i|<1, the canonical innovation is

    e_(i+1)=(u_(i+1)-rho_i u_i)/sqrt(1-rho_i^2).

Expanding its inner products using (12) shows it has norm1 and is
orthogonal to u_0,...,u_i. It is therefore also orthogonal to all earlier
canonical innovations. Put e_0=u_0. Conversely the literal recursion

    u_0=e_0,
    u_(i+1)=rho_i u_i+sqrt(1-rho_i^2)e_(i+1)         (13)

realizes (12) in real coordinates. Degenerate rho_i=+/-1 means
u_(i+1)=rho_i u_i and contributes no canonical innovation.

The corresponding joint sign law is entirely specified by these same
rho_i: for s_sign_i in {-1,1},

    P_sign(s_sign_0,...,s_sign_(n-1))=2^(-n)
                    product_(i<n-1)(1+rho_i s_sign_i s_sign_(i+1)). (14)

It is nonnegative and normalized: summing the last sign gives a
factor2, successively. Equivalently take a fair initial sign and
independent bond signs of means rho_i; this proves (12) for their
moments. Strictly interior rho_i give full support. Neither positivity
of this law nor (13) is asserted to imply interpolation.

Let 0 be any included minimizer and w_(i+1)=<X_0,e_(i+1)>.
Earlier gradients are orthogonal to the innovation, so actual GD and
the definition eta_i=<X_i,g_i>/q_i imply

    eta_(i+1)A_(i+1)
       =rho_i(eta_i-h_i)A_i+sqrt(1-rho_i^2)w_(i+1).

Orthogonal decomposition gives the COMPLETE norm identity

    ||X_0||^2=eta_0^2 q_0
       +sum_(i:|rho_i|<1)
          [eta_(i+1)A_(i+1)-rho_i(eta_i-h_i)A_i]^2
                                      /(1-rho_i^2)
       +||X_perp||^2,                              (15)

where X_perp is orthogonal to all queried gradients. At a degenerate
transition the numerator must be zero, and there is no summand. Formula
(15) accounts for every actual nonzero initial innovation, including
all of them in a dense rule. It is the norm about the included minimizer;
it equals R_init^2 only when that minimizer is closest. The obstruction
uses (9), which is valid for the true radius in ALL cases, instead of
silently identifying these quantities.

For queried transitions the actual projection coefficient is

    t_proj_i=-rho_i A_(i+1)/A_i.                    (16)

Consequently a bound on |rho_i| alone is not the projection cap.
Even an interior, bounded correlation can have t_proj_i>1 when the
next gradient amplitude grows. Conversely, any real rule of the form
g_(i+1)=-t_i g_i+v_i e_(i+1) has t_proj_i=t_i, regardless of its
initial-anchor coefficients. Thus EVERY dense modification of the
previous bounded-rule class retaining t_i<=1 at long steps and (A)
is excluded by (11), without prescribing its q_i, eta_i, z_i, w_i,
or its permitted remote rows. No tiny-coefficient support count is used.

The terminal is still free: the Markov assumptions in this section stop
at index n-1. For the original H_m its last physical step is short, so
the obstruction does not even impose a long-step projection condition
on the actual terminal gradient.

## 6. Quantitative escape requirements, not sufficient conditions

Suppose a family of actual instances satisfying (A) on these words has
liminf B_n V>0. Choose v_0>0 with B_n V>=v_0 eventually. Taking logarithms
in (3) gives the NECESSARY inequality

    E_proj>=n log(1/beta_m)+m log c_m
               -log B_n-log C_tail(a_m)+log v_0.    (21)

Since m log(1/beta_m)->1, log B_n=O(m), and m^2/n->0,

    liminf m E_proj/n >=1.                         (22)

This is a budget of actual strong negative projections, not a claim
that meeting it is useful or legal. It does not replace (15), the
remote interpolation rows, or the terminal payoff calculation.

The only long levels are j>=2: level0 offset a_m<1, level1 offset
beta_m<1, while level2 offset beta_m c_m=sigma(1-1/m^2)>1 for m>=4.
Thus (21) forces useful strong projections at levels at least2; making
the initial anchor dense at the short levels alone does not supply it.

There is a purely analytic count refinement. Let K_proj be the number
of long indices with t_proj_i>1. For such an index of level j, (5)
gives log t_proj_i<=log(beta_m c_m^(j-1))<=(j-1)log c_m.
For every integer r>=1, the number of ALL indices with j-1>=r is at
most N/2^(r+1). Counting the levels of the selected K_proj indices
layer by layer therefore gives, when K_proj>0,

    E_proj <= log c_m sum_(r>=1)min{K_proj,N/2^(r+1)}
           <= (log c_m)K_proj[log_2(N/K_proj)+2].    (23)

For the last inequality put l=floor(log_2(N/K_proj)), which is
nonnegative. Bound the first l summands by K_proj each; the remaining
geometric tail is N/2^(l+1)<K_proj. Replacing l+1 by
log_2(N/K_proj)+2 is a valid weaker bound. For K_proj=0, E_proj=0.

In particular K_proj=o(n/(m log m)) forces E_proj=o(n/m) and is
excluded. To check this limit without any hidden uniformity assumption,
write x=K_proj/N and y=m log m*x. Then y->0 and

    m x log(1/x)
       =(y/log m)[log m+log log m+log(1/y)] ->0,

using y log(1/y)->0. Formula (23) gives the assertion. This count refers
to strong long-step projections, not to the number of nonzero initial
innovation coefficients. No converse is asserted.

For additional precision, equation (4) itself has local multiplier

    1+[dstep_i t_proj_i-1]/kval_i.                      (24)

At a long step this can exceed dstep_i only if

    t_proj_i>1+[(kval_i-1)(dstep_i-1)]/dstep_i.             (25)

Thus t_proj_i>1 can still be insufficient when a positive affine
reserve is paid. At a short step, (5) shows that beating the multiplier
dstep_i is impossible unless kval_i>h_i, equivalently
delta_i>(h_i-1)q_i. Since kval_i=eta_i-z_i/q_i, merely moving the
support eta_i across h_i is insufficient if optimum slack absorbs it.

The next regime is therefore concrete: either build dense real data
with effective long-step anti-alignment beyond (25), of cumulative
size required by (21), or allow an actual short-step VALUE reserve
crossing the physical step. Changing the Markov law alone does not
avoid this obstruction; Sections 2--3 never used that law.
