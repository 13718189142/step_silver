## 1. Exact horizontal lift of one strict-smoothness run

Let f be convex, differentiable and ell-smooth for0<ell<1, with minimum0
attained at0. Fix any finite nonnegative word h of length n and its actual
jets x_i,g_i,f_i, i=0,...,n. Define

    eta_i=<x_i,g_i>-f_i-||g_i||^2/2,
    H_i=sum_(t<i)h_t eta_t,
    Q_ji=f_j-f_i+<g_j,x_i-x_j>+||g_j-g_i||^2/2.

Include a reference label star with g_star=eta_star=f_star=x_star=0.
The standard ell-smooth interpolation inequality gives

    Q_ji <= -gamma||g_j-g_i||^2,
    gamma=(1-ell)/(2ell)>0.

The optimum rows imply eta_i>=gamma||g_i||^2>=0, and
f_i-||g_i||^2/2>=gamma||g_i||^2. If g_i=g_j, both convexity inequalities
give f_i-f_j=<g_i,x_i-x_j>, hence eta_i=eta_j. Thus an equal-gradient pair
has no eta difference even if its original positions differ. If g_i=0,
then f_i=eta_i=0.

For a finite R>0 let

    v_i=(g_i,eta_i/R),
    D_R=conv{0,v_0,...,v_n},
    z_i=(x_i,-R-H_i/R),
    z_star=(0,-R).

This body has AT MOST n+2 vertices and lies in one extra coordinate.
Every eta_i>=0, so z_star belongs to the whole minimum cone D_R^polar of
F_R(z)=max_(v in D_R)(<z,v>-||v||^2/2). Its selected initial distance is
exactly||x_0||.

The exact normal-condition identity for any sampled i and any j including
star is

    <z_i-v_i,v_j-v_i>
      =Q_ji-(H_i+eta_i)(eta_j-eta_i)/R^2.             (1)

For the star label, interpret v_star=0; no z_star term enters this normal
identity. If g_i=g_j, both Q_ji and the eta difference vanish, so the
normal condition is exactly0. Otherwise -Q_ji is strictly positive.

Define the finite nonnegative number

    A=max over sampled i and j in{star,0,...,n} with g_i!=g_j of
      (H_i+eta_i)(eta_i-eta_j)_+/(-Q_ji),

using max empty=0. Then any R>0 with R^2>=A makes EVERY expression in(1)
nonpositive. Since it is affine in v_j, it is nonpositive on all of D_R.
Therefore P_(D_R)(z_i)=v_i at every original physical index, including n.
No normal condition is replaced by an expected or local row.

The literal dynamics are exactly

    z_(i+1)=z_i-h_i*v_i,

because the original horizontal update is x_(i+1)=x_i-h_i*g_i and the
vertical sum increases by h_i eta_i. Thus the SAME ordinary GD word on
one static F_R reproduces the ORIGINAL horizontal trajectory exactly.

At each original sample the actual value is

    F_R(z_i)=f_i-[eta_i H_i+eta_i^2/2]/R^2.          (2)

This follows by expanding <z_i,v_i>-||v_i||^2/2. The value correction is
nonnegative and tends to0. Choosing R even larger retains a positive
terminal value whenever f_n>0. The actual closest radius is then positive
and at most||x_0||, exactly as in the epigraph-body argument. Therefore
the own-closest normalized terminal score is at least

    2[f_n-(eta_n H_n+eta_n^2/2)/R^2]/||x_0||^2.

The body may be degenerate, vertices may repeat, and it is NOT yet claimed
to be a simplex. For every fixed finite run, the maximum defining A is
finite. This is not a uniform in-word conditioning estimate.

## 2. From general1-smooth functions to strict smoothness

Given an arbitrary original1-smooth f with minimum0 at0, choose0<c<1 and
run GD with the SAME physical word h on f_c=c f. Its smoothness constant is
c<1, and its minimum set is unchanged. Its actual trajectory converges
to the original one as c increases to1, by finite induction and continuity
of the gradient. The horizontal trajectories are not asserted identical
at this regularization stage; exactness in Section1 refers to the f_c run.

An explicit comparison is available. With original
M=max_(0<=i<=n)||g_i||, Pi_i=product_(t<i)(1+h_t), the position error obeys

    ||x_i^c-x_i|| <= (1-c)M(Pi_i-1).

Indeed subtract the two updates and bound
||c grad f(x_i^c)-grad f(x_i)|| by c||x_i^c-x_i||+(1-c)||g_i||.
Smoothness and convexity give
|f(x_n^c)-f(x_n)|<=||g_n|| ||x_n^c-x_n||+||x_n^c-x_n||^2/2.
Thus f_c(x_n^c)->f_n. No infimum/limit interchange is required: choose c
for a particular original run and tolerance, then a finite R for its
strict-smoothness run.

This would show that the unrestricted W_n(h) equals the supremum over
projection-body functions generated by at most n+2 points including0,
with their actual complete minimum sets, for every fixed finite h>=0.
The conclusion is again equality of suprema, not finite exact attainment
for arbitrary1-smooth f, and not a schedule-only hard-instance selector.

General L uses L F_R after normalization. Zero steps, repeated samples,
zero gradients and terminal zero values must be handled explicitly in a
complete independent proof. The no-positive-score case is trivial and
must not introduce a closest-radius0 division.

## 3. Optional second mechanism: make the nonzero vertices independent

This paragraph is a PROPOSAL, not an established part of the above proof.
Choose R^2>A strictly. Distinct-gradient pairs then have strict normal
inequalities. Collapse repeated vectors and perturb the distinct nonzero
vertices by tiny separate orthogonal components; retain0 as a vertex.
Use identical perturbations for every occurrence of one repeated vector,
start the added coordinates at0, and recompute ALL actual lifted positions
by the same physical word. The nearby minimum keeps those added coordinates0.
Its dot product with a perturbed vertex is still -eta_i<0 whenever g_i!=0.

The hoped-for argument is that finitely many strict normal inequalities
survive a sufficiently small perturbation; duplicate-vertex inequalities
are exactly0 throughout. The perturbed body would then be a genuine simplex
with0 as a vertex. Objective values, initial distance and full chronological
trajectory would need a quantitative continuity proof. Projecting to the
span of these vertices can only lower the selected initial radius and
preserves their inner products, but must be accounted for explicitly.

Do not call this proposal proved just because the normal matrix is finite.
Check zero-gradient samples, endpoint value positivity, equal-gradient
occurrences at different times, complete minimum sets, dimension count and
whether any supposedly strict constraint is actually active. If it closes,
state the strongest correct finite-vertex/simplex universality theorem.
Otherwise retain Sections1--2 separately and exhibit the exact failed step.

No version of this representation selects a hard original run from h or
