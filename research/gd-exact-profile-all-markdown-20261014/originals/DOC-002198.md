# 2. Interface contracts

Projection U route: one fixed compact convex D containing zero, F_D=max_g(x.g-||g||^2/2), gradient P_D, U_d=max_g(2x.g-d||g||^2). Every claimed U law must hold at arbitrary actual starts and every trailing d>=1, with the real initial maximizer and all original rows. This is not the affine-height residual-gradient class.

Kink route: one fixed odd derivative sign(x) min(B,max(kappa|x|,|x|-(1-kappa))), all B>=kappa>0, true initial radius, all physical steps and the same enclosing m. Gradient capture alone is insufficient because terminal objective changes with core curvature and kink area.

Multi-face route: one fixed K and height vector, gradient X-P_K(X-lambda), with every projection normal, original terminal and actual orthogonal radius retained. A plane reduction needs a finite perpendicular tilt; independent face choices and a reset radius are not legal.

# 3. Dangerous heuristics

Do not promote unverified scalar profiles into a full W bound. Do not erase upper-wing reactivation, equate independently maximized radius and energy, omit the actual initial-maximization remainder, compound an O(1/m) loss once per level without paying the total, or reset the enclosing m in a child. A fixed-face proof is not a changing-face proof. A failed signed certificate is not an interpolable counterexample.
