# Main-owned triangle discovery: one fresh finite batch

Project gd-exact-profile-20260926; original target OPEN. This is a DISTINCT
main-owned discovery allocation. It grants no programs to any existing Danus
or native analytical task and consumes no credit from any closed ledger.

Exactly ten potential mathematical child jobs: two mandatory calibrations,
then eight frozen discovery cases. Each child has a five-second external hard
timeout, with five seconds charged before launch. Maximum fifty accounted
seconds, maximum ten jobs, no retries or correction reserve. A failed
calibration stops discovery and retires all unused jobs. Every failure,
timeout, import, trajectory replay, export and numerical check inside the
child is included. Installation, solver calls, benchmark dynamic programming
and formal verifier calls are zero. Existing shared NumPy software is reused.

The static body is the centered equilateral triangle. All initial points
are real points of its Euclidean plane, all actual GD steps are retained,
and the terminal objective is computed from the same projection potential.
The two discovery grids sample an entire angular fundamental sector with
initial radii up to4D, and selected initial points whose legal constant-vertex
prefix reaches a specified original bridge boundary. Cases use m4,6,8,10,
with the SAME enclosing m in every child. These finite cases lie OUTSIDE
the theorem's m>=1536 range and prove no uniform bound or asymptotic claim.

Sources and case manifest are frozen by hash before the first mathematical
import. Raw initial/terminal arrays, objectives, selected original histories,
projection-normal numerical residuals, process outputs and timings are saved.
No negative value, residual, failed case or parameter is repaired or clipped
afterward. Candidate ratios near one are floating-point evidence only.

Calibration1 includes the full quadratic core and exact Huber-attaining
fixed edge/vertex starts. Calibration2 checks the already derived original
level2 radial-envelope counterexample, its complete constant-vertex prefix,
and projection-normal orientation. These checks calibrate the construction,
objective normalization, chronology and projection operation.

Stop after the frozen batch. Any subsequent mathematics by a program requires
a separate fresh allocation. No publication, fact submission, finalization,
