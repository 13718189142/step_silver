Strict local maximality of full primitive-certificate capacity at the balanced seven-step word.

All vectors and matrices are real. Put q58=sqrt(2), lambda=1+q58, u=q58-1=1/lambda,
    hbar=(q58,2,q58,1+lambda,q58,2,q58), Abar=lambda^3.
Indices of the seven physical steps run from0 to6; indices of coefficient arrays run from0 to7. Let e be the all-ones column in R^8. For h=(h0,...,h6) in[0,infinity)^7 set s=sum_(i=0)^6 h_i and A(h)=1+s. For a real zero-diagonal8-by8 array X set L(X)=diag(Xe)-X. Define the8-by8 matrix T(h) by T(h)_ii=1, T(h)_ij=h_j for j<i, and T(h)_ij=0 for j>i. For a square real matrix K let sym(K)=(K+K^T)/2. Set
    omega(h)=(-2h0,...,-2h6,2s)^T,
    D(h)=diag(h0(2-h0),...,h6(2-h6),-s(s+2)),
    M(h,Lambda)=D(h)+sym(L(Lambda)T(h)).
Call (h,Lambda) feasible if Lambda is a real8-by8 array with Lambda_ii=0, Lambda_ij>=0 for every one of the56 ordered distinct pairs, L(Lambda)^T e=omega(h), and M(h,Lambda) is positive semidefinite on the entire R^8. No symmetry, support, rank, zero-remainder, or equality between formal gradient coordinates is assumed. Nonzero singular positive semidefinite remainders are included.

Define Lambdabar by its following twenty entries, with every other entry equal to zero:
    01:2; 10:2lambda; 13:2lambda;
    21:2lambda*q58; 23:2lambda^2+2lambda*q58; 31:2lambda;
    32:2lambda^3; 37:2lambda^2; 43:2lambda*q58;
    45:2lambda^2; 47:2lambda*q58; 53:4lambda;
    54:2lambda^3; 57:2lambda^3+4lambda; 63:2lambda*q58;
    65:2lambda^3*q58; 67:2lambda^4+2lambda^3*q58+2lambda*q58;
    73:2lambda; 75:2lambda^3; 76:2lambda^5.
Here ij denotes row i, column j. Let E58 be these twenty ordered pairs and Z0 the other36 ordered distinct pairs. The pair(hbar,Lambdabar) is feasible and M(hbar,Lambdabar)=0.

For p in R^7 and a real zero-diagonal8-by8 array Y, let S=sum_(i=0)^6 p_i, let Tp have entry p_j for j<i and zero elsewhere, and put
    op=(-2p0,...,-2p6,2S)^T,
    D1(p)=diag(2(1-hbar_i)p_i for i<7,-2Abar*S),
    W(p,Y)=D1(p)+sym(L(Lambdabar)Tp+L(Y)T(hbar)),
    f(p,Y)=L(Y)^T e-op.
The symbol f(p,Y) denotes this vector-valued flow defect, distinct from scalar objective values in the proof. Define
    C58={(p,Y): f(p,Y)=0, Y_ij>=0 for ij in Z0, W(p,Y) is positive semidefinite on R^8}.
The entries of Y on E58 and all components of p are unrestricted real numbers in this definition. Use the Euclidean norm on physical vectors and the Frobenius norm on arrays, and write
    ||(p,Y)||_* = sqrt(||p||_2^2+||Y||_F^2).

The following intermediate conclusions hold jointly. Every(p,Y) in C58 has S<=0, and S=0 in C58 holds if and only if p=0 and Y=0. Consequently Lambdabar is the unique feasible coefficient array at h=hbar. Every feasible pair with h in[1,4]^7 satisfies sum_(i!=j)Lambda_ij<=2^24. For every sequence of feasible pairs(h_k,Lambda_k) with h_k tending to hbar, the entire sequence Lambda_k tends to Lambdabar; thus this convergence holds uniformly over arbitrary choices of feasible arrays.

For arbitrary displacements p,Y, the exact full-matrix expansion is
    M(hbar+p,Lambdabar+Y)=W(p,Y)+R2(p,Y),
    R2(p,Y)=diag(-p0^2,...,-p6^2,-S^2)+sym(L(Y)Tp),
    ||R2(p,Y)||_F<=13||(p,Y)||_*^2.
Define K58={(p,Y) in C58:||(p,Y)||_*=1}. This set is nonempty and compact, and
    m58=min_((p,Y) in K58)(-sum_(i=0)^6 p_i)>0.

With c=m58/2, there exists epsilon>0 such that for EVERY h in[0,infinity)^7 and EVERY full feasible array Lambda at h, the condition ||h-hbar||_2<epsilon implies
    A(h)<=lambda^3-c*sqrt(||h-hbar||_2^2+||Lambda-Lambdabar||_F^2).
In particular, within this physical neighborhood capacity equals lambda^3 if and only if(h,Lambda)=(hbar,Lambdabar), and every such feasible array satisfies
    ||Lambda-Lambdabar||_F<=(sqrt(7)/c)||h-hbar||_2.
Only h is required epsilon-close in the hypothesis; there is no hypothesis restricting coefficient displacement or selecting a particular certificate. The coefficient estimate is relative to the base, with no assertion of pairwise Lipschitz selection or uniqueness away from the base. No numerical neighborhood radius, global capacity ceiling, or local/global gradient-descent objective minimax optimality is asserted. The original all-word exact-profile problem is not resolved by this local certificate theorem.
