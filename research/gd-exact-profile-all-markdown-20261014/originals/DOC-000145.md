# Methodological source scope: BnB-PEP

Primary sources inspected:
- [Paper](https://arxiv.org/abs/2203.07305)
- [Authors' code](https://github.com/Shuvomoy/BnB-PEP-code)

The paper jointly parameterizes optimization methods and their
performance certificates through nonconvex constrained optimization.
It distinguishes candidate construction from certified global search.
This project borrows only the joint-variable modeling idea for a small
local discovery pilot. It has not implemented the paper's global
branch-and-bound algorithm or imported a theorem from it.

Here the object is the ORIGINAL primitive h/Lambda/full-PSD certificate,
not automatically the paper's chosen performance-estimation objective.
The exact reformulation,all signs/flow/PSD conditions and the actual
seed-to-profile interface must therefore be proved in the project.
Local solver output,finite search restrictions and floating feasibility
are not exact certificates or nonexistence proofs. No package or
commercial solver installation was made by this source inspection.
