## 2. One body, all coordinates, and the full minimum set

    M=sum_(t!=0)b_t^2=1+zeta/N^2,
    T=M+1/R^2,
    w_s=(U_s,1/R) in R^N.

For positive radii sigma_i and the physical Gray labels Gamma(i), put

    v_i=sigma_i w_(Gamma(i)), 0<=i<=n,
    D=conv{0,v_0,...,v_n}, C=cone{v_0,...,v_n}.

vertical coordinate contributes sigma_i sigma_j/R^2 to every Gram

Pairing labels that differ in a bit gives

    sum_s chi_t(s)=0 for t!=0,
    sum_s chi_t(s)chi_u(s)=N*1_(t=u),

where the same statement includes the constant character when needed.
Consequently the full Walsh matrix is invertible. Since all b_t and
1/R are nonzero, the N vectors w_s are linearly independent. Multiplying
the columns by positive radii preserves this property. Thus D is one
full-dimensional simplex in R^N with N+1=n+2 vertices, including 0.
This is proved directly; the separate unverified simplex-universality
candidate is not a premise.

Let

    K(s,u)=<U_s,U_u>,
    E(d)=sum_(t:t dot d=1)b_t^2.

Then

    K(s,u)=M-2E(s+u),
    <w_s,w_u>=T-2E(s+u), ||w_s||^2=T.

The cone C is independent of the positive radii. It is closed: the
linear map with the independent columns w_s is invertible and maps the
closed nonnegative orthant onto C. Its full polar cone is

    C^polar = { (x,y): <x,U_s>+y/R<=0 for EVERY s in G }
            = { (x,y): y<=-R max_s <x,U_s> }.

Define the single static objective

    F_D(z)=max_(g in D) { <z,g>-||g||^2/2 }.

    <z-g,w-g><=0 for every original vertex w of D, including 0.  (2.1)

Necessity follows by differentiating squared distance along each

    <z-z',P_D(z)-P_D(z')> >= ||P_D(z)-P_D(z')||^2.

It follows that P_D is 1-Lipschitz. Comparing the two maximizing affine
expressions shows that the first-order remainder of F_D lies between
0 and ||z-z'||^2, so F_D is differentiable with gradient P_D. It is
finite and convex. An open subset of D has projection equal to the
identity, so its least global Lipschitz gradient constant is exactly 1.

Because 0 belongs to D, F_D>=0. If z belongs to C^polar, every inner
product <z,g> is nonpositive and F_D(z)=0. Conversely, if <z,v_j>>0,

for a sufficiently small positive t. Hence the FULL attained minimum is

    argmin F_D=C^polar, min F_D=0.                         (2.2)

## 3. Physical Gray order and the adjacent necessary condition

Let Gamma(i)=i xor floor(i/2), with m binary bits. If l=nu_2(i+1),
then the bits of i below l are 1 and bit l is 0. Incrementing i flips
exactly bits 0 through l. Taking xor with the shifted label cancels
these changes except at bit l. Thus

    Gamma(i+1)=Gamma(i)+e_l, l=nu_2(i+1).                  (3.1)

This is the original chronological order, not a permutation of the
word. In particular the first three labels are

    Gamma(0)=0, Gamma(1)=e_0, Gamma(2)=e_0+e_1,

and the two corresponding physical steps are H_0 and H_1.

For a fixed bit l, exactly N/2 character labels have t_l=1. Of these,
exactly one is independent, namely e_l. Consequently

    E_l=E(e_l)=2^l/(N-1)+zeta (N/2-1)/(N^2 Kmix),
    t_l=1-2E_l/T.                                        (3.2)

Every E_l is strictly between 0 and M, so -1<t_l<1.
For an adjacent pair p=sigma w_s and q=sigma r w_(s+e_l),
suppose one physical step H=H_l gives

    P_D(z)=p, z'=z-Hp, P_D(z')=q.

Write d=q-p, r_z=z-p, r_z'=z'-q. The two original normal
inequalities against the other vertex are

    <r_z,d><=0, <r_z',d>>=0,
    r_z-r_z'=(H-1)p+q.

Therefore

    <(H-1)p+q,q-p><=0,

or, after dividing by sigma^2 T,

    r^2+(H-2)t_l r+1-H<=0.                              (3.3)

The constant term is negative because H>1, so the quadratic has one
negative root and one positive root. The positive root is exactly

    rho_l=(-(H_l-2)t_l+
        sqrt((H_l-2)^2 t_l^2+4(H_l-1)))/2.

At r=1 its polynomial equals (2-H_l)(1-t_l). Thus

    0<rho_l<1 if H_l<2,
    rho_l>1 if H_l>2.

When r=rho_l, (3.3) is equality. The two original normal
inequalities then have the SAME inner product, one nonpositive and one
nonnegative, and hence

    <r_z,d>=<r_z',d>=0.                                 (3.4)

This equality consequence is the source of the remote obstruction.
Condition (3.3) by itself is only necessary, not sufficient for a
single static projection potential or for global interpolation.

already been included in T in every one of these entries.

    <r_2,p_0-p_2><=0.

    B=u[(beta+v) A + 2 v f(1-u) - 4 v J],

    A=2e a(1+u)/(u+a)>2e a,                            (4.5)

since a<1 and u>0. Both u and v lie strictly between 0 and 1 by

    2a>2/3>1/4.

Therefore 2e a>4J and B>0. This contradicts the required normal row.
It proves Claim I for every m in the requested domain, with no
restriction on R and with no dependence on theta. QED.
