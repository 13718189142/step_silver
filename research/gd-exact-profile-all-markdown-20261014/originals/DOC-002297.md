## Direct calculation of the local roots from static hard functions

Fix ANY predetermined nonnegative word with a selected step alpha>1. Let x be its total mass before that step, y its total mass after it, C=1+x, k=alpha-1. For r>0 define one fixed global gradient g(z)=clip(z,-r,1), with f(z)=integral_0^z g(t)dt and original start z0=C. This f is convex, differentiable and1-smooth, with unique minimum0. Every prefix query stays at least1 and has gradient1, so the pivot input is1 and its output is-k.

Choose r=k/(2y+1). Every remaining query and the terminal stay at most-r, since the terminal is-k+y*r=-(y+1)*r. Their gradient is-r. Direct integration gives

    2f_terminal/C^2 = k^2/[C^2(2y+1)].

The Huber lower witness for the whole word has value1/D, where D=1+2(x+alpha+y)=2C+2k+(2y+1). These two actual full-word witnesses balance exactly when

    k^2 D=C^2(2y+1).

With B=2y+1, the difference factors as

    k^2(2C+2k+B)-C^2B=(k+C)(2k^2+Bk-CB).

The positive root of the second factor gives alpha=psi(x,y). Thus the objective bridge root has a concrete two-ray hard-function interpretation, with all chronology and original radius paid. This is the familiar single-cut type of lower witness, not a claimed new complete adversary.

For the primitive endpoint test, instead choose r=k/(1+y). The same fixed-function trajectory ends exactly at-r. Its primitive quadratic is

    V=C^2-[(x+alpha+y+1)r]^2.

Writing C_R=1+y, its sign changes at

    k(C+C_R+k)=C C_R,

which is alpha=phi(x,y). On this projection-Huber function the original minimizer interpolation rows are zero, so the primitive retained energy is V/2. A negative primitive energy is NOT a useful objective lower bound by itself.

## Actual closure task, not a reformulation

These local roots explain what must be preserved in a recursive adverse construction, but do not supply it. Repeating independent caps after each cut changes the function; directly adding independent functions makes all their coordinates evolve during every step, so it does not concatenate trajectories. Optimizing only the above one-cut witnesses must not be asserted sufficient.

The intended substantive step is an actual finite-dimensional static interpolation construction that retains every earlier query when a primitive-type and dominant-type adverse history are joined. It must pay the cross-history constraints, true initial distance and final objective, and prove a loss that stays1+o(1) after an arbitrary-word decomposition. A second necessary step is to prove that an appropriate split/decomposition exists for EVERY nonnegative word, including zeros and extreme steps; the schedule is not assumed recursive.

If those steps are not proved, naming a typed Bellman value, an equivalent SDP, or a 'gluing lemma' of the same strength as the original target is not a result. The current two displayed local calculations are only calibration for a direct proof attempt. No new numerical job, formal submission or independent model is authorized by this note.
