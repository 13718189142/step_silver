# A concrete affine completion for the variable-matrix repair lane

Status: new self-contained candidate algebra, NOT verifier-accepted. This is
an explicit parameterization for the next proof attempt, not a re-selection
theorem or a strict cone separation. No numerical solver or fact_submit.

## Definitions and full matrix identity

Fix h=(h_0,...,h_(n-1))>=0 with sum s>0. All n+1 formal gradients are independent.
Let x_i=x_0-sum_(t<i)h_t g_t, and define the actual Q_ij and intrinsic V_h by

 Q_ij=f_i-f_j+<g_i,x_j-x_i>+||g_i-g_j||^2/2,
 V_h=2sum_(i<n)h_i(f_i-f_n)+sum_(i<n)h_i(1-h_i)||g_i||^2
                                               -s(s+1)||g_n||^2.

Define the column e of n+1 ones, the lower triangular matrix A with A_ii=1
and A_it=h_t for t<i, and r=A^(-1)e. Thus r_0=1 and
r_(i+1)=(1-h_i)r_i. The vectors e,r are independent because s>0.
Write omega=(-2h_0,...,-2h_(n-1),2s)^T and

 D_quad=diag(h_0(2-h_0),...,h_(n-1)(2-h_(n-1)),-s(s+2)),
 c_quad=1-(1+s)^2 r_n^2.

For a real off-diagonal multiplier array lambda, put
L=diag(lambda e)-lambda. Value cancellation in V_h+sum lambda Q is exactly
L^T e=omega. By definition L e=0. The COMPLETE formal gradient matrix is

                 M=D_quad+sym(L A),                 (1)

where sym(B)=(B+B^T)/2. To check this, the position contribution is
sym(L(A-I)). The squared-difference terms are sym(L)-diag(omega)/2.
Adding the diagonal terms in V_h gives exactly (1).

## Which PSD matrices admit some real multiplier representation?

Claim. A symmetric PSD matrix M has a real multiplier representation (1)
with the actual value cancellation if and only if

                    M e=0, r^T M r=c_quad.           (2)

This permits arbitrary real multiplier signs; the actual sign restrictions
for a primitive or E_theta certificate remain separate and are not deleted.

Necessity: evaluating the value-canceling identity on the affine Huber run
with every gradient equal to1 gives e^T M e=0, hence M e=0 by PSD.
The full-curvature quadratic trajectory has gradients r_i and every Q_ij=0.
Telescoping h_i(2-h_i)r_i^2=r_i^2-r_(i+1)^2 gives
r^T D_quad r=1-(1+s)^2 r_n^2=c_quad, and evaluating the same identity on
that legal quadratic gives the second assertion in (2).

Here is an explicit sufficiency construction. Put C=M-D_quad and set

 U=[e,r], Z=[C e-A^T omega,-C r], H=U^T U, W=U^T Z.

The two-by-two matrix H is positive definite. The matrix W is skew-symmetric:

 e^T C e=omega^T A e=s^2+sum h_i^2,
 r^T C r=0,
 e^T(-C r)+r^T(C e-A^T omega)=-omega^T A r=-omega^T e=0.

The first equality uses M e=0 and the displayed diagonal D_quad, and the
second uses r^T M r=r^T D_quad r. Define

 K_0=Z H^(-1)U^T-U H^(-1)Z^T
                          -U H^(-1)W H^(-1)U^T.     (3)

It is skew-symmetric, and multiplication by U gives K_0 U=Z: the last
two correction terms cancel because Z^T U=-W. Now put

 B=C+K_0, L=B A^(-1), lambda_ij=-L_ij for i!=j, lambda_ii=0.

The relations K_0 r=-C r and K_0 e=C e-A^T omega give
L e=B r=0 and L^T e=A^(-T)B^T e=omega. Thus L is precisely the row
Laplacian of its extracted off-diagonal array, and its flows cancel every
actual value coefficient. Also sym(L A)=C, proving (1).

All representations of this same M arise by replacing K_0 with K_0+S,
where S is any skew-symmetric matrix satisfying S e=S r=0. Indeed their
difference must be skew after multiplying L by A, and must kill both e,r;
the converse follows from the same equations. This also recovers directly
the fixed-remainder obstruction already independently proved earlier.

Consequently a PSD real-multiplier identity with no sign restrictions exists
if and only if c_quad>=0. For sufficiency, let
z=r-e(e^T r)/(e^T e), so z!=0 and r^T z=||z||^2. The rank-one choice

                 M=c_quad z z^T/(r^T z)^2

satisfies (2); use (3). The case c_quad=0 allows M=0. This consequence is
NOT a smooth-convex validity theorem: unrestricted negative multipliers can
invalidate such an implication. It merely separates the full PSD condition
from the indispensable actual interpolation sign inequalities.

## Concrete next interface for four positive steps

If n=4 and the schedule is quadratic-balanced, c_quad=0, every permitted PSD
matrix must annihilate both e and r. The space orthogonal to span{e,r} has
dimension3. Thus M is an arbitrary PSD three-by-three matrix on that space,
and the free S in (3) has three independent skew entries on that same space.
All twenty actual multipliers are then EXPLICIT affine functions of these
six symmetric and three skew coordinates, through (3).

The actual E_theta requirements remain

 lambda_ij>=0 for j!=4,
 lambda_i4>=-theta h_i for i<4, 0<=theta<1.

Ordinary primitivity requires lambda_i4>=0 as well. A successful repair must
move the symmetric M coordinates, not just S: the earlier unit-step family
already refutes fixed-M repair in arbitrarily many positive steps. No change
to M is declared PSD merely because its scalar quadratic calibration is
correct; all three eigen-directions in the displayed quotient must remain
PSD and every multiplier sign must be checked.

The next concrete attack is to start on a four-step quadratic-balanced face
and either construct such a simultaneous M/S repair for one negative terminal
edge, or give an exact E_theta identity and a legal negative-V witness for
the same actual schedule. Physical capacity and objective amplification are
additional obligations. This note supplies neither outcome and does not
claim the general cone problem solved. All new algebra is shared research
evidence only; no fact was added to the graph.
