## 3. A complete crossing-clock inequality

Abbreviate p=p_grow, beta=1-p and C=C_grow. On either ray define

    Clock_sigma(t)=integral_1^t dv/G_sigma(v), t>0.

It is log t in the core. Outside the core put q_t=t/G_sigma(t).
The derivative condition gives q_t'>=beta/G_sigma(t), and hence

    Clock_sigma(t)<=(q_t-1)/beta, t>=1.            (13)

For every h>1 and every strict overshoot z=hG_sigma(t)-t>0,

    Clock_sigma(z)<= C h-1/beta.                  (14)

Here h is a normalized stepsize mu d_j, not the physical stepsize d_j.
We prove all cases, including short crossing steps and core endpoints.

If z<=1, the bound G_sigma(t)<=t^p holds for every t>=0, also inside the
core. Maximizing h t^p-t by differentiation gives

    z<=(beta C h)^(1/beta).

Thus log z<=log(beta C h)/beta<=C h-1/beta.

If z>=1 and t<=1, then h>=2, and monotonicity gives
Clock_sigma(z)<=z-1<=h-2. This is <=C h-1/beta because
C>=1/(2beta). To prove the latter, the function
p log p+beta log beta is increasing for p>=1/2 and equals-log2 at1/2;
therefore beta C=p^p beta^beta>=1/2.

If z,t>=1 and z>=t, monotonicity and (13) yield

    Clock_sigma(z)<=(q_t-1)/beta+(z-t)/G_sigma(t)
                   =h+(1/beta-2)q_t-1/beta
                   <=h/(2beta)-1/beta<=C h-1/beta,

where q_t<=h/2 and p>=1/2 were used.

Finally, if1<=z<=t, integrating (2) between z and t gives
G_sigma(z)>=G_sigma(t)(z/t)^p. Therefore

    z/G_sigma(z)<=q_t^p(h-q_t)^beta
                  <=p^p beta^beta h=beta C h.

The maximum in the last inequality occurs at q_t=p h; this follows by
differentiating p log q+beta log(h-q). Equation (13) proves (14).

Write D=C h-1/beta. If a crossing lands on the other ray, its new clock
is at most kappa_ray D when D>=0: use the pointwise profile comparison
and integrate if z>=1; for z<1 the new clock is negative. If D<0,
(14) forces z<1, and BOTH ray clocks equal log z, so the new clock is
at most D, with no comparison-factor loss. A noncrossing nonzero step
reduces its own clock by at least h, since

    integral_(t-hG_sigma(t))^t dv/G_sigma(v)>=h.

We also have Clock_sigma(t)<=t-1 for all t>0, using G_sigma>=1 outside
the core and log t<=t-1 inside it.

## 4. Reciprocal cores: every crossing is annihilated

Assume (4), and put sigma_clock=kappa_ray C and
tau_clock=kappa_ray/beta. The function C=(p/(1-p))^p increases for
p>=1/2, so C<=3^(3/4)<23/10. In particular the class is nonempty
throughout the asserted p range. Also (10) gives

    sigma_clock<=23/10<1/r_s.

Since p/beta>=1 and p<=1, C<=(p/beta), so

    tau_clock-sigma_clock=kappa_ray(1/beta-C)>=1.  (15)

If a trajectory ever reaches zero, it stays there. Otherwise choose its
last strict crossing. A crossing requires h=mu d_j>1 because G_sigma(t)<=t.
Thus its level j is greater than r. Every occurrence of d_j in the ruler
is immediately followed by a complete H_j. This copy of H_j contains a
last occurrence of d_r, followed by H_r. The physical mass before that
last d_r, measured from the start of this copy of H_j, is

    S_j-S_r-d_r.                                 (16)

Suppose the overshoot radius z is greater than1. Section3 bounds its
target clock by sigma_clock d_j/d_r-tau_clock. Define
D_j=S_j-sigma_clock d_j. By (1),

    D_j=a(1/r_s-sigma_clock)c^j+(1-A_mass)2^j-1-sigma_clock

is increasing. Consequently

    S_j-S_r-d_r-(sigma_clock d_j-tau_clock d_r)
      =D_j-D_r+(tau_clock-sigma_clock-1)d_r>=0.    (17)

There is no subsequent crossing by our choice of the last one. Each
subsequent nonzero step decreases the target clock by its normalized
stepsize. Equations (16)-(17) force the path into the core by the last
d_r in that copy of H_j. If z<=1 it is already in the core; a
noncrossing core step keeps it there. The last d_r then maps x to
x-d_r mu x=0. This proves the annihilation assertion without assuming
that an arbitrary earlier core entry is permanent.

For completeness, a run with no crossing, on either ray, has final
radius v and gradient magnitude u. Monotonicity gives
|x_0|>=v+S_m u. Since the actual derivative is mu-Lipschitz,

    f(x_n)<=u v-u^2/(2mu).

This follows by integrating the bound |g(t)|<=min(mu|t|,u) from0 to
the final point. Therefore

    2f(x_n)<=2|x_0|u-(2S_m+1/mu)u^2
             <=x_0^2/(2S_m+1/mu).                 (18)

For G_+=G_-=min(t,1), start at x_0=R(1+2mu S_m). Every gradient on
the trajectory equals mu R, all iterates remain beyond the core, and
x_n=R(1+mu S_m). Substitution into (9) gives equality in (18).
Together with annihilation this proves (5), including r>=m.

## 8. Scope and the next real gap

No external theorem was used as a black box. Exact scalar-order/area
constructions and the earlier fixed13/5 clock arguments informed this
choice of family, but every estimate on the actual near-critical word
has been derived here, with uniform constants.

The restrictions are substantive: a common quadratic neighborhood;
outer logarithmic slope at most3/4 in the reciprocal case, or2/3 in
the small-curvature nonresonant case; a specified ray-comparison bound;
and, for the latter case, mu<=1/d_2. General nonresonant curvatures
above1/d_2, independent core curvatures, outer ramps with logarithmic
slope near or above1, or profiles without a common quadratic core are
not covered. No upper bound on all scalar functions, no unrestricted
W_n upper bound, and no completion of the project target is asserted.

There is an exact countertest against silently removing resonance from
the annihilation conclusion. Take mu=1, G_+=G_-=min(t,1), R=1, and
epsilon=[2 product_(h in H_m)(1+h)]^(-1)>0 as the initial point.
Every prefix radius is below1/2, by induction using the bound1+h for
each update, so the whole trajectory uses g(x)=x. All h=d_j exceed1;
therefore every update strictly crosses zero and none reaches it.
Its final normalized objective is the strictly positive quantity

    product_(h in H_m)(h-1)^2
      =(ac)^(2(2^m-1)) c^(-2m).

For the last identity, the multiplicity of d_j is2^(m-j-1), the total
is n=2^m-1, and the multiplicity-weighted sum of j is n-m (induction
in m verifies this identity). This refutes the extended annihilation
claim, not an objective bound at K. Also S_1/d_1<3/4 and
S_2/d_2<3/2 on the actual parameter range, so the uniform7/4 waiting
budget used in Section5 cannot be imported to the first three levels.
The latter strict inequality follows from
S_2-(3/2)d_2=3/2+a(2+c-(3/2)c^2)<0 using a>2/5,c>12/5.
