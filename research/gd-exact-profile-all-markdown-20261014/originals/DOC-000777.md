# Variable-step interval matrices and their first exact obstruction

Status: unverified analytic identities and a complete three-step test, not an improved schedule. This extends the matrix construction in Zhao, arXiv:2609.11784v1, Sections3.1–3.3, whose definitions and proof were read from a local downloaded/extracted copy. No external theorem is needed for the calculations below. The authorized numerical budget remains exhausted.

Work at L=1 with x_(i+1)=x_i-h_i g_i, i=0,...,n-1. Define the trajectory matrix T by T_ii=1, T_ij=h_j for j<i, and T_ij=0 for j>i. The symbol T is used to avoid confusion with the benchmark denominator B_n. Thus (Tg)_i=g_i+x_0-x_i.

For any matrix C with zero row sums, write b=C^T1 and H=CT+T^TC^T. Define the nonnegative interpolation quantity

  I_ij=2f_i-2f_j-2<g_j,x_i-x_j>-||g_i-g_j||^2.

It equals -2Q_ji in the project's sign convention. Direct expansion gives

  sum_(i,j) C_ji I_ij
  =2sum_i b_i f_i+sum_(i,j) H_ij<g_i,g_j>-sum_i b_i||g_i||^2.    (A)

Diagonal entries of C are immaterial to the sum because I_ii=0. If C has nonnegative off-diagonal entries, the left-hand side is nonnegative on every legal trajectory.

## 1. Interval diagonalization survives arbitrary steps

Fix0<=a<b<=n and positive numbers w_a,...,w_b. Put

  L_i=sum_(a<=j<i)w_j, R_i=sum_(i<j<=b)w_j,
  u_i=h_i(L_i+w_i)-w_i,
  v_i=w_i+h_i R_i.

At i=n choose any auxiliary h_n: all formulas in which it could affect the matrix cancel because R_n=0 and no entry lies above its diagonal. Define C^(a,b;w), zero outside the interval, by

  C_ij=u_i w_j for a<=i<j<=b,
  C_ij=v_i w_j for a<=j<i<=b,
  C_ii=-u_i R_i-v_i L_i.

Its row sums vanish. For i<j in the interval,

  (CT)_ij=u_i(w_j+h_j R_j)=u_i v_j,
  (CT)_ji=v_j(w_i-h_i(L_i+w_i))=-v_j u_i.

For a column before a, its entries vanish because the row sum is zero; for a column after b, its entries vanish by triangularity. Hence H=CT+T^TC^T is diagonal, with

  H_ii=2[(h_i-1)u_i R_i-v_i L_i].                    (B)

If h_i>=1 for a<=i<b, all off-diagonal entries of this interval matrix are nonnegative. For the special choice w_i=1, put s=i-a and t=b-i. Formula(B) becomes

  H_ii=2[(h_i-1)^2(s+1)t-s(t+1)].                   (C)

This is the constant-step paper's diagonal formula with the actual local step h_i inserted; no equality of the steps was needed for diagonalization.

## 2. The primitive coefficient target

Let S=sum_(i<n)h_i. The saturated primitive intrinsic potential is

  V_h=2sum_(i<n)h_i(f_i-f_n)
      +sum_(i<n)h_i(1-h_i)||g_i||^2-S(S+1)||g_n||^2.

Thus(A) equals V_h exactly when

  b=(h_0,...,h_(n-1),-S),
  H=diag(h_0(2-h_0),...,h_(n-1)(2-h_(n-1)),-S(S+2)).   (D)

Nonnegative off-diagonal entries of C then certify V_h>=0. This is a sufficient certificate class with zero PSD remainder, not a necessity claim for arbitrary primitive schedules.

There is an algebraic prerequisite for(D). Set p_0=1 and p_(i+1)=(1-h_i)p_i. Then Tp=1, so C1=0 implies p^THp=0. For the target(D), telescoping gives

  p^THp=1-(S+1)^2p_n^2.

Therefore a certificate of this exact diagonal form requires |p_n|=1/(S+1). A schedule with strict slack in the full-curvature quadratic test requires a nonzero PSD remainder or another quadratic coefficient pattern. This is a structural limit of the ansatz, not a failure of the schedule itself.

## 3. Positive interval coefficients exclude the basic three-step silver block

Let a=sqrt(2), lambda=1+a, and h=(a,2,a). Use the unweighted modes C^[i,j] from part1 with w=1, and write their coefficients as z_01,z_12,z_23,z_02,z_13,z_03.

Suppose all six z are nonnegative and the target(D) is matched. At index0 the diagonal equation gives

  z_01+2z_02+3z_03=lambda.

The column-sum equation b_0=a gives

  (2-a)z_01+(6-2a)z_02+(10-2a)z_03=a.

Since (2-a)lambda=a, subtracting the first equation times(2-a) yields

  2z_02+(4+a)z_03=0.

Nonnegativity forces z_02=z_03=0 and z_01=lambda. The diagonal equation at index1 becomes

  z_12+2z_13=lambda.

The cumulative column sum through cut1 is a+2. With z_02=z_03=0, only the [1,3] mode has a nonzero cut flow; that flow is a per unit coefficient. Therefore a z_13=a+2, so z_13=lambda and z_12=-lambda, a contradiction.

Consequently the direct positive-mode generalization of the constant-step proof is too narrow even for this basic silver schedule. This is a hostile test of the proposed proof class, not a counterexample to silver validity.

Signed interval coefficients repair the problem while every actual interpolation multiplier remains nonnegative. Choose

  C=lambda C^[0,1]-lambda C^[1,2]
      +lambda C^[1,3]+2lambda^2 C^[2,3].             (E)

Its only nonzero off-diagonal entries are

  C_01=1, C_10=lambda, C_13=lambda,
  C_21=2+a, C_23=5+3a,
  C_31=lambda, C_32=7+5a.

Every listed entry is positive. Setting each diagonal to minus its row sum gives b=(a,2,a,-2lambda). Formulas(C) give H=diag(2a-2,0,2a-2,-(2lambda)(2lambda+2)), so(D) is met. Hence(A) is an exact conic interpolation certificate for the three-step silver block. The apparent negative coefficient in(E) is only a coordinate in the interval basis; it is not a negative interpolation multiplier.

## 4. Explicit elimination of the lower-triangular unknowns

For arbitrary h_i>1, any zero-row-sum matrix C with diagonal CT+T^TC^T is uniquely determined by its strict upper triangle U_ij=C_ij, i<j. Write r_i=h_i-1. For a row j>i define L_(j,i)=sum_(k<=i)C_jk, with L_(j,-1)=0. The off-diagonal equation at(i,j) is exactly

  r_i L_(j,i)+L_(j,i-1)
    =U_ij+h_j sum_(k>j)U_ik.                        (F)

For j=n the sum is empty, so h_n is again immaterial. Starting at i=0, equation(F) gives the lower entries C_ji=L_(j,i)-L_(j,i-1) without matrix inversion. Conversely this recursion and the zero row sums make every off-diagonal entry of CT+T^TC^T vanish, so there are no omitted constraints.

All interpolation coefficients are nonnegative precisely when U_ij>=0 and every computed difference L_(j,i)-L_(j,i-1)>=0. The remaining column sums and diagonal conditions(D) are linear equations in U for a fixed step vector. Thus this specific zero-remainder certificate class has an exact system of scalar linear equalities and inequalities, with no PSD feasibility test left over. This does not assert that the class captures the full primitive PEP or that the step optimization is convex.

The next analytic task, if this interface is pursued, is a variable-step family and a symbolic solution of those inequalities, including aggregate positivity after signed interval cancellation. Producing the interface alone is not asymptotic progress. Any candidate must still beat the exact benchmark or meet the sufficient amplification threshold proved conditionally in research/max4_primitive_seed_amplification.md.
