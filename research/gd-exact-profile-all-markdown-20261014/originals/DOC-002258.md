## 1. Exact matrix mode for an arbitrary positive word

Let the physical word be h_0,...,h_(n-1), with h_i>=1 for this mode construction. Let B be the (n+1)-square trajectory matrix

    B_ij=h_j for j<i, B_ii=1, B_ij=0 for j>i.

Fix a contiguous interval [a,b] of query indices, a<b. Choose positive weights z_i,v_i for i in[a,b], and set

    Z_i=sum_(a<=k<=i) z_k,  Z_i^-=sum_(a<=k<i) z_k,
    V_i^+=sum_(i<k<=b) v_k, V_i=v_i+V_i^+,
    u_i=h_i Z_i-z_i, w_i=v_i+h_i V_i^+.

The value h_b is irrelevant wherever b is the terminal query: u_b has no upper entries and w_b=v_b. It can be given any dummy value without changing the matrix. Define

    C_ij=u_i v_j for a<=i<j<=b,
    C_ij=w_i z_j for a<=j<i<=b,
    C_ii=-sum_(j!=i) C_ij,

with entries outside the interval zero. Every off-diagonal entry is nonnegative, because u_i=h_i Z_i^-+(h_i-1)z_i>=0 and w_i>0. Every row sums tozero.

For i<j in the interval,

    (CB)_ij=u_i(v_j+h_j V_j^+)=u_i w_j,
    (CB)_ji=w_j(z_i-h_i Z_i)=-w_j u_i.

The second equality uses the zero row sum. Entries of CB outside the interval vanish: earlier columns are h_j times a zero row sum, and later columns are zero by triangularity. Therefore H=CB+B^T C^T is DIAGONAL, with

    H_ii=2[(h_i-1)^2 Z_i V_i^+ - Z_i^- V_i].        (1)

For i=b this is -2 Z_b^- v_b, independent of the dummy h_b. To check(1),

    (CB)_ii=(h_i-1)u_i V_i^+ - w_i Z_i^-
            =(h_i-1)^2 Z_i V_i^+ - Z_i^- V_i.

With constant h and z=v=1 this reproduces the source's interval mode. For variable h it keeps the ACTUAL physical trajectory matrix, not a reparameterized clock. No smoothness or interpolation condition is changed.
