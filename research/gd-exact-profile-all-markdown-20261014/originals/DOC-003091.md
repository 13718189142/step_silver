## 1. Exact object and the two divergence equations

For an integer r>=1, let h=(h_0,...,h_(r-1)) be an original nonnegative
physical word, s=sum_i h_i, A=1+s, n=r+1, and e the all-ones vector in
R^n. All n original formal gradients remain separate variables. Define

    T_ii=1, T_it=h_t if t<i, T_it=0 if t>i,
    z=T e, so z_i=1+sum_(t<i)h_t and z_r=A,
    Z_diag=diag(z),
    omega=(-2h_0,...,-2h_(r-1),2s)^T,
    D=diag(h_i(2-h_i) for i<r,-s(s+2)).               (1)

For every real n-by-n array Lambda with zero diagonal, set

    L=diag(Lambda e)-Lambda,
    M=D+(L T+T^T L^T)/2.

The equality space of interest is exactly

    L^T e=omega,                 M e=0.             (2)

The original certificate additionally requires Lambda_ij>=0 for EVERY
i!=j and M>=0 on ALL of R^n. At this stage the off-diagonal entries
are allowed to be arbitrary real numbers so that coverage of the whole
equality space, before inequalities, can be established.

For any zero-diagonal real matrix X define two divergences

    d(X)=X e-X^T e,
    d_z(X)=X z-Z_diag X^T e=d(X Z_diag).                      (3)

Both have coordinate sum zero. The weighted matrix in (3) is X Z_diag,
whose (i,j) entry is X_ij z_j; it is NOT Z_diag X. No division by z_i is
involved.

The elementary identity driving the construction is

    2D e+T^T omega=-Z_diag omega.                         (4)

Here is every coordinate of its verification. For i<r put
p_i=sum_(t<i)h_t, so z_i=1+p_i. Then

    (T^T omega)_i=-2h_i+h_i sum_(k=i+1)^r omega_k
                 =-2h_i+2h_i(p_i+h_i).

Adding 2h_i(2-h_i) gives 2h_i(1+p_i)=-z_i omega_i.
At i=r the left side is -2s(s+2)+2s=-2s(s+1), also
-z_r omega_r. Thus (4) holds even at zero steps.

If d(Lambda)=L^T e=omega, then

    2M e=L z-Z_diag omega=-d_z(Lambda).                   (5)

Indeed L z=Z_diag Lambda e-Lambda z, so
Z_diag d(Lambda)-L z=Lambda z-Z_diag Lambda^T e. It follows that

    (2) is equivalent to d(Lambda)=omega,
                         d_z(Lambda)=0.             (6)

No equation has been dropped: the equivalence holds coordinate by
coordinate on all n vertices. The two zero-sum identities are the
only redundant equations on the nondegenerate domains proved below.

Nor does (2) impose an additional restriction on an original PSD
certificate. Under value flow one has

    e^T D e=-(s^2+sum_i h_i^2),
    z^T omega=s^2+sum_i h_i^2,
    e^T M e=0.                                      (7)

For the second equality use
2 sum_i h_i sum_(t<i)h_t=s^2-sum_i h_i^2. If a symmetric
matrix M is PSD and e^T M e=0, then for every real vector v the
nonnegative quadratic (e+t v)^T M(e+t v) has zero constant term;
its linear coefficient 2e^T M v must be zero. Hence M e=0.
Consequently retaining (2), all original signs, and full PSD is exactly
equivalent to the original full certificate conditions at the same h.

## 2. General tree chart: explicit formulas and both directions

Fix ANY undirected spanning tree on {0,...,r}. Give each of its r
edges an orientation u_l -> v_l. Delete that edge and let S_l be
the component containing u_l. Write

    Delta_l=z_(u_l)-z_(v_l).

The chart domain is

    U_tree={h: Delta_l!=0 for every tree edge l}.     (8)

The original positive-word domain (0,infinity)^r is contained in
U_tree for every tree, since z_0<...<z_r. The formulas also apply to
any nonnegative boundary point lying in U_tree. More generally their
algebra is valid for real h in (8), though signed physical steps are
outside the original problem.

For EACH ordered off-diagonal pair whose unordered pair is not a tree
edge, introduce an INDEPENDENT real coordinate N_ij. There are

    n(n-1)-2r=r(r-1)

such coordinates. Define N to have these entries, zero diagonal, and
zero on both directions of each tree edge. For each tree cut compute

    alpha_l=sum_(i in S_l) omega_i
             -sum_(i in S_l,j not in S_l)(N_ij-N_ji),
    beta_l=-sum_(i in S_l,j not in S_l)
                                (N_ij z_j-N_ji z_i). (9)

Terms with tree pairs in these sums are zero by the definition of N.
The chart Phi_tree(h,N) is the following COMPLETE array:

    Lambda_ij=N_ij                         off the tree,
    Lambda_ii=0,
    Lambda_(u_l,v_l)=(z_(u_l) alpha_l-beta_l)/Delta_l,
    Lambda_(v_l,u_l)=(z_(v_l) alpha_l-beta_l)/Delta_l. (10)

Only the explicitly nonzero Delta_l are denominators. In particular
there is no denominator h_i-1, h_i-2, 1-product(1-h_i), determinant
of an unspecified matrix, or fitted completion.

Proof of the construction and coverage. For an edge oriented u->v
with coefficients a=Lambda_uv and b=Lambda_vu, its contributions to
the two divergences in (6) are, respectively,

    (a-b)(e_u-e_v),
    (z_v a-z_u b)(e_u-e_v).                         (11)

Summing either divergence over S_l cancels all edges internal to
S_l or to its complement. The ONLY tree edge crossing S_l is edge l.
Thus (6) requires exactly

    a-b=alpha_l,        z_v a-z_u b=beta_l.           (12)

Solving this displayed two-by-two system with Delta_l!=0 gives (10).
Conversely those formulas satisfy BOTH equations in (12) exactly.

It remains to prove that all these cut equations force every vertex
equation, rather than only some aggregation. Let q be either residual
vector d(Lambda)-omega or d_z(Lambda). Its coordinate sum is zero.
If every tree cut sum of q is zero, choose a root for the tree.
Every subtree cut has zero sum: it is either S_l or its complement,
and q has total sum zero. A nonroot leaf therefore has q_i=0.
Inducting upward, the subtree sum at a nonroot vertex and all its
child subtree sums being zero imply q_i=0. The root then follows
from total sum zero. This proves q=0, and therefore (6) and (2).

Now start with ANY original real Lambda satisfying (2) at h in
U_tree. Read off all its off-tree ordered entries to form N. Its tree
coefficients satisfy (12) by summing the actual vertex equations.
The determinant of (12) is z_v-z_u=-Delta_l, which is nonzero, so
each pair is exactly (10). Thus the inverse is simply

    (h,Lambda) -> (h,(Lambda_ij on all off-tree ordered pairs)). (13)

Equations (10) and (13) are inverse in both directions. They cover
the WHOLE equality space, not just arrays reached from an initial
curve or through a restricted type of correction. For each fixed h
in U_tree the equality space is an affine space of dimension r(r-1).
The equality map has rank 2r. When h also varies, (10) is a smooth
rational chart with r+r(r-1)=r^2 independent real coordinates.
For r=5 this means 20 independent coefficient coordinates and five
independent physical steps. All statements about dimension concern
the equality space; the sign/PSD feasible subset is still constrained.

The tree is a basis for equality elimination ONLY. Non-tree entries
are not set to zero in Lambda; only the auxiliary matrix N sets the
dependent tree positions to zero. Opposite non-tree directions are
independent. There is no reflection condition or repeated first row.

## 5. All signs and the FULL PSD condition remain

On any nonsingular chart impose

    N_ij>=0 on EVERY independent ordered pair,
    (z_u alpha_l-beta_l)/Delta_l>=0,
    (z_v alpha_l-beta_l)/Delta_l>=0 on EVERY tree edge. (19)

There are exactly n(n-1) original sign inequalities. Depending on
the sign of Delta, multiplying one through by Delta reverses its
sense; retaining the displayed quotient avoids that ambiguity.
No sign of a final tree entry is promised for arbitrary N.

The full symmetric matrix is always formed by the original formula
in Section1. Let B be its leading r-by-r principal block and let
one_r be the all-ones vector in R^r. Because M e=0 identically,

    M = [[B, -B one_r],
         [-one_r^T B, one_r^T B one_r]]
      = J B J^T,       J=[[I_r],[-one_r^T]].         (20)

This follows by solving each of the first r row sums for its final
entry and the final row sum for the final diagonal. Consequently,
for EVERY original formal-gradient coordinate vector g,

    g^T M g=(g_(0:r-1)-g_r one_r)^T
                   B(g_(0:r-1)-g_r one_r).          (21)

Thus M>=0 on R^(r+1) if and only if B>=0 on R^r. One direction
also follows by taking g=(y,0); the other follows from (21).
The variables have not been identified: (21) evaluates the original
form for arbitrary independent g_0,...,g_r. Furthermore B>0 if and
only if M is positive definite on e-perp and ker(M)=span{e}.
Indeed the difference vector in (21) vanishes exactly on span{e}.

For completeness the exact Cholesky equivalence, INCLUDING singular
boundary matrices, is

    M>=0  <=>  B>=0  <=>  B=C C^T
    for some real lower triangular r-by-r C with C_jj>=0. (22)

A finite construction proving the last implication is as follows.
Process columns j=0,...,r-1. Set

    p_j=B_jj-sum_(k<j) C_jk^2,
    a_ij=B_ij-sum_(k<j) C_ik C_jk  for i>j.

If p_j>0 take C_jj=sqrt(p_j) and C_ij=a_ij/C_jj. If p_j=0,
require a_ij=0 for all i>j and take the whole remaining part of
column j, including its diagonal, equal to zero. If p_j<0, or if
p_j=0 with some nonzero a_ij, reject PSD. Set C_ij=0 for i<j.

To prove this algorithm covers all PSD matrices, suppose the active
trailing residual S is PSD. If its leading pivot p>0, for any y the
minimum of (x,y)^T S(x,y) over x is
y^T(S_tail-a a^T/p)y; hence that Schur residual is PSD. If p=0,
nonnegativity of (t,e_i)^T S(t,e_i) for every real t forces the
corresponding a_i=0; the trailing principal submatrix is PSD.
This proves the assertion inductively. Conversely completing the
recursion gives B=C C^T entry by entry and therefore PSD. The same
two tests prove that a rejection rules out PSD. No divisions by
zero are concealed. Strictly positive diagonal factors describe
only B>0 and must not be presented as coverage of the whole cone.

At fixed h the entries of B are affine in the independent N entries,
so the exact fibre of feasible certificates is given by the linear
sign inequalities (19) and B>=0. When h varies the displayed
functions are rational; no convexity or improved convergence of
the joint search is claimed. Introducing a factor C and imposing
B=C C^T is an optional equivalent description, with all zero-pivot
cases allowed. It introduces additional variables/equalities and
does not replace the actual matrix formula by a freely chosen PSD
remainder. Nothing here sets M=0 or imposes its rank.

## 7. Finite implementation specification; no execution

The following is pseudocode for the requested original-index path.
It is supplied as text only; it has NOT been run or numerically
evaluated during this round.

    input h[0..4], twenty real coordinates N at the listed locations
    make a 6-by-6 zero matrix N and insert those twenty coordinates
    z[0] = 1
    for i = 0..4: z[i+1] = z[i] + h[i]
    omega = (-2h[0],...,-2h[4],2*sum(h))
    Lambda = N
    for (u,v,S) in the five rows of (14):
        Delta = z[u]-z[v]
        alpha = sum(omega[i], i in S)
                 -sum(N[i,j]-N[j,i], i in S, j outside S)

            compatibility condition and free variable from (16)-(17)

            Lambda[v,u] = (z[v]*alpha-beta)/Delta

    retain all thirty inequalities Lambda[i,j] >= 0 for i != j
    take B = leading 5-by-5 block of the actual M
