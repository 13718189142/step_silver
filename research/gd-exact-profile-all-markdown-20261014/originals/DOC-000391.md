# Existing shared mathematical Python runtime

This launcher invokes only the already-provisioned Python executable:

```
/opt/danus/runtime/projects/gd-exact-profile-20260926/workers/max4/.venv-pep/bin/python
```

Run a caller-owned script, retaining the caller's working directory:

```sh
/opt/danus/runtime/projects/gd-exact-profile-20260926/research/run_shared_math_python.sh /absolute/path/to/your/script.py
```

Standard Python `-c`, `-`, and script arguments also pass through unchanged.
The launcher does not activate a shell environment, read any worker records,
copy scripts, install packages, start services, or edit configuration. Only
the software runtime is shared; private worker directories are not a data
interface. Use your own scripts and output paths. Existing discovery budgets
still apply; publishing this launcher authorizes no additional solve.
