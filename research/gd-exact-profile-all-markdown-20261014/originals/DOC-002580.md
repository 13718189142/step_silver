# Exact order sensitivity beyond the terminal schedule polynomial

Status: complete exploratory derivation, not submitted to the verifier. This is a counterexample to a proposed algebraic reduction, not to the project's asymptotic conjecture.

For every H>2,

    W_2(H,1)=(H-1)^2/3
    > W_2(1,H), since W_2(1,H)<=1/3+(H^2-2H)/4.

In particular W_2(3,1)=4/3 while W_2(1,3)<=13/12.
The two schedules have identical terminal polynomial (1-z)(1-Hz) and identical total step sum. Thus neither the full terminal polynomial, nor that polynomial together with the sum, determines the full smooth-convex worst-case objective.

All proofs below apply in arbitrary finite dimension. Normalize L=1, x_*=0, f_*=0, ||x_0||=1 by translating and rescaling the function and coordinates; the ratio defining W is unchanged.

## Elementary inequalities

For convex differentiable 1-smooth f,

    f(u)>=f(v)+<grad f(v),u-v>+(1/2)||grad f(u)-grad f(v)||^2.       (I)

For a self-contained proof, put k(x)=f(x)-<grad f(v),x>. Convexity and grad k(v)=0 show v minimizes k. Integrating the 1-Lipschitz gradient on a segment gives k(x-grad k(x))<=k(x)-||grad k(x)||^2/2. Combine with k(v)<=k(x-grad k(x)) and rearrange.

Adding both orientations of (I) gives
<grad f(u)-grad f(v),u-v>>=||grad f(u)-grad f(v)||^2.
Taking v=0 shows <grad f(u),u>>=||grad f(u)||^2, and Cauchy--Schwarz yields ||grad f(u)||<=||u||.

## A unit GD step

Start at an arbitrary vector x, put u=grad f(x), y=x-u and v=grad f(y). Inequality (I) for (x,y) gives

    f(x)-f(y)>=(||u||^2+||v||^2)/2.

The optimum pairs give f(x)<=<u,x>-||u||^2/2 and
f(y)<=<v,x-u>-||v||^2/2. Therefore

    f(y)<=<u,x>-||u||^2-||v||^2/2,
    f(y)<=<v,x>-<v,u>-||v||^2/2.

Average these two upper bounds. Writing w=(u+v)/2 gives

    f(y)<=<w,x>-(3/2)||w||^2-(1/8)||u-v||^2
         <=||x||^2/6.                                             (U)

Also f(y)>=||v||^2/2. Combining this with the first upper bound above yields

    ||v||^2<=<u,x>-||u||^2
             =||x||^2/4-||u-x/2||^2<=||x||^2/4.                   (G)

## Upper bound for (1,H)

After its first step, (U) and (G) give f(x_1)<=1/6 and ||grad f(x_1)||^2<=1/4.
The integrated Lipschitz-gradient inequality gives

    f(x_1-H grad f(x_1))
      <=f(x_1)+(H^2/2-H)||grad f(x_1)||^2.

For H>=2 the coefficient is nonnegative, so

    W_2(1,H)<=1/3+(H^2-2H)/4.                                    (F)

## Exact value for (H,1)

For H>=2, put u=grad f(x_0). Cocoercivity against the minimizer gives

    ||x_0-Hu||^2
      =1-2H<u,x_0>+H^2||u||^2
      <=1+H(H-2)||u||^2
      <=1+H(H-2)=(H-1)^2.

Apply (U) to the following unit step:

    W_2(H,1)<=(H-1)^2/3.                                         (R)

Equality is realized in dimension one. Set delta=(H-1)/3>0 and define

    f(x)=x^2/2                       if x>=-delta,
         -delta*x-delta^2/2          if x<=-delta.

The pieces and their derivatives match. Its derivative is max(x,-delta), which is nondecreasing and 1-Lipschitz; therefore f is convex, differentiable and 1-smooth. It has minimizer 0 and minimum zero.

Starting from x_0=1, the H-step gives x_1=1-H=-3delta. The unit step gives x_2=-2delta. Since x_2<=-delta,

    f(x_2)=2delta^2-delta^2/2=3delta^2/2.

The normalized terminal error is 2 f(x_2)=3delta^2=(H-1)^2/3. This proves equality in (R).

Finally the difference between (R)'s exact value and (F)'s upper bound equals H(H-2)/12, strictly positive for H>2. The result permits arbitrary real H>2 and does not use numerical certificates or computational evidence.

## Scope

This rules out an exact order-blind description of W using only the terminal scalar polynomial. It does not rule out a weaker permutation-invariant lower bound, and it does not by itself decide the asymptotic minimax target.
